# 01 · 哲学基础

本目录保存 Aletheia 与思想传统的对话。它的作用是暴露前提、提供概念工具和提出反驳，而不是用名家权威替项目证明结论。

## 每篇笔记必须回答

1. 它回应哪个 Aletheia 核心问题？
2. 可借用的概念是什么？
3. 它对 Aletheia 提出什么挑战？
4. Aletheia 接受、修订或拒绝哪些前提？为什么？
5. 哪些文本与事实仍待核查？

## 当前路线

- [`原典核查优先级.md`](原典核查优先级.md)：按与第一原则的直接性、当前文本暴露和下游影响排序；先核查真正被使用的概念，不一次补完全部哲学目录。

- [`存在与自我.md`](存在与自我.md) 与 [`自我意识.md`](自我意识.md)：制度为何必须面对可自我解释和修订的主体，并区分因果解释、个人意义、共享意义与公共正当性。
- [`黑格尔主奴辩证法.md`](黑格尔主奴辩证法.md)：从二人承认模型进入现实中的多重承认网络，并区分象征认可、资源、权限、退出与救济；劳动的主体形成作用不为强迫劳动辩护。
- [`从奴隶道德到价值定义权.md`](从奴隶道德到价值定义权.md)：从奴隶道德主题对话重构处境中的评价脚本、局部评价的跨域扩张，以及适应、同意与正当性的区分；不把“价值定义权”归于尼采本人。
- [`马克思异化理论.md`](马克思异化理论.md)：劳动与人的活动如何被外部结构支配。
- [`康德伦理学.md`](康德伦理学.md)：人格不可仅作为工具的规范资源及其边界。
- [`儒家伦理.md`](儒家伦理.md)：关系责任、道德外包、书写与命名权、个体限度以及道德课程与制度实践的一致性。
- [`现代个人主义.md`](现代个人主义.md)：自主、多元生活与共同条件之间的张力。

其中《儒家伦理》《黑格尔主奴辩证法》《从奴隶道德到价值定义权》和《存在与自我》已有实质草稿，但原典、思想史与经验命题仍待核查；其余文件可能仍是研究提纲。哲学目录提供概念工具与反驳，不应被引用为 Aletheia 的当前制度基线。
