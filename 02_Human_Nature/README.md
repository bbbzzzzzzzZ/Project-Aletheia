# 02 · 人类模型

目录名沿用 `Human_Nature`，但这里研究的是**可被证据修正的人类行为假设**，不是固定不变的“人性本质”。制度若依赖错误的人类模型，即使价值目标良好，也可能产生强迫、套利或崩溃。

## 当前最小假设

- 人不是出厂定型的功能设备，也不是可以被无限塑造的空白；人在现实限度中仍可能终身发展能力并修订方向。
- 人具有多种需求，且对自身需求的认识有限、可变并受环境塑造。
- 人既可能合作、照护和互惠，也可能竞争、支配、搭便车和欺骗。
- 行为会受资源、信息、身份、关系、制度激励和权力结构影响。
- 制度宣称的价值与实际奖惩可能不同；这种差距如何影响选择是经验问题，不作单一心理推断。
- 能力、精力、健康、风险承受和照护负担在个体与时间之间高度不同。
- 没有单一动机可以解释全部行为。
- “搭便车”只能作为具体行为假设接受条件审查，不能被固定成人格或群体身份；正当理由也不以公开全部私人信息为前提。

当前人的工作模型见 [`开放主体模型.md`](开放主体模型.md)。它区分持续发展的可能、已经形成的能力、任务资格与承担意愿，不能被当作无限可塑或强制成长的依据。

## 研究纪律

每个假设都应记录：支持证据、反例、适用条件、跨文化差异、制度含义，以及该假设若错误会导致什么失败。
