## 为什么要归档

原项目里混合了：

- 当前定义；
- 历史定义；
- 机制草案；
- 审计记录；
- 对话整理；
- 外发文章；
- 论文草稿；
- 证据与材料；
- AI 生成的中间版本。

这些内容都有保留价值，但不应该全部出现在当前入口层。否则项目会变成资料库，而不是一个可以被作者重新理解和维护的理论。

## 恢复方式

如果以后需要查旧版本，可以解压历史包，按文件名、日期或目录查找。

当前精简版不删除历史，只是不再把历史材料放在主阅读路径上。
