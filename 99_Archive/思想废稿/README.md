# 思想废稿

这里登记已明确放弃或被替换的路线，目的是保存失败原因，不是隐藏不利材料。

## 当前已放弃表述

- “需求直接产生要求别人满足的权力” → 替换为表达、说明、请求协作和自主追求的资格。
- “未被市场或公众认可的活动不算劳动” → 替换为劳动属性与交换价值分离。
- “完成公共责任才取得基本保障” → 替换为基本保障来自存在与成员资格。
- “绝对时间主权 / 绝对拒绝权” → 替换为默认归属个人，严格例外需完整约束。
- “承担责任自然获得权力” → 替换为仅获得完成特定任务所需的有限权限，并必须退出。
- “知识收益权可以永久化” → 替换为贡献记录可长期保存，收益权必须有限。
- “AI 自动裁决公共事务” → 替换为 AI 仅辅助整理、匹配、模拟、审计与预警。
- “责任或贡献积分可以换取更高人格、福利或政治资格” → 明确禁止跨域资本化。

未来新增废稿时应说明原文、日期、放弃理由、替代表述和相关证据。
