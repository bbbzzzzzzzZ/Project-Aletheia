# Pre Root Restructure · 重构前阶段

这是 Project Aletheia 根目录重构前的思想阶段归档：项目当时以“社会制度白皮书”为主要入口，围绕需求、责任、能力、权力、劳动、基本保障、知识贡献与治理建立了较完整的应用性框架。

本目录保存迁移摘要和 2026-08-10 完整白皮书框架快照；原始长对话、完整劳动经济母稿和其他来源材料仍保留在原位置。当前定义以新框架为准。

## 被替代的项目定位

旧定位容易被理解为“一套新的社会制度”。新定位上移为：研究人如何认识需求、形成共同需求，并使责任与权力保持一致。
