# 05 · 历史案例

本目录不编写“人类制度从低级走向 Aletheia”的历史。案例的作用是检验命题、寻找反例和暴露机制代价。

## 使用规则

- 每个时代名称都只是研究入口，不把广泛、多样的社会压成单一制度。
- 区分当时人的自我理解、制度文本与实际运行。
- 说明材料范围、证据不确定性和未被记录者。
- 同时记录改善、代价、失败、适用条件和不可复制条件。
- 每个案例必须指出它检验哪个 Aletheia 命题。

统一格式见 [`案例分析模板.md`](案例分析模板.md)。宽泛时代文件仍只是研究入口；v0.2.9 首次完成两个边界明确的案例分析。两案均保持 `draft`，不代表相应社会类型或整个项目已经验证。
