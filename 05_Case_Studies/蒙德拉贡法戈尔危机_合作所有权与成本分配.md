# 蒙德拉贡法戈尔家电危机：合作所有权、实际控制与成本分配

> 本文分析 Fagor Electrodomésticos 在金融危机后至 2013 年破产及 2014 年成员安置的有限时段。它不是对蒙德拉贡全部历史、全部合作社或“社会主义实验”的总评。

## 1. 范围与证据

- **核心时间**：2008—2014 年；2015 年反思文集只用来标记危机后的内部讨论。
- **组织范围**：Fagor Electrodomésticos 的巴斯克合作社母体、部分法国和波兰子公司，以及蒙德拉贡集团对受影响成员的互助安置。
- **机制范围**：成员民主、母子公司控制、受影响者范围、危机信息、就业安置和成本分配；不评价蒙德拉贡的全部金融、教育和社会保障体系。
- **主要资料**：Errasti 在 2012—2013 年进行的参与观察和访谈研究；蒙德拉贡 2014 年年报；危机后由蒙德拉贡大学出版的反思文集。

### 证据限制

1. Errasti 的论文在最终破产前完成，适合分析母子公司结构，不足以独立重建破产决定全过程。
2. 蒙德拉贡年报能证明集团公开报告的成员安置结果，但属于组织自我报告，不能替代独立审计或非成员叙述。
3. 不同资料对“受影响者”“安置”“就业解决方案”和统计时点的口径可能不同，本文不合并成单一最终数字。
4. 子公司工人、临时工、供应商、债权人、家庭和地方社区的材料明显少于成员材料。

## 2. 所检验的命题

| Aletheia 命题 | 本案问题 | 竞争性解释或反例 |
|---|---|---|
| 所有权、成员权与具体控制权必须分开 | 合作社成员民主是否覆盖跨国子公司的劳动者？ | 母体成员民主可能与对子公司劳动者的层级控制同时存在 |
| 受影响者不等于决定者，二者不能互相冒充 | 谁承担关厂、转产和失业风险，谁能参与决定？ | 为保护成员就业而国际化，可能把风险转给无成员权的劳动者 |
| 事实权力按实际控制识别 | 战略、研发、品牌和资本由谁控制？ | 法律上多个公司并不表示决策能力已经分散 |
| 合作制度需要危机期退出、修复和互助 | 集团能否在成员失业时分担损失？ | 安置成员的互助能力可能建立在成员／非成员边界上 |
| 贡献或专业声誉不能自动生成跨域权力 | 既有管理和合作声誉是否掩盖信息不对称？ | 组织成功叙事可能降低外部质疑和内部预警的可见性 |

**反驳当前判断的证据**包括：证明境外子公司劳动者拥有与母体成员实质相当的议题、信息、投票和危机保护；或证明集团安置与母体成员身份无关而对所有受影响劳动者按同一规则覆盖。

## 3. 需求结构

至少存在四类不同需求：母体成员保住工作与资本账户，子公司劳动者保住工作并参与影响自身的决定，集团维持整体偿付与就业，地方社区降低工厂收缩造成的连锁损失。

“合作社成员的共同需求”不能自动代表全部受影响者。Errasti 的研究指出，国际化后的外国子公司通常不是合作社，境外劳动者不因此取得母体成员的治理位置。于是同一企业网络中出现了不同的需求入口和保护等级。

## 4. 责任结构

Fagor 的母体成员通过合作社机构参与治理；管理层、治理委员会和社会委员会承担不同职责。但跨国经营把责任链拉长：母体可以控制品牌、研发、资本与产能调整，境外子公司却承受部分就业与转产风险。

危机后的集团内部安置显示，联合体不是只在账面上共享名称。蒙德拉贡 2014 年报称，在约 1,900 名受影响成员中，接近 90% 当时已有就业解决方案。这是互助能力的正面证据，也是范围限定的证据：公开数字明确以“members”为对象。

## 5. 权力结构

### 形式权力

- 母体成员拥有合作社内部的表决与治理资格；
- 管理层负责经营和国际化执行；
- 子公司依法具有自身公司结构和劳动关系。

### 事实权力

Errasti 的材料显示，波兰工厂的研发能力有限，并依赖巴斯克和法国的产品工程与集团研究中心；关于让子公司工人成为成员的讨论又受到母体成员不愿失去控制的边界影响。由此可见：

- 公司法律边界不能替代实际控制图；
- “合作所有”只回答谁是成员，不回答非成员受谁控制；
- 母体内部民主不自动消除母体对外的层级权力。

## 6. 资源、劳动与时间

国际化在一段时期内扩大市场、调整产能并保护母体成员就业，同时把生产、技术依赖和危机风险分布到不同国家。劳动者承担的不是同一种风险：成员可能有资本账户、治理渠道和集团内部安置，子公司雇员可能只有劳动合同和当地工会渠道。

这要求 Aletheia 在计算公共责任、贡献与修复时区分：

- 对组织投入的劳动时间；
- 对经营决策的实际影响；
- 危机损失、转岗成本和家庭迁移成本；
- 成员身份带来的互助资格；
- 非成员为维持同一系统承担却未进入共同账本的成本。

## 7. 结果与分布

### 可观察的制度收益

- 联合体在大型成员失业危机中表现出跨合作社协调和再就业承接能力；
- 成员所有制使就业、团结和共同体影响成为不能被利润指标完全替代的组织目标；
- 危机后出现内部反思材料，为制度学习保留入口。

### 分布不对称

- 母体成员、当地非成员、境外子公司工人和其他受影响者拥有不同治理与互助资格；
- 母体保护就业的目标可能与子公司转产、关闭或削减岗位的风险冲突；
- 内部安置数字不能说明供应商、临时工、非成员员工和地方社区的损失是否得到修复；
- 能否参与决定和能否在危机后被承接，是两种不同权利，不应合并为“合作社已经照顾劳动者”。

## 8. 反馈与失败

合作社大会、治理委员会、社会委员会和集团协调为成员提供反馈通道；境外子公司主要依赖管理链和工会，跨国劳动者之间缺少同等共同治理接口。Errasti 在危机前的研究已把这种“合作母体—资本主义子公司”的张力列为核心问题。

2013 年破产说明，成员民主和集团互助不能替代产品、市场、资本、风险和信息治理。2014 年的安置结果说明修复机制具有真实能力，但不能反向证明此前决策、预警和受影响者参与已经充分。

## 9. 对 Aletheia 的结论

### 支持

- 支持按实际控制而不是组织名称识别事实权力；
- 支持把成员、需求者、受影响者、决定者和执行者分开记录；
- 支持建立跨组织的失业承接、转岗和修复储备；
- 支持“合作可以成为理性选择”，因为联合体确实能提供单体组织难以提供的危机缓冲。

### 挑战

- 挑战“合作所有权自然消除权力集中”；成员民主可以与对非成员的层级控制并存。
- 挑战只按组织内部平均结果评价制度；成员得到安置不等于所有受影响劳动者得到同等保护。
- 挑战把共同身份直接当作共同需求；成员共同体也可能把外部成本留给边界之外的人。

### 项目需要增加的测试条件

1. 十环节权力矩阵必须把关联公司、供应商和跨境控制纳入“同一关联主体”审计。
2. 任何互助、责任积分或贡献制度都要显示成员和非成员的资格边界，以及边界外成本。
3. 项目生命周期应分别记录危机前信息、决定参与、执行影响、危机后安置和未修复损失。
4. 组织自报的高覆盖率必须保留口径、时点和对象，不得升级为对全部受影响者的总评价。

### 暂不能判断

- 最终破产决定中各机构掌握信息的精确时间线；
- 非成员、境外子公司工人和地方社区的完整净损失；
- 同样的联合互助结构能否在缺少共同历史和高组织密度的地区复制。
