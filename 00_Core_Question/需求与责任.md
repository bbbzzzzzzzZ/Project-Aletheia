# 需求与责任

## 当前回答摘要

> 需求首先取得表达、修订、请求和自主追求的资格；共同体成员的有限互惠公共责任来自共同维持公共条件的成员关系，而不是由某个需求自动生成。具体任务义务仍须逐项分配和证明。

“需求产生责任”不能被简化为“有需求的人必须独自承担一切”，也不能被理解为“只要有需求，别人就有义务满足”。

完整责任类型与边界只在 [`../03_Aletheia_Framework/责任模型.md`](../03_Aletheia_Framework/责任模型.md) 维护；以下阶梯用于暴露研究问题，不是第二套规范定义。

## 责任问题的分流

```text
感受到需求
↓
表达、解释与修订 —— 基本资格，不自动产生执行责任

请求他人协作或调用公共资源
→ 在本人能力和安全允许范围内产生条件、成本、风险的说明责任

创设依赖 / 作出承诺 / 形成判断或共同决定 / 授权 / 执行
→ 分别产生面向未来的角色职责与可追溯问责

造成实际影响
→ 产生停止扩大伤害、说明、修复、补偿与学习责任
```

这不是从需求向责任自动下行的阶梯。同一事件中，需求体验者、提议者、受益者、负担承担者、决定者、授权者和执行者可以不同，必须逐项识别。

## 公共责任的四个相互分离判断

```text
公共必要性认定
→ 某项共同条件或服务是否必须维护，最低水平、替代和可接受降级是什么？

公共组织与维护责任
→ 经正当决定后，哪些机构或角色负责融资、组织、招募、储备、监督、救济与连续性？

有限互惠公共责任
→ 具备现实能力的成员原则上是否应对维持公共必要条件作有约束力但有限的公平分担？当前回答：是。

具体公共责任任务义务
→ 某一成员在某一时间是否须承担某项任务？必要性、公平、能力、合理条件、替代、豁免、延期和申诉是否全部成立？
```

四个判断不得自动跳转。项目已经接受有限互惠公共责任的原则性存在，但认定某事具有公共必要性仍不自动确定唯一组织形式，机构承担维护责任也不自动把负担下沉给成员、一线人员或家庭；一般责任原则更不等于任何具体任务已经分配。具体任务义务必须在机构先行责任可追溯后，逐项满足公共必要性、分配公平、本人相关能力、合理任务条件、替代、豁免、延期与申诉条件。

## 关键区分

- 本人是自身需求经验与终极生活目的的第一表述者，也是自主行动的默认决定者；这不等于本人必须先证明需求、独自满足或承担全部成本。
- 普通自愿任务只有在本人知情承诺后产生承诺范围内的任务责任；有约束力的公共责任任务则走独立分配分支，不能伪装成本人自愿，也不能跳过适用条件、通知、豁免与申诉。
- 共同依赖和共同条件支持有限互惠公共责任的一般原则，但不自动确定机构形式、具体承担者或具体任务，更不能由抽象道德口号替代分配论证。
- 承担责任可以成为申请相应授权权限的理由之一，但责任本身不生成权限；还必须明确任务或公共职能、能力条件、授权者、范围、监督和退出。
- 退出终止相应的未来角色义务和权限，不抹除退出前已经发生的伤害、既有修复责任或必要的安全交接。
- 食物、住所、基础医疗、教育、人身安全和必要服务等基本保障不以履责为条件；拒绝劳动、失职或逃避互惠责任都不得取消这些底线。
- 某些高于基本底线、与公共协作直接相关的互惠性公共运行权益，可以在严格相关、相称、限期、可申诉且有恢复程序时与履责状态相关；具体范围和后果仍待研究。
- 拒绝单项任务不等于逃避互惠责任。只有具备现实能力者在多种合理分担方式可用、正当理由已经审查后，仍长期拒绝任何合理分担，才可讨论逃避；批评针对行为，不固定人格。

## 未决问题

- 婴幼儿、重病者和失能者的需求如何产生他人的照护责任？
- 历史形成的结构性伤害由谁承担修复责任？
- 不可预见影响如何分配责任？
- 集体责任如何避免变成无人负责或全体有罪？
- 成员资格、共同受益与现实能力如何共同界定有限互惠责任的适用范围，而不把成员身份变成自动派工权？
- 公共必要性由谁按什么证据认定，最低服务与可接受降级怎样确定？
- 机构维护责任怎样避免被静默转嫁给一线人员、家庭和退出能力较低者？
- 具体任务的公平分配、总负担、合理条件、替代、豁免、延期与申诉采用什么程序？
- 哪些非基本权益确与公共协作直接相关，何种关联、期限、相称后果与恢复程序才正当？
