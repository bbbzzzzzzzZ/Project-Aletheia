# 需求与责任

## 当前回答摘要

> 需求首先取得表达、修订、请求和自主追求的资格。判断第一责任时，先问这项具体需求归属于谁：私人需求由个人先负责；经正当确认的公共需求由公众先负责。第一责任不等于亲自执行、全部过错或具体个人任务；组织、成员和执行者的责任仍须分别成立。

“需求产生责任”不能被简化为“有需求的人必须独自承担一切”，也不能被理解为“只要有需求，别人就有义务满足”。

完整责任类型与边界只在 [`../03_Aletheia_Framework/责任模型.md`](../03_Aletheia_Framework/责任模型.md) 维护；以下阶梯用于暴露研究问题，不是第二套规范定义。

## 责任问题的分流

```text
感受到需求
↓
表达、解释与修订 —— 基本资格，不自动产生执行责任

拆分具体需求并判断归属
→ 私人需求由个人负归属层第一责任
→ 公共需求主张先接受公共正当性审查，成立后由公众负归属层第一责任
→ 组织或任务需要由采用目标、职能或任务的可识别结构负第一责任

对归属于个人的需求请求他人协作或调用公共资源
→ 在本人能力、安全和现实条件允许范围内形成合理自助、求助、维权、必要交互、减损与说明的个人需求责任

创设依赖 / 作出承诺 / 形成判断或共同决定 / 授权 / 执行
→ 分别产生面向未来的角色职责与可追溯问责

造成实际影响
→ 产生停止扩大伤害、说明、修复、补偿与学习责任
```

这不是从需求向责任自动下行的阶梯。同一事件中，需求归属主体、需求体验者、提议者、受益者、负担承担者、决定者、授权者和执行者可以不同，必须逐项识别。第一责任只是归属层的起点，不替代其余责任。

个人需求责任只处理归属于个人的需求，不要求独自解决一切，也不适用于单纯感受和表达需求。健康、残障、知识与资源不足、照护负担、权力差距、报复风险、渠道不可及和紧急危险都会改变本人能够合理承担的部分；公共需求、组织需求、制度失败和侵害后果不能因为发生在某个人身上就改写成他的个人责任。

## 公共责任的五个相互分离判断

```text
公共必要性认定
→ 某项公共需求主张是否成立，最低水平、替代和可接受降级是什么？

公共需求归属责任 / 第一责任
→ 公共需求成立后，公众怎样承担不能把最低回应与持续承接推回给求助者的集体责任？

公共组织与维护责任
→ 经正当决定后，哪些机构或角色负责融资、组织、招募、储备、监督、救济与连续性？

有限互惠公共责任
→ 具备现实能力的成员原则上是否应对维持公共必要条件作有约束力但有限的公平分担？当前回答：是。

具体公共责任任务义务
→ 某一成员在某一时间是否须承担某项任务？必要性、公平、能力、合理条件、替代、豁免、延期和申诉是否全部成立？
```

五项内容必须分别说明。公共必要性认定一旦确认某项主张属于公共需求，公众第一责任就随归属成立；它不是每个自然人的义务总和，也不自动确定唯一组织形式、成员分担、具体任务或权限。公众第一责任必须落实为可追溯的共同决定和机构职责，机构也不能把维护负担下沉给成员、一线人员、家庭或当下求助者。具体任务义务必须在机构先行责任可追溯后，逐项满足公共必要性、分配公平、本人相关能力、合理任务条件、替代、豁免、延期与申诉条件。

## 关键区分

- 本人是自身需求经验与终极生活目的的第一表述者，也是自主行动的默认决定者；这不等于本人必须先证明需求、独自满足或承担全部成本。
- 需求表达者、当下求助者和需求体验者不自动成为需求归属主体；第一责任跟随需求归属，不跟随谁最先开口。
- 对于归属于个人的需求，个人请求他人或公共资源时，应在现实能力范围内说明已采取行动、障碍与所需协助，并考虑合理替代；这可以影响响应方式和资源配置，但不取消基本权利、基本保障或紧急救助。公共服务使用者的具体交互责任则须按本人能力、信息可及性、实际必要性与比例逐项判断，不能由“正在求助”直接推出。
- 公共需求由公众先负责，不表示每名成员承担相同任务；必须先把集合层责任落到可追溯机构，再分别判断成员分担和具体任务。
- 人的能力和处境会变化；互助可以跨时间和对象传递，基本照护不按逐人功劳结算，承认帮助者贡献也不产生人格债务、永久还债或服从。
- 普通自愿任务只有在本人知情承诺后产生承诺范围内的任务责任；有约束力的公共责任任务则走独立分配分支，不能伪装成本人自愿，也不能跳过适用条件、通知、豁免与申诉。
- 共同依赖和共同条件支持有限互惠公共责任的一般原则，但不自动确定机构形式、具体承担者或具体任务，更不能由抽象道德口号替代分配论证。
- 承担责任可以成为申请相应授权权限的理由之一，但责任本身不生成权限；还必须明确任务或公共职能、能力条件、授权者、范围、监督和退出。
- 退出终止相应的未来角色义务和权限，不抹除退出前已经发生的伤害、既有修复责任或必要的安全交接。
- 食物、住所、基础医疗、教育、人身安全和必要服务等基本保障不以履责为条件；拒绝劳动、失职或逃避互惠责任都不得取消这些底线。
- 某些高于基本底线、与公共协作直接相关的互惠性公共运行权益，可以在严格相关、相称、限期、可申诉且有恢复程序时与履责状态相关；具体范围和后果仍待研究。
- 拒绝单项任务不等于逃避互惠责任。只有具备现实能力者在多种合理分担方式可用、正当理由已经审查后，仍长期拒绝任何合理分担，才可讨论逃避；批评针对行为，不固定人格。

## 未决问题

- 婴幼儿、重病者、残障者和失能者的需要怎样由局面创设、亲职、公共必要性、机构职能与有限互惠分别形成照护责任？
- 私人、组织和公共需求怎样判断归属；同一事件中的复合需求怎样拆分？
- 如何判断合理自助、真实渠道可及和正当障碍，而不把不幸、制度失灵或侵害后果单方归咎需求者？
- 怎样承认照护与帮助贡献而不建立功劳等级、感恩服从或以过去贡献换取基本照护？
- 历史形成的结构性伤害由谁承担修复责任？
- 不可预见影响如何分配责任？
- 集体责任如何避免变成无人负责或全体有罪？
- 成员资格、共同受益与现实能力如何共同界定有限互惠责任的适用范围，而不把成员身份变成自动派工权？
- 公共必要性由谁按什么证据认定，最低服务与可接受降级怎样确定？
- 机构维护责任怎样避免被静默转嫁给一线人员、家庭和退出能力较低者？
- 具体任务的公平分配、总负担、合理条件、替代、豁免、延期与申诉采用什么程序？
- 哪些非基本权益确与公共协作直接相关，何种关联、期限、相称后果与恢复程序才正当？
