# 人是什么？

## 当前回答摘要

人在制度中首先被视为能够感受、形成需求、反思自身、参与关系并修订生活方向的开放主体，而不是职业、身份、能力、收入或贡献的集合。

这不是对“人的本质”的最终形而上学回答，而是制度设计的最低约束：制度不能把一个可自我修订的人压缩成单一社会功能，也不能借“可发展”要求人不断优化自己。

当前工作模型见 [`../02_Human_Nature/开放主体模型.md`](../02_Human_Nature/开放主体模型.md)，完整规范理由见 [`../03_Aletheia_Framework/第一原则.md`](../03_Aletheia_Framework/第一原则.md)；本文件保持问题与反例入口，不作为平行定义源。

## 需要回答

- 自我是否先于关系存在，还是在承认与关系中形成？
- 当人的陈述受创伤、操控、成瘾或信息限制影响时，谁能质疑其需求？
- 儿童、失能者和无法表达者如何保持主体地位？
- 人的身份何时帮助行动，何时反过来吞噬自我？
- 人的能力与生活方向具有多大可变性，现实边界和制度条件是什么？
- 制度能评价人的行为到什么程度，不能评价人的存在到什么程度？

## 当前边界

- 可以评价行为、能力、结果和风险。
- 不能由这些评价推出人格等级或基本生存资格。
- 任何代理判断都必须以恢复或扩大当事人的自主表达为目标，而不是永久取代当事人。
