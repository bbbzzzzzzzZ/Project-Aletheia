# 权力与责任

## 当前回答摘要

> 基本权利、事实权力与授权权限必须分别分析；承担责任本身不会把任何一项自动转换成另一项。

完整定义与授权条件只在 [`../GLOSSARY.md`](../GLOSSARY.md) 和 [`../03_Aletheia_Framework/权力模型.md`](../03_Aletheia_Framework/权力模型.md) 维护；以下约束是问题检查表。

因此，“权责一致”不能把权利、控制力和执行许可合并。对授权权限至少检查六项：

1. 授权权限有可追溯的公共事项、决定与授权来源；
2. 授权权限只覆盖明确任务或公共职能、对象和行为；
3. 执行者具备相应能力；
4. 判断、执行、监督与救济尽可能拆分；
5. 授权权限有期限、复核和申诉；
6. 任务完成、任期届满、授权撤销或条件消失后，授权权限退出；既有修复责任另行保留。

同时必须审计未经授权但真实存在的事实权力，并保护不以任务授权为条件的基本权利。

有限互惠公共责任的原则性存在，不会自行生成对某个人的派工权限。普通自愿任务由本人承诺进入；有约束力公共责任任务须先完成具体义务分配，再由独立、可追溯程序授予执行所需权限。即使具体任务义务成立，执行权限仍须受任务封套、能力、安全、数据、资源、监督和退出边界限制。

## 不能成立的推论

- 我承担责任，所以我拥有被照护者、下属或共同体。
- 我能力更强，所以我天然拥有决定目标的权力。
- 我贡献更多，所以我应拥有更多基本政治权利。
- 我代表公共利益，所以可以免于公开、监督和退出。
- 我有权分配公共责任，所以可以跳过豁免、申诉或用基本保障迫使执行。

## 研究问题

- 谁判断某项权限是完成责任所必需的？
- 监督者如何被监督？
- 分权会不会造成责任破碎和无人承担？
- 紧急状态下扩大权限的最小条件是什么？
- 权限退出后，数据、关系、资源和事实影响如何一并归还或清除？
