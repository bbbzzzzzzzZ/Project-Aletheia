# 02_当前机制

这一层保存当前仍有参考价值的机制草案。

这些文件不是第一原则，也不是现实实施方案。它们只是尝试回答：

> 如果接受 Aletheia 的核心判断，制度机制可能怎样设计？

## 阅读提醒

机制草案必须接受三个限制：

1. 不能反向改写第一原则；
2. 不能把候选规则写成已经确认的制度；
3. 不能用复杂机制盖住人的真实感受、退出权和承担能力。

特别是责任积分、公共任务、资源优先权等内容，目前仍应作为候选机制阅读，而不是项目定论。
