# Aletheia Core v0.1：核心原则与推导关系

修订：2026-09-25。规范摘要与论证说明；不是经过验证的制度方案。

## 这份文件回答什么

Aletheia 坚持：人不能仅被当作他人目标的工具；共同需要的基本条件由公众共同承接；决定权、履责条件、后果承担与纠错之间应保持有效联系。

本文件解释这些选择之间的关系。完整规范依据是[第一原则](../01_核心定义/第一原则.md)，冻结范围见[语义冻结说明](../01_核心定义/01_第一原则_v1.0_语义冻结.md)。摘要不能增加或削弱冻结公理。

## 怎样阅读“推导”

下文区分三种内容：

- **规范选择**：项目认为应当怎样对待人，需要给出理由，并接受价值层面的批评。
- **规范含义**：在已经接受相关价值前提后，对制度边界作出的解释。
- **经验假说**：某种安排可能产生什么效果，需要证据，不能凭价值正确就宣布有效。

“人是目的”并不单独决定所有保障项目、分担方式和组织结构。基本保障、共同承接与有限互惠也是项目明确选择并承担论证责任的规范前提。具体机制另行比较。

## 一、人是目的，评价不能决定人格资格

**规范选择：** 具体的人具有不因职业、财富、健康、学历或贡献而降低的基本地位。

**规范含义：** 可以评价行为、能力、成果和任务表现；不能据此判断一个人是否值得生存、受到尊重或拥有基本权利。承认能力、智慧和领导力的差异，与拒绝人格等级可以同时成立。

这不保证任何一种评价工具有效，也不预先否定责任积分。工具是否有助于记录贡献和激励参与，属于机制研究。

## 二、需求值得被表达，满足方式需要另行论证

**规范选择：** 本人是自身需求的首要表述者；需求不直接产生支配他人的权力。

**规范含义：** 私人愿望不能自动成为他人义务；公众的需要也不能自动授权无限占用个人时间、身体和资源。共同安排需要说明影响、代价、权利边界及授权。

紧急任务的边界、期限和复核受第一原则约束，具体程序属于机制文件。

## 三、先判断需求归属，再判断第一责任

**规范选择：** 第一责任跟随需求归属主体，不跟随最先开口者、当下受难者或最有能力执行的人。

私人需求首先由个人在现实能力范围内负责。疾病、衰老、残障、失能及维持共同生活所需的基本条件，是项目主张由公众共同承接的需求；组织运行产生的用工、排班与资源需求，由相应组织或任务系统承接。

**规范含义：** 公共需求在某个人身上显现，不表示他应独自维持整个回应系统；公众第一责任也不表示每个人承担相同任务。第一责任不等于亲自执行、全部过错或自动获得权限。

哪些服务纳入保障、保障到什么程度，仍需要公共论证，不能只凭分类名称决定。

## 四、分工可以不同，权责关系应当接得上

**规范选择：** 决定、执行、监督和后果承担之间，应有可追踪、可质疑、可纠错的有效联系。

需求者、决策者和执行者可以是不同主体。本文所说的“主体链断裂”，指职责与实际控制、履责所需条件、受影响者质疑以及纠错回应之间出现可识别的联系失效；分工本身不是断裂。

**规范含义：** 公共任务委托给机构后，公众的共同承接责任不因合同而消失；机构也不能把自己的组织责任直接下推给家庭或一线人员。

**经验假说：** 在资源压力相近的情况下，无法有效质疑分配安排、缺少可行替代的群体，可能承担更多未被安排和补偿的成本。检验时分别记录安排和结果，不用“已经受损”同时定义断裂并证明其效果。具体方法见[反证条件与测试方法](05_反证条件与测试方法.md)。

## 五、有能力者应有限分担；公共权利不靠劳动换取

**规范选择：** 具备现实承担能力的共同体成员，应以有限、公平、可调整的方式分担维持基本共同条件的责任。这是项目认可的有限互惠原则，需要独立的规范论证；它不由“我有需求”单独推出。

它的理由是：共同条件持续需要有人维护，仅把负担留给固定的一群人并不公平。这个理由仍需与个人时间自主、现实能力和负担差异一起讨论，不能直接决定某个人应做什么。

**规范含义：** 表达、参与、质疑、监督和救济的基本资格，不以完成公共任务为前提。未参加任务、无法参加任务或正在提出异议的人，仍保有这些权利。具体执行权限则需要另行授权。

**经验假说：** 在负担合理、信息可理解、意见能够影响决定的条件下，参与公共事务可能增加知识、经验和实际影响力。参与也可能流于形式或造成过载；不能预先宣布它必然带来公共控制力。

“拿回权力”在这里表示增强行使已有权利的现实能力：

```已有的公共参与与监督权利
＋ 合理的参与条件、共同维护经验和有效反馈
→ 可能增强实际影响公共事务的能力
```

健康、年龄、残障、孕产、照护负担和学习状态等影响实际承担能力。任务范围、替代方式、总负担与问责安排见[公共责任制度草案](../02_当前机制/03_公共责任制度.md)。

## 六、基本保障不能变成服从交换

**规范选择：** 基本生存与自主所需的保障，不以就业、服从、公共任务表现或积分为资格条件。

**规范含义：** 对具体行为追责，不得取消基本权利与生存保障。贡献可以获得额外回报，但回报不能成为他人失去底线的依据。

这项选择不意味着现实资源始终充足。实际短缺、公开配给和未兑现的保障需要如实记录，不能把规范资格当成已经交付的服务。

缺席后果、任务选择限制及记录方式属于[候选机制](../02_当前机制/03_公共责任制度.md)，不在 Core 中确认其适用项目或有效性。

## 七、评价服务具体任务，不扩张为总体人格排序

**规范选择：** 能力、劳动、贡献与领导力可以被承认，评价保持领域和用途边界。

**规范含义：** 专业声望不能自动取得跨领域决定权；积分不能决定基本保障、一般政治权利或人格地位。自愿追随可以撤回，不能等同永久授权。

责任积分作为记录、反馈、成就感与激励工具继续保留为候选，见[积分与领域评价](../02_当前机制/04_责任积分_贡献积分与领域专业评价.md)。它能否改善参与、是否增加记录负担，均需要比较。

## 八、公共能力不足应公开，公开不等于解决

**规范选择：** 公共系统应说明缺口在哪里、谁受影响、谁正在承担代价、何时复核，不把能力不足改写为个人道德失败。

**经验判断，保留但待检验：** 如果缺口不公开，它通常会被转移给没有退出权的人。

这里的“通常”需要跨案例材料支持，不能仅用一个养老案例证明；“没有退出权”在经验研究中还应区分法律上的限制与现实中缺少可行替代。

**规范含义：** 照护不足不能仅被解释为子女不孝，护理员短缺不能仅被解释为不愿吃苦。公开缺口为质疑和共同决定提供条件。

公开本身不会新增人员、资金或时间。即使公开且公平地讨论，仍可能无法兑现全部保障；此时记录供给失败和剩余损害，不把公开视为免责，也不据此自动给个人增加任务。

## 九、制度可以纠错，项目自己的判断也可以被推翻

**规范选择：** 受影响者应能质疑决定，制度保留与事项相适应的复核、退出、修复及修订路径。

**规范含义：** 退出未来角色不自动免除已产生的修复责任；交接要求也不能成为无限延期退出的理由。

**经验假说：** 有效反馈可能减少持续伤害，但纠错程序本身有时间、资源和参与成本。原则得到认真执行仍可能出现效果不佳的方案，见[Failure Map](09_Aletheia_Failure_Map_v0.1_目前已知的制度失败模式.md)。

反例先检验命题，不自动生成新规则。

## 原则与下游研究的关系

| 已选择的前提 | 可以据此要求的边界 | 尚不能单独推出 |
|---|---|---|
| 人格平等、基本保障与时间自主 | 不以履责决定人格和生存资格 | 保障篮子、资源数量、统一工时 |
| 公共需求共同承接、有限互惠 | 组织责任可追踪、分担有边界 | 平均派工、某一种任务制度 |
| 权力受限、受影响者有程序权利 | 可质疑、可复核、可修正 | 程序必然有效、治理形式天然优越 |
| 贡献可以承认、评价不能吞没人 | 记录有用途边界 | 积分算法、兑换比例及其效果 |

原则提供评价方向；经验研究检查解释；制度工程比较方案。三者之间需要补充理由和证据，不能用一串箭头省略论证。
