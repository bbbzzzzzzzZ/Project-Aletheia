# 《责任型社会制度—架构规格文档》兼容性审计

> [!WARNING]
> 该旧规格已被 Project Aletheia v0.1.4 取代。原文中“核心公理”、“不可协商”、“已确定”和“架构核心”只表示当时整理结果，不是现行状态。

## 一、文档性质与使用边界

- 原文件是一份约 200 行的旧综合架构，不是原始对话，也不是现行白皮书。
- 它的可保留价值是显示早期模块关系、当时认为的空缺和面向专业协作者的接口。
- 它把当时的 AI 整理、用户方向、候选机制和具体参数统一写成“已确定原则”，来源分层不足。
- 该文档不再担任总控。现行状态只能从 [`../../DOCUMENT_STATUS.md`](../../DOCUMENT_STATUS.md)、[`../../GLOSSARY.md`](../../GLOSSARY.md) 及各现行模块读取。

## 二、四项旧公理的兼容性

| 旧公理 | v0.1.4 判定 | 现行替代 |
|---|---|---|
| 存在先于职业 | 保留并精化 | 人格、基本尊严与生存资格不由职业、劳动、能力或贡献证明；见 [`../../03_Aletheia_Framework/第一原则.md`](../../03_Aletheia_Framework/第一原则.md)。 |
| 需求对应权力，权力对应责任 | **已取代** | 需求先生成表达与请求资格，不生成支配权；责任按请求、承诺、事实判断、共同决策、授权、执行、监督和修复分账；执行权限须经具体任务授权。 |
| 组织是任务的临时载体，任务后解散 | **已取代** | 临时的是具体任务权限，不是所有组织。医疗、照护、能源、知识维护与申诉可能需要稳定团队、记忆和连续责任；角色、授权和组织本身应有复核、替代与退出。 |
| 不得替他人选择牺牲 | 保留并精化 | 过去自愿、关系身份与抽象牺牲意愿不是未来具体授权；紧急例外须有条件、最小侵害、期限、补偿、复核、终止与追责。 |

## 三、总体架构的取代

### 保留的接口

1. 教育、劳动、经济、科研、政治与纠错之间必须显示依赖关系。
2. 政治不只是一个并列模块，还回答谁能制定、修改、暂停和废除其他模块规则。
3. 边界情况与反馈修正应贯穿所有模块，不只是某一独立机构。
4. 面向专业协作者时，应分别写已接受的规范边界、待验证机制、尚未回答的工程问题和不可由专家代替决定的公共价值问题。

### 已取代的中心化表述

- “劳动制度是架构核心”已被根问题、哲学、人类模型、Aletheia 框架与应用层的根目录分层取代。
- “教育产出能力并进入劳动系统调度”已被本人控制的私人能力图谱、细粒度授权、公共能力池最小投影、任务邀请与本人承诺取代。
- “科研是过剩劳动力的导流出口”不再保留；科研是独立的知识活动，不是为了填满人的时间而制造的任务。

## 四、教育模块审计

| 旧内容 | 兼容性结论 |
|---|---|
| 终身学习、可反复转换方向 | 保留；当前路由为 [`../../04_Institution_Design/Education_System/生命周期教育.md`](../../04_Institution_Design/Education_System/生命周期教育.md)。 |
| “带教推荐 + 同行匿名 + 服务对象信任”的统一毕业公式 | 已取代。证据应按具体任务风险选择，服务对象反馈不是唯一准入且不是无偿评审义务。 |
| 兴趣教学与高风险公共任务教学分开 | 保留为研究方向，但须继续分开表达、教学、受监督实践和独立高风险执行。 |
| 异端通道 | 保留为反垄断和替代证据路径问题，不取消安全、伦理、数据与受影响者边界。 |
| 学习时间与公共责任换算 | 已取代；教育不是责任积分账本的子系统。 |

## 五、劳动模块审计

### 保留为当前接口

- 能力不应等同于永久职业身份；但能力信息默认私有，不由“社会”完整记录。
- 连续性是运行问题，但应分开任务结果、关系、专业判断和系统连续；不把“进行中不可换人”当作普遍原则。现行路由为 [`../../04_Institution_Design/Labor_System/Mechanisms/公共服务连续性与储备机制.md`](../../04_Institution_Design/Labor_System/Mechanisms/公共服务连续性与储备机制.md)。
- 专业当场判断与事后独立复核是可用接口，但不能从职业身份推出默认同意任何风险指令。
- 一项复杂技能能否拆分为可协作子任务，及哪些情境判断必须综合保留，仍是有用研究问题；外科等示例不是已验证结论。
- 长期离开后重新进入应依据当前相关证据，不仅依据固定年限；但风险底线、独立评估和利益冲突仍须保留。

### 明确已取代

- 一生责任总量、每年 `400/800` 小时、难度系数、积分倍增时间、跨期结清与“提前换自由”全部已取代。
- “任务积分是文明贡献履历”不消除它形成道德等级、声望资本和对未来人生索权的风险。
- 任务优先级表不能凌驾个人授权、健康、照护、受影响者风险与真实替代方案。
- “公共责任的本质是维系身心健康与社会联结”已取代；人的关系与意义不是强制劳动的附产品。
- 警察普遍轮转、军事小队必须重组、以邓巴数证明编组、以同行信任作为唯一复工标准，均为待核查候选。
- 医疗错误不能以旧稿的四分法直接决定可原谅、吊销或刑事责任；事实、能力、过程、因果、可预见性、组织条件与救济需分开。

## 六、经济与科研模块审计

- 基本保障不以市场成功和劳动服从为条件已保留；但“基础物资与货币完全分开”、土地全部公有只租不卖、企业互助担保、双账本结构都仍是资源与经济研究问题，不是现行原则。
- 多源数据、异常背离和独立审计是可保留的反造假接口；满意度、投诉率和事故率不能被写成已验证的统一算法。
- 同行评议、复现、第三方验证与实践结果可作为多元证据接口，但不是所有科研领域的统一排序公式。
- 稀缺实验室、设备、导师时间和风险材料的分配，以及成果如何反馈教育，仍是有用模块接口。

## 七、政治、司法与元规则审计

### 保留的空缺与接口

1. 谁能制定、修改、暂停和废除规则，以及谁能修改“修改规则的规则”。
2. 事实争议与组织权限/管辖争议可能需要不同的程序。
3. 原决定机构不能同时垄断吊销、驳回、事实认定和最终复核；应有可接近的独立救济。
4. 战争与紧急状态的启动、权限范围、补偿、复核、终止与追责是上游政治问题。
5. 多功能组织的跨中心协调不会因“去中心”自动消失；现行路由为 [`../../04_Institution_Design/Political_System/多中心治理与技术中枢.md`](../../04_Institution_Design/Political_System/多中心治理与技术中枢.md)。

### 已取代或仍未验证

- 混合陪审制、随机抽签、专家证人和扩大人数不是已完成的政治合法性设计；它们只能作为待比较机制。
- 随机抽签不自动解决资格池边界、参与负担、知识差距、专家库控制、少数保护与可申诉性。
- 公民判断能力不能被写成教育系统必然产出的人力资源；公民教育不产生服从现行程序的义务。

## 八、边界情况方法审计

保留：

- 制度不以“第一版正确”为目标，而必须保留反馈、申诉、替代、日落与修正。
- 平均满意度不能掩盖最差受影响者、少数人或不能参与评价者。
- 应使用健康、残障、照护、紧急、少数、拒绝、欺诈、数据错误和系统中断等边界案例测试候选机制。

已取代：

- “客观障碍”与“主观消极”不能由机构简单二分并据此惩罚；应评估任务条件、说明范围、可替代方案、健康与照护隐私，不判定完整内心。
- 满意度、更换率、工时和健康数据都不是可自动优化的单一目标；它们会受选择偏差、压力、不报告和指标博弈影响。

## 九、可继续使用的协作者接口

对任何专业协作稿，保留旧规格“区分原则与工程问题”的形式，但改用以下四栏：

| 栏位 | 必须说明 |
|---|---|
| 当前规范边界 | 可从现行第一原则和词汇表引用的内容 |
| 候选机制 | 尚待比较、验证和受影响者参与的实现 |
| 专业证据问题 | 数据、风险、可行性、成本、失败模式与不确定性 |
| 公共价值问题 | 谁受影响、目标是什么、哪些负担与风险可接受；不得交由专家或算法单方决定 |

## 十、审计结论

旧规格作为架构演化证据仍有价值，但它不能再作为当前定义、制度总图或参数来源。其中最值得保留的是模块接口、政治合法性空缺、事实争议与权限争议分程序、独立复核、元规则以及边界情况测试。需求直接生权、所有组织临时化、固定工时与积分、社会完整记录能力、自动调度和已完成的混合陪审制均已被 v0.1.4 取代或降级为待验证问题。
