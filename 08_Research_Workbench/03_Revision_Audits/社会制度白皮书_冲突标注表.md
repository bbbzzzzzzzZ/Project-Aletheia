# 二、最重要的三处修订点

## 1. 责任积分不是冲突，而是需要拆成两层

原稿中责任积分有两个方向：

- 责任记录；
- 未来责任调整与自由时间转换。

根据最新确认，这两点和当前版本并不冲突。

应拆成两层：

第一层是责任积分：

> 责任积分 = 任务时长 × 难度 / 风险 / 消耗系数。

它用于判断一个人已经完成了多少公共责任，并支持 400/800/1200 这类责任周期结算。

第二层是社会贡献积分：

> 一生总责任 = 终身社会贡献积分。

它是责任积分、知识贡献积分和其他公共贡献沉淀后的贡献履历。

边界是：

- 责任积分可以用于公共责任结算；
- 社会贡献积分可以用于终身贡献展示；
- 二者都不能交易、继承、兑换市场货币、购买公共权力、决定基本保障或成为市场/教育筛选条件。
- 科研资助、实验设备等稀缺公共科研资源申请，可以参考责任积分、对应业务任务质量分和专业评审。

结论：

> 第八章不需要否定“积分与自由时间转换”，而是要把它明确为“责任结算释放时间”，不是“积分购买特权”。

## 2. 专利制度需要换成知识贡献权制度

原稿中的 11.2 仍有传统专利逻辑：

> 给予创新者有限排他权。

当前确认版更接近：

> 知识立即公开，贡献者获得有限收益权，但没有阻止他人学习、研究、改进的否决权。

结论：

> 11.2 应从“专利制度”改为“知识贡献权制度”。传统专利可以作为旧制度对照或过渡机制，不应作为新制度核心。

## 3. 强制机制必须写成最后兜底

原稿已经很强调强制边界，但还没有写入当前新机制：

- 年度四级公共运行任务清理；
- 脏累险提高责任系数；
- 纯枯燥缩短排班；
- 18 到 25 岁一生一次抽签半年；
- 普通拒绝不惩罚；
- 只有抽签后无合理理由拒绝才触发诚信后果；
- 诚信后果不得触碰基本食物、住所、医疗、教育和必要公共服务。

结论：

> 第四章或第七章需要新增“无人承担任务处理流程”。

# 三、基本一致但建议补强的地方

| 原稿内容 | 当前判断 | 建议 |
|---|---|---|
| 人先于职业、存在价值与劳动价值分离 | 一致 | 保留 |
| 基本生存保障不以劳动表现为条件 | 一致 | 补充“基本食物、基本住所、基础医疗、基础教育、基本人身安全、必要公共服务” |
| 能力不等于随时可调用 | 一致 | 保留 |
| AI 不能成为最终权力主体 | 一致 | 可与技术基因图谱 AI 初筛机制合并说明 |
| 战争与灾害中的权力退出 | 一致 | 补充统一启动条件和分灾种机制 |
| 公共资源不得按责任积分高低分配基础资源 | 一致 | 保留 |

# 四、建议优先修订顺序

1. 第八章：公共责任积分制度  
   先改，因为这里需要把“责任积分结算”和“终身贡献积分展示”拆清楚。

2. 第十一章：专利制度与创新奖励  
   改成知识贡献权制度，否则会和最新知识贡献方案冲突。

3. 第六章：公共责任时间  
   补入 400/800/1200 三档。

4. 第四章或第七章：无人承担任务处理流程  
   补入年度任务清理和抽签半年机制。

5. 第十二章：战争与灾害  
   补入统一启动条件和分灾种机制。
