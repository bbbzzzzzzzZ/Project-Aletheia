# 二、已确定原则提取

## 1. 经济金融模块已确定

1. 企业互保不能用无限连带担保链，应转为共同基金和风险池。
2. 金融互助担保基金负责可分散的个体或局部信用风险。
3. 跨行业风险池负责单一行业无法消化的行业冲击。
4. 系统性流动性危机不能由互助基金解决，应另设公共流动性管理组织。
5. 基金管理、风险评估、审计监督、危机处置必须分离。
6. 公共流动性支持不是赔钱，只能面向仍具偿付能力但暂时缺现金的主体。
7. 流动性投放必须多人授权、强制回避、临时权限、事后审计。
8. 保留现代商业银行贷款创造存款货币。
9. 银行拥有贷款审批权，是因为银行承担贷款判断错误造成的第一顺位损失。
10. 利率由市场和公共流动性管理体系共同影响：市场定具体贷款价格，公共组织调节基础融资环境。
11. 个人存款进入金融互助担保基金，但采用限额保障。
12. 银行破产时，股东、风险资本和债权人先承担损失，不能让互助基金替股东兜底。
13. 现代资本充足率、杠杆率、流动性覆盖率等框架可以基本沿用，只替换公共权力执行结构。

## 2. 企业制度已确定

1. 现代股权中“资本 → 治理权”的绑定不适合当前制度。
2. 企业权利应拆成：
   - 收益权；
   - 治理权；
   - 专业经营权。
3. 收益权来自资本投入或合法取得，可以交易。
4. 治理权来自治理责任和管理能力认证，不可以买卖。
5. 创始人不是治理权的永久所有者，而是第一任治理责任承担者。
6. 治理权限随治理责任终止而终止。
7. 企业兼并收购可以买收益权和可交易资产，不能购买治理资格。
8. 企业不能通过收购绕过公共资源规则。
9. 投资者获得收益权、信息权、契约保护权，但不因出资获得治理权。

## 3. 司法模块已确定

1. 结果不好不等于应当追责。
2. 追责需要存在可归责因素：违规、玩忽职守、主观恶意、未达行业基本标准。
3. 判断责任主要看：
   - 主观心态；
   - 注意义务；
   - 因果关系；
   - 可预见性。
4. 民事案件原则上由双方举证，不由警察主动取证。
5. 民事案件可以进入法律任务池，由具备律师资格的人领取代理任务。
6. 弱势方、基本权利案件、小额但重要案件可以进入公共法律责任任务池。
7. 律师能力、裁判能力、专业鉴定能力必须分开。
8. 裁判者从司法裁判能力池临时抽取，案件结束权限消失。
9. 判决记录应公开可查，公众可监督、申诉、反馈。
10. 多数意见不能直接替代司法判断，但可以触发复核或法律评估任务。

## 4. 受害者救济模块已确定

1. 司法目的不只是程序公平，而是保护人的基本权利。
2. 司法应通过公平程序确认事实与责任，恢复受害者对自身经历的解释权。
3. 受害者救济应优先于责任认定，不应等法院多年判完才救助。
4. 基础医疗、基本生活、紧急支持先由基础保障承担。
5. 大额和长期损害通过保险、公共基金、责任赔偿等分层处理。
6. 无责任受害者应进入公共救助基金、灾害基金、特殊风险基金。
7. 公共赔偿基金可以先行救济，并取得对责任人的追偿权。
8. 责任人偿还应考虑能力、比例和期限，不能制造永久奴役。
9. 受害者有知情权、陈述权、影响说明权、对赔偿方案发表意见的权利。
10. 受害者不拥有刑罚决定权，刑罚属于公共司法权力。
11. 公共责任积分不是货币，不能直接用于赔偿受害者。

# 三、待补与风险点

| 模块 | 待补问题 | 风险 |
|---|---|---|
| 金融互助基金 | 缴费比例、行业风险评级、基金规模、安全阈值 | 高风险行业长期依赖低风险行业补贴 |
| 公共流动性管理 | 公共流动性管理组织的组成、任期、权限边界、启动条件、回收机制 | 流动性发行权变成支配企业生死的权力 |
| 流动性审核组 | 3 人、5—7 人、9—15 人等比例只是初始参数 | 审批过慢或被利益集团渗透 |
| 存款保障 | 保障限额具体多少、个人/企业账户是否不同标准 | 全额兜底导致大额资金不承担银行选择责任 |
| 银行破产 | 员工工资、供应商应付款、税费、公共债权的顺位 | 互助基金变相救助股东 |
| 企业收益权 | 收益权发行上限、反稀释细则、信息披露格式、最低分配触发条件 | 投资者收益权变成空壳，企业融资困难 |
| 治理权继任 | 治理责任如何认定，管理能力认证如何做，创始人退出如何交接 | 治理权变成隐性身份特权 |
| 反垄断 | 收益权、供应链、数据、渠道集中如何评估 | 即使不能买治理权，仍可能形成事实垄断 |
| 民事法律任务池 | 律师任务报酬、责任积分、公共报酬、弱势方匹配机制 | 律师只接容易赢或高额案件 |
| 临时裁判 | 上诉、复审、司法解释统一机制 | 临时裁判导致判决不一致 |
| 判决公开 | 隐私保护、未成年人保护、商业秘密、受害者二次伤害 | 公开变成舆论审判 |
| 受害者救济 | 长期伤残评估、护理支持、心理修复、家庭照护补偿 | 受害者获得程序承认但现实恢复不足 |
| 司法赔偿基金 | 基金来源、先行支付范围、追偿比例、期限限制 | 基金透支或责任人被永久债务化 |
| 刑事制度 | 什么行为进入刑法，刑罚形式，是否保留监禁，服刑劳动边界 | 刑罚滑向复仇或强迫劳动 |

# 五、建议下一步

如果继续正式修订白皮书，我建议下一步不要马上回到第八章，而是优先做：

> **司法制度总章草案。**

原因：

1. 后半段最新讨论已经转向司法；
2. 司法目的、责任认定、民事任务池、临时裁判、受害者救济已经有不少已确定内容；
3. 但刑罚形式、监禁、刑事边界还没有定；
4. 司法制度会反过来支撑前面所有“责任—权力—能力”的争议处理。

建议司法制度先按以下目录起草：

```text

X.1 司法目的
X.2 结果不好与应当追责的区分
X.3 民事法律任务池
X.4 临时裁判能力池
X.5 判决公开、申诉与法律反馈
X.6 受害者权利保护与损害修复
X.7 司法赔偿预备金与追偿机制
X.8 刑事责任类型与刑罚目的
X.9 待补：刑罚形式、监禁与改造机制
```
