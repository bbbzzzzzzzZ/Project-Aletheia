## G 组：公共权力失效纠错

| 编号 | 确认后的状态与边界 |
|---|---|
| G-01 | 接受公共项目持续产生并分级公开责任记录。 |
| G-02 | 接受外部托管方向；改为分散风险、完整性校验、分级访问和访问留痕，不建不可审计的中央证据库。 |
| G-03 | 接受合理怀疑启动初查；初查不等于定责，善意举报与滥用分流并行。 |
| G-04 | 接受限事项、限类型、限期限的证据保全与法定强制取证。 |
| G-05 | 接受毁灭受控证据的独立责任及相称不利推定；不得自动推定有罪。 |
| G-06 | 接受监督失效后的多入口替代调查。 |
| G-07 | 接受临时调查组并增加来源多样、利益回避、经费安全和过程审计；随机抽取不单独证明独立。 |
| G-08 | 接受司法授权调查方向，同时保留多个法定入口、理由公开和复核，不假定司法永不失效。 |
| G-09 | 接受必要修复不等待责任人偿付能力；完整赔偿仍须依法确认。 |
| G-10 | 接受受害者修复账户与责任追偿账户分离。 |
| G-11 | 接受公共基金先行修复和后续追偿方向；基金来源、顺序、审计与不足方案继续开放。 |
| G-12 | 接受追偿保留基本保障，并区分主观状态、时效与重新开始机制。 |
| G-13 | 删除以公共责任劳动偿还赔偿；不得形成债务劳动。 |
| G-14 | 追偿只及责任人实际取得的遗产，不把债务转移给继承人或家属。 |
| G-15 | 接受无法归责损害的公共救助方向；未知责任、尚未查明、无法归责与灾害分别处理。 |
| G-16 | 接受重大利益申报；采用实际控制和重大利益门槛，保护无关家属隐私。 |
| G-17 | 接受利益冲突回避；项目失败不自动证明腐败或触发没收。 |
| G-18 | 接受只追缴与滥权有因果关系的不当利益增量，并保护善意第三人。 |
| G-19 | 接受经独立审查、限范围并保留基本生活与申诉的资产保全。 |
| G-20 | 接受追回利益优先修复受害者和公共损失，调查人员不得按追回金额提成。 |

## C 组：公共合作激励

| 编号 | 确认后的状态与边界 |
|---|---|
| C-01 | 接受合作应成为个人理性上值得选择的行为，而非服从测试。 |
| C-02 | 接受需求、时间、安全和服务改善；公共改善原则上惠及所有受影响者。 |
| C-03 | 接受以减少重复办理和制度摩擦作为优先合作回报。 |
| C-04 | 接受项目承担交通、照护、无障碍、翻译、时间和必要专业支持等参与成本。 |
| C-05 | 接受困难、高风险、专业和长期任务获得现实补偿。 |
| C-06 | 成本维度只作分项检查，不合成为统一补偿分或难度分。 |
| C-07 | 接受意见进入方案及重要异议回应义务。 |
| C-08 | 接受合作身份不产生无限任务义务；有限公共责任任务仍走独立个案程序。 |
| C-09 | 接受拒绝具体任务不生成跨领域人格或信用评价。 |
| C-10 | 接受举报、异议和反对属于制度纠错合作，并保护免受报复。 |
| C-11 | 只允许复用有效资料、资格和具体履约事实；删除个人综合可靠度。 |
| C-12 | 接受记录的范围、期限、最小化、纠错和申诉。 |
| C-13 | 删除责任积分，不以积分记录或激励合作。 |
| C-14 | 困难必要劳动的供给效果保持开放，须按行业验证。 |

## 确认边界

- 接受的是经逐项修订后的项目方向，不是现实法律条文、机构授权、程序参数或有效性证明。
- 不恢复债务劳动、统一补偿分、责任积分、综合可靠度、总诚信分或按合作记录分配基本服务。
- “公共权力失效五层纠错”保留为候选框架名；具体调查、基金、追偿和资产规则继续保持 `draft` 或 `question`。
