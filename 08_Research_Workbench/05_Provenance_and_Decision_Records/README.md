# 05 · Provenance and Decision Records

本目录保存来源身份映射与 Project Aletheia 自身的决定确认记录。它解决两个不同问题：某项材料来自哪里，以及项目发起者具体确认了什么。

- [`SOURCE_REGISTRY.md`](SOURCE_REGISTRY.md)：为来源提取、导入记录和本轮项目对话分配稳定、不携带语义的 Source ID。
- [`PROJECT_DECISION_CONFIRMATIONS.md`](PROJECT_DECISION_CONFIRMATIONS.md)：记录项目内部方向决定的确认主体、确认范围及所依赖的 Source ID。

`v0.1.6` 的 `PCR-5E7A91` 记录有限互惠公共责任方向及其边界，并明确其只部分取代 `D-015` 的开放结论，不取消三层不得自动跳转的结构。

这里的记录只证明 Project Aletheia 的思想归属和项目内部决定链，**不是**现实共同体、受影响者或公众对任何制度的授权。项目内部确认不能替代公共决策所需的参与、异议、代表、复核和撤回程序。

## 记录顺序

```text
来源进入项目并取得 Source ID
→ 起草命题或决定
→ 记录确认主体、来源与范围
→ DECISION_LOG 标记 Accepted
→ 同步术语、理论、文档状态和 Unreleased 变更记录
```

Source ID 与决定确认记录必须在语义冻结前形成；压缩包、校验和及最终发布版本在结构冻结后形成。
