每项请选择：

- **修改**：方向基本接受，但按你的文字修改。

- **删除**：不进入项目。

本确认只确定项目内部研究与写作方向，不确认具体参数、法律效力、现实公共授权或实施可行性。

## P · 职业入口开放

| 编号 | 待确认命题 | 选择 |
|---|---|---|
| P1 | 取消与专业能力、任务风险和责任承担无直接关系的职业准入限制。 | 接受 |
| P2 | 学习、训练和申请能力验证的入口原则上向所有人开放。 | 接受 |
| P3 | 专业资格认证原则上不设人数名额；达到公开标准者均可取得相应资格。 | 接受 |
| P4 | 训练资源可以因真实稀缺而公平分配，但资源稀缺不得变成永久身份或职业名额垄断。 | 接受 |
| P5 | 能力、能力证据、任务资格、岗位、责任和执行权限分别成立，任何一项都不自动推出下一项。 | 接受 |
| P6 | 固定岗位可以根据真实任务量、连续性、预算和组织责任设置数量；岗位有限不影响资格开放。 | 接受 |
| P7 | 资格按具体领域、任务、风险和有效期记录，不建立跨职业总等级或统一职业分数。 | 接受 |
| P8 | 培训、认证、任务使用、监督、申诉和处罚不得由同一主体全部控制。 | 接受 |
| P9 | 任务评价针对具体任务并考虑结果、过程、风险和复杂度，不转化为人格信用或永久身份。 | 接受 |
| P10 | 医疗、司法、工程等高风险领域保留能力与安全门槛，但不得封闭学习和申请验证的入口。 | 接受 |

## J · 司法制度与人身安全

| 编号 | 待确认命题 | 选择 |
|---|---|---|
| J1 | 司法采用“法院常设、资格开放、岗位有限、案件逐项授权”的四层结构。 | 接受 |
| J2 | 达到司法资格标准者不因岗位名额已满而被认定为没有资格。 | 接受 |
| J3 | 法官岗位依据案件量、复杂度、地域、紧急需求和合理工作负荷设置，不构成永久司法身份。 | 接受 |
| J4 | 具体案件先匹配领域和风险资格、排除利益冲突，再在合格范围内随机或以其他可审计方式分配。 | 接受 |
| J5 | 复杂和长期案件原则上维持核心承办连续；必要更换时交接案件知识，但不绑定前任结论。 | 接受 |
| J6 | 只有延误可能造成不可逆损害的事项需要持续值班，值班权限必须最小、短期、留痕并及时复核。 | 接受 |
| J7 | 裁判理由、法律依据和司法权力使用原则上公开，敏感原始材料实行分级保护。 | 接受 |
| J8 | 司法透明、司法独立和司法问责必须同时成立；保护法官安全不等于司法免责。 | 接受 |
| J9 | 每个人的生命、身体完整、性自主和现实人身安全都属于最高保护层级。 | 接受 |
| J10 | 人身安全最高保护不等于所有身体损害适用同一种最重刑罚，仍须区分行为、主观状态、后果、证据和程序。 | 接受 |
| J11 | 本轮不确认死刑、具体刑期、法官人数、司法等级数量、任期或案件时限。 | 接受 |

## F · 生育、婚姻、亲职与儿童保障

| 编号 | 待确认命题 | 选择 |
|---|---|---|
| F1 | 生育、婚姻、亲职和儿童权利是四种不同关系，不得相互自动推出。 | 接受 |
| F2 | 怀孕、继续或终止妊娠和分娩的最终决定属于孕育者的身体自主；伴侣或遗传材料提供者不取得身体否决权。 | 接受 |
| F3 | 婚姻是成年人自愿关系，不自动产生生育义务、性义务、亲职资格或儿童支配权。 | 接受 |
| F4 | 生育和血缘可以构成初始关系与责任依据，但不产生对儿童的所有权或无限支配权。 | 接受 |
| F5 | 亲职是围绕儿童利益、稳定关系、现实照护和非伤害边界形成的持续照护关系，不采用普通职业考试和晋升制度。 | 接受 |
| F6 | 儿童是独立权利主体，不属于父母、婚姻或国家；其表达和参与资格随年龄与理解能力逐步扩大。 | 接受 |
| F7 | 公共育幼分担产后、日间、临时和紧急照护压力，但不以大型匿名机构取代稳定亲密关系。 | 接受 |
| F8 | 儿童住房和支持资源跟随真实居住与照护需要，不以婚姻或生育身份奖励成年人。 | 接受 |
| F9 | 普通困难优先支持；存在即时、现实、严重人身危险时保护优先，但紧急措施不等于最终亲职判断。 | 接受 |
| F10 | 儿童保护必须有具体风险依据，不得以贫困、非婚、残障或非主流生活方式代替伤害证据。 | 接受 |
| F11 | 亲职履责记录只保存与特定儿童直接相关的必要事实，不建立综合诚信分、永久人格标签或跨领域信用。 | 接受 |
| F12 | 本轮不确认具体亲职审查、探望、住房、记录、公共育幼和替代照护参数。 | 接受 |
