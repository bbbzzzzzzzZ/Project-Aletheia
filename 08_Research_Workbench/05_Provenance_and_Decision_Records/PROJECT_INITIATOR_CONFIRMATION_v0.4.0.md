# Project Initiator Confirmation v0.4.0

## 确认事项

项目发起者确认将当前项目整理为 `v0.4.0` 发布包，并更新到公开 GitHub 仓库 `bbbzzzzzzzZ/Project-Aletheia`。

发布名称：

> Aletheia 哲学理论 v0.4.0：人的主体性、公共责任与制度边界

## 被确认的发布范围

1. 本次发布以当前项目 Markdown 文件为发布树，不包含 `.DS_Store`、ZIP、AppleDouble、脚本、外部附件全文或本机杂项。
2. 本次版本重点是把《哲学理论基础与制度推论》及其来源、确认、状态和导航记录纳入公开研究快照。
3. 本次发布同时包含 v0.3.0 之后已经登记的上海养老护理转行材料、补贴与招聘样本核对、五层需求优先序候选接口等 `Unreleased` 变更。
4. `main` 和 `v0.4.0` 快照分支在发布后应指向同一提交，除非 GitHub 权限或远端保护规则阻止分支更新。

## 确认边界

- 发布不表示《哲学理论基础与制度推论》已经完成外部验证。
- 发布不修改《第一原则 v1.0》的冻结语义。
- 发布不表示 40 岁转行外部验证已经开始，不表示养老护理现制材料已经取得企业、经办或实践者复核。
- 发布不构成现实公共授权、法律效力、制度实施许可、事实核查完成或作者逐段批准。
- 发布包只是当前研究状态的可公开核对快照。
