# 验证记录

本目录保存案例、外部讨论、访谈、专业复核、模拟或试验怎样影响项目判断的可追溯记录。它不把浏览量、赞同、作者确认或 AI 审阅冒充验证。

- [`EXTERNAL_FEEDBACK_REGISTRY.md`](EXTERNAL_FEEDBACK_REGISTRY.md)：外部讨论的发布与逐条反馈登记。
- [`Publication_Snapshots/`](Publication_Snapshots/)：用户提供并映射到公开页面的外发正文历史快照；不作为当前定义源。
- [`External_Validation_Plans/`](External_Validation_Plans/)：尚未启动的外部验证方案；当前已把 40 岁转行收窄为上海普通企业职工主动离职后转向养老护理员，形成现制基线、阶段性调查、居家—机构成本核对、十条招聘广告样本和统一复核材料，但仍未取得雇主、实践者或参与者验证结果。

探索性公众讨论已取得两份用户提供的外发正文快照、两个公开问题页、两个公开回答直链及若干可辨认截图反馈，继续保持 `in-validation`。反馈已经触发范围明确的修订，但评论发生时的正文版本尚不能逐条核对；平台编辑历史、部分反馈 permalink、事实核查和受影响者或实践者复核仍缺，任何候选机制均不随之升级。
