# 验证记录

本目录保存案例、外部讨论、访谈、专业复核、模拟或试验怎样影响项目判断的可追溯记录。它不把浏览量、赞同、作者确认或 AI 审阅冒充验证。

- [`EXTERNAL_FEEDBACK_REGISTRY.md`](EXTERNAL_FEEDBACK_REGISTRY.md)：外部讨论的发布与逐条反馈登记。

只有取得实际公开链接、反馈原文或稳定摘要、来源身份和适用范围后，才能把相应验证单元从 `ready-for-validation` 更新为 `in-validation`。
