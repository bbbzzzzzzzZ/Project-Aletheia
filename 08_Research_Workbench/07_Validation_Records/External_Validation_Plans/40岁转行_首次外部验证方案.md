# 40岁转行：首次外部验证方案

> **上海养老护理员材料正在编制，验证尚未启动。**  
> 本轮只做现行材料核对、结构化访谈和多方方案复核，不改变参与者的真实辞职、培训、招聘、社会保障、福利或公共责任状态，不把任何候选输出用于人事或行政决定。

## 一、验证问题

本轮不问“你是否赞同责任型社会”，而问：

> 对同一个 40 岁转行情境，现行安排、局部修补和 Aletheia 候选分别保留了什么、改善了什么、增加了什么成本；哪些判断会被转行者、培训与评价机构、养老服务机构用人方、在岗养老护理员、社会保障实践者、劳动与养老服务研究人员，以及老年服务对象、家属或权益实践者推翻？

外部复核只影响这张比较卡及相邻研究问题，不能外推为劳动模块或整个项目已经成立。

## 二、固定比较基线

本轮以通用基线 `BASE-40-2026-01` 为父项，建立收窄基线 `BASE-40-SH-CARE-2026-01`。地域、年龄、原就业身份、离职方式和目标职业已经由项目发起者确认；其余变量只能作为明示分支，不能暗中补齐。

### 1. 用户确认事实

- 地域：中国大陆，上海市；
- 年龄：40 岁；
- 原就业身份：普通企业职工；
- 离职方式：本人主动离职；
- 目标职业：养老护理员。

### 2. 为保持可比性暂时固定的研究假设

- 时点：2026 年；
- 原单位和最后职工社会保险缴费地均在上海；
- 本人依普通主动辞职程序离开非安全关键岗位，不是由急性疾病、即时危险、单位违法或强制解雇触发；
- 尚无新工作邀请，没有养老护理经验、技能等级证书或相关医学学历；
- 需要持续获得食物、安全住所及卫生水电、基础医疗和必要交通；
- 没有正在发生的重大健康危机，也没有育儿、老人或患病亲属照护负担；这些条件只能以后另开分支；
- 旧岗位按法律、合同和双方合理约定完成通知、必要交接与资源归还，没有不能立即脱离的第三方生命安全任务；
- 首要比较分支为与上海民政部门备案养老机构直接建立劳动关系，从事一线养老护理；劳务派遣、居家社区服务、长期护理保险定点服务和医疗护理岗位另列敏感性分支。

项目发起者已经确认把上述内容作为首轮比较的研究假设；它们**不是项目发起者本人或现实参与者的个人事实**。任何一项被实践材料推翻时，须另建版本或敏感性分支。

### 3. 未固定的敏感性变量与观察问题

- 未固定变量：性别、户籍、学历、住房和流动资金；这些变量分别测试，不把某种有利条件默认给任何方案；
- 观察问题：是否能退出、保障是否连续、怎样获得学习入口、怎样证明相称能力、能否进入岗位、成本由谁承担，以及是否出现年龄替代能力判断。

这些事实一旦进入首轮复核不得为某套方案单独改写。需要改变时，另建带版本号的敏感性分支，不能覆盖 `BASE-40-SH-CARE-2026-01`。

### 4. 上海现制基线的范围与待核验描述

首轮现制基线限定为：**2026 年中国大陆国家规则与上海现行规则下，普通企业职工主动离职后转向备案养老机构一线养老护理员。**国家规则固定共同起点，上海规则固定当前办理与政策入口；两者都不能替代个人资格判断和行业现实。

现制基线不是“最坏个案”，而是需要由社会保障和劳动实践者纠正的常规功能链。必须把普通养老机构就业、长期护理保险服务和考证补贴拆成分支：普通养老机构可能允许无证入职并由机构培训；长期护理保险有自己的服务人员资格要求；连续职工社保和六个月就业条件主要用于某些证书补贴，不得倒推为所有养老护理岗位的统一准入门槛。

```text
本人依普通主动辞职程序退出旧岗位并完成合理交接
→ 工资收入随原就业关系结束或变化
→ 生活成本由储蓄、家庭、新收入及符合条件的现有公共支持组合承担
→ 本主线的普通主动辞职不符合“非因本人意愿中断就业”条件，不能领取失业保险金；养老与医疗保险按实际身份另行衔接
→ 从认可入口了解职业、接受培训并参加技能评价
→ 养老机构决定是否录用；双方依法建立劳动关系，机构负责岗前训练、安全管理和受监督任务授权
→ 符合条件后再申请技能、入职或激励补贴
```

招聘薪资通常只提供合计区间，基础工资、全勤、食宿和绩效提成可能无法从广告或合同中完全拆出。因此，无法取得完整合同并不阻止本轮材料准备；未观察到的工资结构、实际工时和到手收入必须登记为未知，不得用招聘区间自行反推。

详细规则、时间线、政策差异和待核事实见[上海养老护理员现制基线](BASE-40-SH-CARE-2026-01_上海养老护理员现制基线.md)。该材料已完成首轮官方来源核对，但没有经办结果、机构数据或参与者意见；不足之处不能由项目自行推断。

### 5. 资料锚点与使用边界

以下只用于建立待复核的国家规则起点，取得时间为 2026-08-26；具体适用仍须由社会保障与劳动实践者确认：

- `SRC-A13F6C90`：[《中华人民共和国社会保险法》](https://www.npc.gov.cn/npc/c2/c10134/201905/t20190522_175815.html)规定社会保险的基本制度、单位与个人缴费，以及部分灵活就业人员自愿参保入口；它不能单独回答主动离职后每项待遇怎样连续。
- `SRC-5D0B7E42`：[《中华人民共和国就业促进法》](https://www.mohrss.gov.cn/xxgk2020/fdzdgknr/zcfg/fl/202011/t20201102_394626.html?xxgkhide=1)规定自主择业、平等就业、公共就业服务、职业培训和特殊工种资格等国家层面功能；它不能证明年龄、跨行业经验和招聘门槛在现实中已经公平。
- `SRC-92C4F1D8`：[《中华人民共和国职业教育法》](https://www.moe.gov.cn/jyb_sjzl/sjzl_zcfg/zcfg_jyfl/202204/t20220421_620064.html)把职业学校教育与职业培训纳入服务全民终身学习的体系；它不能证明成年人实际取得课程、时间、费用和岗位入口。
- `SRC-3E8A6B51`：[人力资源社会保障部《关于健全全国统一的社会保险公共服务平台的意见》](https://www.mohrss.gov.cn/xxgk2020/fdzdgknr/qt/gztz/202503/t20250318_538687.html)要求规范关系转移接续、灵活就业参保登记等跨地区服务；它是公共服务建设方向，不等于每个地方、每项待遇已经无缝运行。

在上述国家资料外，上海材料已经覆盖普通主动辞职、失业保险申领、灵活就业参保、医保等待期、定向培训、养老护理员评价、技能提升补贴、入职补贴、激励补贴、养老服务机构责任和长期护理保险服务人员资格；本轮又补入全国在线职业标准查询和养老护理课程入口，以及职业结构、公开招聘、长期护理保险机构、支付示例和监管案例。上海市民政局年度材料确认机构日支付已从 `20/25/30` 提高到 `25/35/45` 元，另一份民政局答复明确自 2025-09-01 起上调；医保局 2026-07-15 的 `20/25/30` 问答因此保留为滞后旧口径。十条新增招聘页面只对应六个具名发布企业，仍未形成可验证工资或订单基线。具体入口与 Source ID 见[现制基线](BASE-40-SH-CARE-2026-01_上海养老护理员现制基线.md)、[阶段性调查整理](40岁转行_上海养老护理员阶段性调查整理.md)、[成本表核对](40岁转行_上海长护险居家与机构成本表核对.md)、[招聘样本表](40岁转行_上海长护险招聘样本表.md)、[上海现制来源说明](../../06_Current_Round_Source_Notes/2026-08-26_40岁转行上海养老护理员范围与现制来源.md)、[在线课程与通知核对](../../06_Current_Round_Source_Notes/2026-08-26_养老护理在线课程与定向培训通知来源核对.md)及[调查对话证据分层](../../06_Current_Round_Source_Notes/2026-08-30_上海养老护理调查对话提取与证据分层.md)。

这些资料不得被写成“现制没有支持”或“现制已经解决转行障碍”的单向结论。尤其不能把取得证书、就业并连续工作后才能申领的补贴，提前填成离职当月收入；也不能把培训补贴等同于每名主动辞职者都能获得的免费脱产学习。

本轮岗位材料再拆为四条路径：普通养老机构直接就业（主线）、高端/医疗化或专业化机构与一般机构的敏感性分层、劳务派遣或中介用工分支、长期护理保险定点服务分支；考证与技能提升、入职、在岗激励补贴另立支持分支。普通机构可能接受无证入职并由机构训练，高端机构可能提出护理专业、年龄、身高、健康或证书要求；这些是广告或项目发起者观察到的待核差异，不是全行业事实。招聘页面的 5–8K、5–6K、6–8K 和 13 薪只能登记为宣传区间，基础工资、绩效/提成、全勤与食宿折价、实际工时和到手收入均保持未知。详见[补贴与岗位样本核对](../../06_Current_Round_Source_Notes/2026-09-14_上海养老护理入职补贴与机构岗位样本核对.md)。

## 三、三套制度安排，不是三个就业岗位

本轮 A、B、C 比较的不是三个职业、三份合同或三个招聘结果，而是同一名 40 岁转行者在同一时间线上的三种制度安排：谁承担转行成本，谁承担培训和带教，工资与过渡支持如何筹资，社保怎样连续，以及养老服务安全如何维持。

提高工资可能吸引更多人进入岗位，但必须同时核对出资者、财政可持续性、机构成本、照护对象负担、留任效果和服务质量；“钱够高就有人做”只能作为待检验的劳动供给假设，不能作为方案 B 的既定收益。

方案 C 还不是整套 Aletheia 社会转型的验证。教育、社会观念和公共影响需要长期建设，本轮只能检验其中“转行—学习—训练—上岗—退出”的制度接口，并把长期转型所需的人手、时间和观念改变列为实施依赖。

### 方案 A：现制基线

保持上海现有劳动合同、社会保障、失业支持、公共职业指导、职业培训、养老护理评价、招聘、正常工资和机构安全责任，不增加项目机制。重点记录现制已经提供的自主退出、参保路径、职业方向与培训信息、机构推荐、定向培训、专业准入、雇主选择和后置补贴，也记录每项入口是否真实走通，以及离职至首次稳定上岗之间的收入、医保、培训、评价和招聘空档。

A 的岗位主线按“普通养老机构直接用工”观察，但不得把一般机构、高端/医疗化机构、劳务派遣和长护险定点服务混成一个岗位。正式入职补贴的五年合同、上海职工社保、学历、证书和一线工作条件，职业技能提升补贴的取证与连续就业条件，以及在岗激励补贴的服务年限条件分别记录；任何一项未满足条件，都不能把相应金额计入主线现金流。

### 方案 B：现制内局部修补

不建立统一基本保障或有限公共责任体系，只在现有结构内比较较小改进：在既有公共职业指导、培训信息、定向培训和机构推荐基础上，补足入口之间的可查询衔接、等待时间、责任人和失败转介；提供离职前职业说明、模拟环境、教学材料、去标识任务记录，以及不进入服务区域的设施和流程介绍；为符合条件者提供限期培训、交通或生活过渡支持；由机构提供有工资的岗前训练、带教和任务分级；必要时比较更高工资或过渡补助，但必须明确由机构、护理服务支付方、地方财政或其他主体承担，记录金额、期限、覆盖对象和财政机会成本；要求招聘和资格判断说明与具体任务相关的能力理由；保留现有雇佣、工资、社会保障与公共财政框架。

本轮所谓职业了解不包括旁观洗浴、排泄、身体转移、病情沟通或查阅服务档案。观察真实照护须另行取得服务对象知情同意、机构授权、隐私边界与退出安排，不属于本轮材料复核。

具体工具必须由复核者根据已存在制度提出，不能把 Aletheia 机制换名塞入“局部修补”。

方案 B 的外部复核必须特别比较：由机构承担有工资岗前训练和带教，还是由培训公司先收费且培训期无工资；岗位广告的合计薪资是否掩盖了基础工资、绩效、食宿和实际工时；以及机构、派遣方、长护险支付方或地方财政谁承担新增成本。

### 方案 C：Aletheia 候选

方案 C 在本轮只作为“转行接口候选”：把“基本保障在退出、探索、学习和求职期间连续，不以工资或就业状态为条件”设为候选制度义务；学习资源开放，岗位训练和带教成本由使用该劳动的养老机构承担；本人继续适用与其他有现实能力成员相同的有限公共责任规则，转行不新增任务债，学习也不自动抵销或生成具体任务；兴趣、学习、评价、证书、岗位、任务和执行权限分别成立；养老机构仍须正常雇佣、付酬、配备人员、训练和保护劳动者；新人按风险进入模拟、受监督实践和有限授权，年龄本身不代替能力证据。教育体系、社会观念改变和长期公共财政安排不在本轮假定为已经完成，而列为后续实施依赖。

方案 C 必须沿用与 A、B 相同的时间线，逐项说明保障篮子、取得方式、住房与医疗怎样交付，以及等待、短缺、服务质量、错误拒绝和申诉失败。基本保障、教育容量、公共任务、资格验证、监督申诉和转换期的资金、人员、数据与机会成本都须计入；如果不能实际交付，不得仍把“保障连续”记为方案收益。

## 四、统一比较问题

每组复核者都使用同一张表，不得只评价自己熟悉的方案：

| 维度 | 必须记录 |
|---|---|
| 退出与时间自主 | 退出所需条件、延迟、不可逆风险及谁有能力阻止退出 |
| 基本生活连续 | 食物、住房、医疗和必要服务怎样实际交付；发生短缺时谁最先受损 |
| 学习可达 | 信息、费用、时间、先备条件、年龄、地区和能力支持 |
| 学习效果 | 完成、退出、技能形成、无效培训和重新选择的成本 |
| 岗位入口 | 资格、经验、年龄、招聘成本、上岗培训和实际录用条件 |
| 第三方安全 | 哪些岗位确需严格资格，哪些门槛只是行业占有或惯例 |
| 公共责任 | 是否新增任务、怎样与学习时间冲突、谁承担未被看见的服务劳动 |
| 机构和财政成本 | 培训容量、用人单位适应、基本保障、行政、数据、监督和申诉成本 |
| 数据与事实权力 | 谁掌握学习、年龄、能力、保障和任务信息，能否纠错与退出 |
| 最坏受影响者 | 哪类人失去现制已有功能，或承担被平均值掩盖的成本 |
| 可逆性 | 方案错误时能否回到原服务、修复损害并退出新增权限 |

## 五、可以被推翻的候选命题

1. 在固定场景下，方案 C 预计比方案 A 降低退出旧职业导致基本生活中断的风险，并扩大重新选择时间；如果资源无法实际交付或负担只是转给其他一线人员，该改善不成立。
2. 方案 C 预计比方案 A 更少用年龄和旧职业替代现实能力判断；如果用人单位和安全实践者证明相关条件确实预测具体任务风险，须缩小该判断。
3. 方案 B 可能以更低转换成本取得方案 C 的大部分转行改善；若成立，就没有理由从本场景推出更大制度转换。
4. 方案 C 可能增加公共财政、培训容量、任务协调、监督和数据治理成本；若这些成本使最坏受影响者、关键服务或公共责任承担者明显恶化，应停止扩大。
5. 转行者的主观欢迎不等于制度可行，用人单位或机构的反对也不等于候选无效；结论必须同时显示各方受益、损失、事实权力与不可调和分歧。

## 六、七类不可替代复核者

| 复核组 | 最低纳入方向 | 不得被替代的知识 |
|---|---|---|
| 转行者 | 至少包括已经转成、正在转和曾放弃转行的人 | 退出成本、家庭与生活压力、培训体验、招聘门槛和真实选择 |
| 培训与评价机构 | 认可培训、技能评价与用人合作分别记录 | 零经验入口、课程与实操成本、评价、完成与退出、容量、质量和就业连接 |
| 养老服务机构用人方 | 直接用工与其他用工分开，任务风险分级 | 招聘、健康证明、资格、岗前训练、带教、工资、团队成本和安全 |
| 在岗养老护理员 | 包括承担新人带教及未承担带教者 | 隐性技能、班次、身体与情绪劳动、恢复、带教负担和安全独立条件 |
| 社会保障实践者 | 熟悉所选地域医疗、养老、失业和就业服务实际办理者 | 适用身份、连续性、资格、资金、行政流程和现制救济 |
| 劳动与养老服务研究人员 | 与上海、中年职业流动及养老护理有关的研究者 | 样本偏差、因果解释、年龄歧视、转岗、留任、伤害和政策比较 |
| 老年服务对象、家属或权益实践者 | 首轮可先用匿名情境，不要求真实接受新人服务 | 本人同意与拒绝、身体与隐私、关系连续、安全暂停、投诉和修复 |

七组都未进入以前，只能记录为缺席视角，不能以“已邀请”或“社会认可”替代。用人单位不能代表一线护理员，家属不能自动代表能够表达的老年人。存在项目、培训销售、用人、行政考核或研究利益冲突时必须披露。

“培训与评价机构”至少分别取得培训实施方和技能评价方的材料；同一机构兼具两种角色时须分栏回答，并披露招生、收费、评价、证书和就业率利益。家属或权益实践者的材料不能登记成已经取得服务对象本人经验；权益实践者可以先做法律伦理预审，但服务对象本人视角仍须标为缺席。具有表达能力的老年人可以只审阅匿名情境，不要求其接受新人护理。

## 七、复核流程

### A. 现行材料回溯

以上海与备案养老机构一线护理岗位为首要分支，用法规、办事规则、项目材料和公开数据填出现制功能链。每项材料保存版本、日期、适用对象和空白；培训、评价、用工和经办实践仍须由对应实践者纠正。

### B. 分组独立复核

向七组提供同一份 `BASE-40-SH-CARE-2026-01`、三套方案和[统一复核材料](40岁转行_上海养老护理员统一复核材料.md)。先分组书面纠错，避免强势机构或专业语言提前压住转行者、一线护理员和服务对象视角。可以匿名引用意见，但需保留角色、利益冲突和材料依据。

### C. 跨组争议会议

只讨论已经记录的事实分歧、成本转移和停止条件，不要求形成价值共识。任何一组可以指出遗漏、要求分支或提出“不继续”。少数意见和无法调和的冲突必须保留。

### D. 版本化输出

输出应包含：修正后的现制基线、三套方案比较、各组一致与分歧、被推翻命题、资源与事实权力变化、最坏受影响者、尚缺证据、停止理由和下一次复核条件。不得输出个人排名、转行适合度或招聘建议。

## 九、停止线

- 没有分清养老机构、居家社区、长期护理保险和医疗护理岗位，就开始宣称三套方案优劣；
- 只邀请支持转行或支持项目的人，缺少七类任一不可替代复核视角却输出结论；
- 为验证而要求参与者真实辞职、停止缴费、放弃收入、报名培训或接受／拒绝岗位；
- 让未经验证的新人接触真实老年人，或独立完成可能伤害其身体、隐私、财产或关系连续性的任务；
- 用培训学员、公共责任任务或无薪试岗替代养老机构的正常招聘、工资、人员配置和带教责任；
- 将复核意见提供给现实用人、培训、保障或公共责任决定；
- 用理想方案 C 对比现制最坏个案，或隐藏方案 B 已经能够取得的改善；
- 不记录基本保障、培训容量、雇主适应、公共任务、数据和监督的成本来源；
- 平均结果改善但最坏受影响者、基本权利、第三方安全或关键服务明显恶化；
- 因参与者批评、退出或拒答而降低其任何现实资格；
- 把一次 40 岁转行复核外推成劳动制度或整个社会制度已经验证。
