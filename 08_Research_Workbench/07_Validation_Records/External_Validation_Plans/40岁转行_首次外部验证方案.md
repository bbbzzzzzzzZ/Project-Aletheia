# 40岁转行：首次外部验证方案

> **方案已建立，验证尚未启动。**  
> 本轮只做现行材料核对、结构化访谈和多方方案复核，不改变参与者的真实辞职、培训、招聘、社会保障、福利或公共责任状态，不把任何候选输出用于人事或行政决定。

## 一、验证问题

本轮不问“你是否赞同责任型社会”，而问：

> 对同一个 40 岁转行情境，现行安排、局部修补和 Aletheia 候选分别保留了什么、改善了什么、增加了什么成本；哪些判断会被转行者、培训机构、用人单位、社会保障实践者和劳动研究人员推翻？

外部复核只影响这张比较卡及相邻研究问题，不能外推为劳动模块或整个项目已经成立。

## 二、固定比较基线 `BASE-40-2026-01`

### 1. 不随方案改变的情境事实

- 时点：2026 年；
- 对象：一名 40 岁、具有稳定全职工作经历的成年人；
- 当前状态：本人自愿离开原行业，不是由急性疾病、即时危险或强制解雇触发；
- 下一步：尚无新工作邀请，计划用一段连续时间探索并学习一项不同领域技能；
- 生活条件：需要持续获得食物、安全住所及卫生水电、基础医疗和必要交通；
- 本轮排除：没有正在发生的重大健康危机，没有育儿、老人或患病亲属照护负担；这些只能以后另开分支；
- 旧岗位：普通岗位，按照合理原则说明必要状态并归还资源；没有不能立即脱离的第三方生命安全任务；
- 新方向：先不指定具体行业；若复核者认为行业风险决定结论，必须分别填写低风险普通岗位与高风险专业岗位，不得暗中更换主场景；
- 观察问题：是否能退出、保障是否连续、怎样获得学习入口、怎样证明相称能力、能否进入岗位、成本由谁承担，以及是否出现年龄替代能力判断。

这些事实一旦进入首轮复核不得为某套方案单独改写。需要改变时，另建带版本号的敏感性分支，不能覆盖 `BASE-40-2026-01`。

### 2. 现制基线的范围与待核验描述

首轮现制基线限定为：**2026 年中国大陆国家层面规则下的普通企业职工主动离职与转行；地方经办、待遇等待期、补贴和培训项目另选一个明确地区补充。**国家规则只能固定共同起点，不能替代地方实际流程或个人资格判断。

现制基线不是“最坏个案”，而是需要由社会保障和劳动实践者纠正的常规功能链：

```text
本人依法或依约退出旧岗位并完成合理交接
→ 工资收入随原就业关系结束或变化
→ 生活成本由储蓄、家庭、新收入及符合条件的现有公共支持组合承担
→ 医疗、养老、失业等社会保障连续性依适用身份、缴费、资格和地方规则处理
→ 重新学习依靠个人、自有资金、现有公共培训、院校或企业项目
→ 新用人单位按岗位、经验、资格和招聘流程决定是否录用与怎样上岗
```

本描述只固定需要核对的功能，不预判法律结果。首批材料必须标明适用地域、就业类型、时期和来源；不同地方规则分别记录，不得平均成一个虚构的“全国统一现制”。如果无法固定至少一个具体地域和就业类型的现实流程，本轮停在材料准备，不进入参与者比较。

### 3. 国家层面的首批资料锚点

以下只用于建立待复核的国家规则起点，取得时间为 2026-08-25；具体适用仍须由社会保障与劳动实践者确认：

- `SRC-A13F6C90`：[《中华人民共和国社会保险法》](https://www.npc.gov.cn/npc/c2/c10134/201905/t20190522_175815.html)规定社会保险的基本制度、单位与个人缴费，以及部分灵活就业人员自愿参保入口；它不能单独回答主动离职后每项待遇怎样连续。
- `SRC-5D0B7E42`：[《中华人民共和国就业促进法》](https://www.mohrss.gov.cn/xxgk2020/fdzdgknr/zcfg/fl/202011/t20201102_394626.html?xxgkhide=1)规定自主择业、平等就业、公共就业服务、职业培训和特殊工种资格等国家层面功能；它不能证明年龄、跨行业经验和招聘门槛在现实中已经公平。
- `SRC-92C4F1D8`：[《中华人民共和国职业教育法》](https://www.moe.gov.cn/jyb_sjzl/sjzl_zcfg/zcfg_jyfl/202204/t20220421_620064.html)把职业学校教育与职业培训纳入服务全民终身学习的体系；它不能证明成年人实际取得课程、时间、费用和岗位入口。
- `SRC-3E8A6B51`：[人力资源社会保障部《关于健全全国统一的社会保险公共服务平台的意见》](https://www.mohrss.gov.cn/xxgk2020/fdzdgknr/qt/gztz/202503/t20250318_538687.html)要求规范关系转移接续、灵活就业参保登记等跨地区服务；它是公共服务建设方向，不等于每个地方、每项待遇已经无缝运行。

以上资料不得被写成“现制没有保障”或“现制已经解决转行障碍”的单向结论。地方经办规则、实际等待、缴费责任、培训可达性和招聘结果仍由本轮外部复核补充。

## 三、三套方案

### 方案 A：现制基线

保持适用地区现有劳动合同、社会保障、失业支持、职业培训、招聘和用人安排，不增加项目机制。重点记录现制已经提供的收入风险分担、专业准入、雇主选择、培训市场、责任追踪与救济功能，也记录转行者实际面对的中断、门槛和成本。

### 方案 B：现制内局部修补

不建立统一基本保障或有限公共责任体系，只在现有结构内比较较小改进：提高离职期间医疗及必要服务衔接的可达性；提供可选择且可携带的职业咨询和再培训支持；要求招聘和资格判断说明与具体任务相关的能力理由；改善学习成果与岗位入口的连接；保留现有雇佣、社会保障与公共财政框架。

具体工具必须由复核者根据已存在制度提出，不能把 Aletheia 机制换名塞入“局部修补”。

### 方案 C：Aletheia 候选

基本保障在退出、探索、学习和求职期间连续，不以工资或就业状态为条件；本人继续适用与其他有现实能力成员相同的有限公共责任规则，转行不新增任务债，学习也不自动抵销或生成具体任务；教育入口贯穿成年阶段；低风险岗位使用最小能力说明和上岗适应，高风险任务使用风险相称的资格、监督实践与有限授权；年龄本身不代替能力证据；旧岗位只作合理、有限交接。

方案 C 必须说明基本保障、教育容量、公共任务、资格验证、监督申诉和转换期的资金、人员、数据与机会成本，不能只写自主性的规范收益。

## 四、统一比较问题

每组复核者都使用同一张表，不得只评价自己熟悉的方案：

| 维度 | 必须记录 |
|---|---|
| 退出与时间自主 | 退出所需条件、延迟、不可逆风险及谁有能力阻止退出 |
| 基本生活连续 | 食物、住房、医疗和必要服务怎样实际交付；发生短缺时谁最先受损 |
| 学习可达 | 信息、费用、时间、先备条件、年龄、地区和能力支持 |
| 学习效果 | 完成、退出、技能形成、无效培训和重新选择的成本 |
| 岗位入口 | 资格、经验、年龄、招聘成本、上岗培训和实际录用条件 |
| 第三方安全 | 哪些岗位确需严格资格，哪些门槛只是行业占有或惯例 |
| 公共责任 | 是否新增任务、怎样与学习时间冲突、谁承担未被看见的服务劳动 |
| 机构和财政成本 | 培训容量、用人单位适应、基本保障、行政、数据、监督和申诉成本 |
| 数据与事实权力 | 谁掌握学习、年龄、能力、保障和任务信息，能否纠错与退出 |
| 最坏受影响者 | 哪类人失去现制已有功能，或承担被平均值掩盖的成本 |
| 可逆性 | 方案错误时能否回到原服务、修复损害并退出新增权限 |

## 五、可以被推翻的候选命题

1. 在固定场景下，方案 C 预计比方案 A 降低退出旧职业导致基本生活中断的风险，并扩大重新选择时间；如果资源无法实际交付或负担只是转给其他一线人员，该改善不成立。
2. 方案 C 预计比方案 A 更少用年龄和旧职业替代现实能力判断；如果用人单位和安全实践者证明相关条件确实预测具体任务风险，须缩小该判断。
3. 方案 B 可能以更低转换成本取得方案 C 的大部分转行改善；若成立，就没有理由从本场景推出更大制度转换。
4. 方案 C 可能增加公共财政、培训容量、任务协调、监督和数据治理成本；若这些成本使最坏受影响者、关键服务或公共责任承担者明显恶化，应停止扩大。
5. 转行者的主观欢迎不等于制度可行，用人单位或机构的反对也不等于候选无效；结论必须同时显示各方受益、损失、事实权力与不可调和分歧。

## 六、五类不可替代复核者

| 复核组 | 最低纳入方向 | 不得被替代的知识 |
|---|---|---|
| 转行者 | 至少包括已经转成、正在转和曾放弃转行的人 | 退出成本、家庭与生活压力、培训体验、招聘门槛和真实选择 |
| 培训机构 | 公共、院校、企业或市场化项目分别记录 | 课程成本、先备能力、完成与退出、容量、质量和就业连接 |
| 用人单位 | 低风险普通岗位与至少一种高风险专业岗位分开 | 招聘、资格、上岗训练、团队成本、安全与岗位真实需求 |
| 社会保障实践者 | 熟悉所选地域医疗、养老、失业和就业服务实际办理者 | 适用身份、连续性、资格、资金、行政流程和现制救济 |
| 劳动与就业研究人员 | 与具体地域、行业和中年职业流动有关的研究者 | 样本偏差、因果解释、年龄歧视、转岗结果和政策比较 |

五组都未进入以前，只能记录为缺席视角，不能以“已邀请”或“社会认可”替代。存在项目、培训销售、用人、行政考核或研究利益冲突时必须披露。

## 七、复核流程

### A. 现行材料回溯

先选择至少一个明确地域和就业类型，用法规、办事规则、项目材料和公开数据填出现制功能链。每项材料保存版本、日期、适用对象和空白；资料不足即停止。

### B. 分组独立复核

向五组提供同一份 `BASE-40-2026-01`、三套方案和统一比较表。先分组书面纠错，避免强势机构或专业语言提前压住转行者体验。可以匿名引用意见，但需保留角色、利益冲突和材料依据。

### C. 跨组争议会议

只讨论已经记录的事实分歧、成本转移和停止条件，不要求形成价值共识。任何一组可以指出遗漏、要求分支或提出“不继续”。少数意见和无法调和的冲突必须保留。

### D. 版本化输出

输出应包含：修正后的现制基线、三套方案比较、各组一致与分歧、被推翻命题、资源与事实权力变化、最坏受影响者、尚缺证据、停止理由和下一次复核条件。不得输出个人排名、转行适合度或招聘建议。

## 八、参与、隐私与记录

- 邀请说明必须写明研究尚未证明 Aletheia 更好，参与不影响任何就业、培训或社会保障资格；
- 参与者可以拒答、撤回和要求更正本人陈述；
- 不向用人单位提供可识别的转行者材料，不向培训机构提供招生线索；
- 不收集与比较问题无关的医疗、家庭、财务或身份数据；
- 访谈补偿不得以赞同项目或完成全部问题为条件；
- AI 可以帮助整理已去标识材料，但不能代替参与者、决定争议或生成缺席意见。

## 九、停止线

- 尚未固定具体地域、就业类型和现制来源，就开始宣称三套方案优劣；
- 只邀请支持转行或支持项目的人，缺少五类任一不可替代复核者却输出结论；
- 为验证而要求参与者真实辞职、停止缴费、放弃收入、报名培训或接受／拒绝岗位；
- 将复核意见提供给现实用人、培训、保障或公共责任决定；
- 用理想方案 C 对比现制最坏个案，或隐藏方案 B 已经能够取得的改善；
- 不记录基本保障、培训容量、雇主适应、公共任务、数据和监督的成本来源；
- 平均结果改善但最坏受影响者、基本权利、第三方安全或关键服务明显恶化；
- 因参与者批评、退出或拒答而降低其任何现实资格；
- 把一次 40 岁转行复核外推成劳动制度或整个社会制度已经验证。

## 十、当前缺口与启动条件

当前尚未选择具体地域和就业类型，未完成现制材料包，未形成参与者邀请名单、知情说明、访谈提纲、数据保存与删除规则、利益冲突表和独立复核安排，也没有任何参与者意见。
