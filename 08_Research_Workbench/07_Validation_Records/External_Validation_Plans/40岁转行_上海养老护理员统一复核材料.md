# 40 岁转行上海养老护理员：统一复核材料

> **尚未发送邀请，也没有取得任何外部意见。** 本材料只让不同复核者判断同一个匿名情境；不得要求任何人真实辞职、停保、付费培训、接受岗位或接触老年服务对象。

## 一、给所有复核者的同一张情境卡

### 用户确认事实

- 中国大陆，上海市；
- 40 岁；
- 普通企业职工；
- 本人主动离职；
- 转向养老护理员。

### 为保持可比性暂时固定的研究假设

> 2026 年，L，40 岁，在上海一家普通企业的非安全关键岗位工作，处于正常劳动合同期、非试用期，原单位和最后职工社会保险缴费地均在上海。L没有因单位违法而解除合同，也没有现成的协商离职补偿，决定依普通主动辞职程序离开。  
>   
> 离职时，L没有新的工作邀请，没有养老护理经验、技能等级证书或相关医学学历，希望转入上海民政部门备案养老机构的一线养老护理岗位。L没有正在发生的重大健康危机，也没有育儿、老人或患病亲属照护负担。

项目发起者已经确认把这段人物设定用于首轮比较；它不是本人或现实参与者的个人经历。首要比较分支采用养老机构直接用工；劳务派遣、居家社区服务、长期护理保险定点服务和医疗护理岗位必须单列，不得暗中拿某个分支的便利替换主场景。

### 未固定的敏感性变量

研究不规定 L 的性别、户籍、学历、住房和流动资金，而把它们分别作为敏感性分支。任何复核材料改变暂定研究假设时，须另建版本或分支，不得倒写成用户确认事实。

## 二、三套待比较方案

### A · 现制基线

- L按普通主动离职程序退出，原工资停止；
- 本主线的普通主动辞职不符合“非因本人意愿中断就业”条件，不能领取失业保险金；单位违法解除等情形另开分支；
- 按实际身份分别处理养老和医疗保险衔接；
- 可以通过公共就业服务推荐、符合条件的定向培训、养老机构招聘培训或个人自行寻找进入认可的培训与评价入口，并承担不被现有项目覆盖的费用和时间；实际走通哪一条必须记录，不能预设现制只有个人摸索；
- 可以先利用全国在线课程与国家职业技能标准查询入口了解职业和预习理论；平台课程完成不自动等于上海认可培训、技能等级证书、机构录用或独立任务资格；
- 由养老服务机构决定是否录用；双方依法约定劳动关系、工资与劳动条件，机构负责岗前训练、安全管理和具体任务授权；
- 符合条件时再申请技能、入职或激励补贴；补贴按实际规则后置兑现。

本情境的岗位主线是普通养老机构直接用工，但复核时必须分开一般机构、高端/医疗化或专业化机构、劳务派遣/中介用工和长期护理保险定点服务。考证及补贴不是普通机构岗位的统一前置条件。正式入职补贴按官方办法另记为：五年合同、上海职工社保、证书、学历和持续一线工作等条件，五年合计 3 万或 4 万元，按 1/3/5 年 20%/40%/40% 发放；它不能与技能提升补贴或在岗激励补贴相加为确定现金流。招聘广告中的基础工资、绩效、实际工时和到手收入均未知。

必须同时记录现制已经保留的自主离职、劳动合同、专业安全、正常工资、机构责任、培训市场和补贴功能，不能只挑失败个案。

### B · 现制内局部修补

不建立 Aletheia 的统一基本保障或公共责任体系，在现有劳动、社保、职业培训和养老服务结构内比较以下组合：

- 离职前可以获得职业说明、模拟环境、教学材料、去标识任务记录，以及不进入服务区域的设施和流程介绍；本轮不得旁观真实照护或查阅服务档案；
- 在现有公共职业指导、培训信息、定向培训和机构推荐基础上，补足就业服务、认可培训机构、评价机构和养老服务机构之间的查询、等待、责任人和失败转介；
- 把在线预习与认可培训、技能评价和用人入口做成可查询衔接，但先核对课程版本、费用、学习记录和承认规则，不预设线上课时可以直接抵扣备案培训或岗前训练；
- 对符合条件者提供限期培训、交通或生活过渡支持，并明确由谁先垫付；
- 养老机构提供有工资的岗前训练、带教和任务分级，不用学员替代正式人员；
- 招聘与资格要求说明与具体任务风险的关系；
- 保留现有雇佣、工资、社保、补贴和公共财政结构。

复核者必须指出哪些工具已经存在、哪些需要新增、覆盖谁、成本由谁承担。不得把方案 C 换名塞进方案 B。

### C · Aletheia 候选

- 方案把“L在退出、探索、学习和求职期间仍能取得项目所称的基本保障”设为候选制度义务，而不是已经证明可交付的结果；
- 转行不产生额外公共责任债，学习不自动抵销或生成具体任务；
- 成人可以申请学习入口，但兴趣、学习、考试、证书、岗位、任务和执行权限分别成立；
- 养老机构仍以正常劳动关系、工资、人员配置、带教和安全责任承接服务，不以公共责任人员替代岗位；
- 养老照护按风险拆分观察、模拟、受监督实践和独立任务；年龄本身不替代能力证据；
- 本人可以退出培训或岗位，安全交接有限且不能无限拖延退出。

方案 C 必须沿用与 A、B 相同的时间线，列出保障篮子、取得方式、住房与医疗交付、等待和短缺，以及培训容量、带教时间、工资、公共资金、数据、申诉失败、服务连续性和最坏受影响者。无法实际交付时，不得仍把“保障连续”记为收益。

## 三、所有复核者先回答的共同问题

1. 情境卡或[上海现制基线](BASE-40-SH-CARE-2026-01_上海养老护理员现制基线.md)哪一项不准确？请区分法规、经办规则、机构记录、个人经历、研究证据与推测。
2. 每套方案保留了现制哪项有效功能，又削弱了什么？
3. 每套方案改善了谁的处境，把费用、时间、风险或照护负担转给了谁？
4. 在 T0—3个月、3—6个月、6—12个月和12—24个月，L的生活、医保、培训、收入和上岗状态分别怎样？
5. 最坏受影响者是谁：转行者、一线护理员、老年服务对象、其他求职者、机构、公共财政还是家庭？
6. 哪个可观察结果会使你放弃或缩小对某套方案的支持？
7. 方案 B 是否已经能用明显更低的成本取得方案 C 的大部分改善？
8. 哪项问题必须由另一类复核者回答，不能由你代答？
9. 在线课程在无登录、登录后、符合地方免费政策三种情况下分别能学到什么；课程记录、结业证明和技能等级证书分别由谁出具、在哪里查询、被哪个上海环节承认？
10. 对一般机构、高端/医疗化机构、派遣岗位和长护险岗位，法定雇主、证书门槛、培训费、培训期工资、社保和实际工时分别是什么？哪些只能用合同、参保记录或工资条确认？
11. 5–8K、5–6K、6–8K 或 13 薪广告中，哪些是基础工资、绩效/提成、全勤、食宿折价或其他项目？如果无法拆分，请明确登记为未知，不用区间反推到手收入。
12. 技能提升补贴、正式入职补贴和在岗激励补贴是否可以同时申请？谁申请、何时起算、跨机构和社保中断如何处理？

## 四、七类不可替代视角

原方案的五类复核者继续保留；由于目标职业会直接接触老年服务对象，另加在岗养老护理员和老年服务对象／权益视角。一个人可以兼具多种身份，但记录时必须分开其角色与利益冲突。

培训实施方和技能评价方须分别回答；同一机构兼具两种角色时，应分栏记录并披露招生、收费、评价和就业率利益。家属或权益实践者意见不等于服务对象本人经验；如果只完成权益预审，必须把服务对象本人视角登记为缺席。具有表达能力的老年人可以审阅匿名情境，但不得被要求接受新人照护。

| 复核组 | 专属问题 |
|---|---|
| 已转、正在转或放弃转行者 | 为什么必须先离职；真实收入、住房、医保和培训现金流；何时第一次知道工资、班次、排泄清洁、身体接触、夜班和情绪负担；退出培训或试岗的成本 |
| 培训与评价机构 | 零经验 40 岁成人的合规入口；线上预习、备案培训、线下实操和评价分别多久、多少钱；在线学习记录是否承认；谁承担保险和事故；退款与转班；通过率、就业率及利益冲突 |
| 养老服务机构用人方 | 无证新人能否录用；哪些任务只能观察、模拟、受监督或独立完成；工资、排班、健康证明、带教、流失与职业伤害；年龄条件是否与任务相关 |
| 在岗养老护理员 | 新人带教增加多少显性和隐性劳动；哪些能力考试看不到；夜班、身体和情绪负担；新人何时可以安全独立；机构是否用学员替代人员配置 |
| 上海社保与就业服务实践者 | 主动辞职、失业登记和失业保险金的关系；脱产学习期间养老和医保路径；户籍差异；三个月医保窗口；培训及就业补贴的申请、垫付和拒绝原因 |
| 劳动与养老服务研究人员 | 选择偏差；工资替代率；3、6、12、24 个月留任；伤害、倦怠、流失；培训就业率口径；补贴归宿；年龄、性别、户籍和学历差异 |
| 老年服务对象、家属或权益实践者 | 哪些新人任务需要本人同意；怎样保护身体、隐私、财产和关系连续性；发生恐惧、拒绝或近失事件时谁能暂停、调查和修复；家属不得自动代替能够表达的本人 |

首轮可以先用匿名情境由权益实践者复核，不要求真实老年人接受新人服务。缺少一线护理员或服务对象权益视角时，不输出职业转换安全结论。

## 五、敏感性分支

共同情境回答完成后，再分别改变一个变量：

| 分支 | 只改变的变量 | 要检查的问题 |
|---|---|---|
| H | 上海户籍／非上海户籍 | 医保、就业服务和困难支持是否不同 |
| G | 女性／男性 | 40 岁时大龄人员类别条件是否不同；不能单靠性别推出已经认定或取得支持 |
| E | 高中以下／高中或中职／专科以上 | 培训和入职补贴资格是否改变，学历是否被错误当作照护能力 |
| S | 可支撑必要生活不足一个月／三个月／六个月 | 方案是否只对有储蓄者可达 |
| W | 租房／家庭住房／自有住房 | 住房成本与退出自由怎样改变 |
| J | 直接用工／劳务派遣／居家社区服务 | 谁付工资、参保、培训、监督和修复 |
| R | 普通机构照护／长期护理保险定点服务 | 证书、记录、任务和数据要求怎样改变 |
| I | 一般机构／高端或医疗化机构 | 护理专业、年龄、身高、健康、证书和班次要求是否与具体任务相关 |
| D | 直接用工／劳务派遣或中介 | 法定雇主、工资支付、上海社保、培训和补贴责任是否发生分离 |
| K | 无证入职后机构训练／先取证再求职 | 培训费、培训期工资、待考状态和上岗授权由谁承担 |

另设 `ED` 联合资格结果分支：未申请／申请未认定／已经依法认定为就业困难人员。该结果必须在性别、户籍、连续实际失业时间、公共就业服务等条件已经分别记录后使用，不能伪装成只改变一个变量，也不能自动写入主线。

除明确标为联合资格结果的 `ED` 外，不得同时改变多个变量后仍称它们是同一个基线。

## 六、参与说明

实际邀请前必须向每位参与者提供以下说明：

> Project Aletheia 正在核对一个虚构的上海 40 岁主动离职转向养老护理员情境。我们不要求您赞同项目，也不会要求您真实辞职、停保、付费培训、招聘、录用或提供养老服务。请帮助纠正现行流程，并比较维持现制、现制内修补和 Aletheia 候选的收益、代价、最坏受影响者与停止条件。您可以拒答、撤回或更正本人的陈述；参与不影响任何就业、培训、社保、补贴或服务资格。

正式发送版本还须逐项写明：邀请主体和联系方式、为什么邀请该角色、预计时间、补偿、录音与否、匿名引用方式、资料保存地点和期限、删除办法、投诉入口、利益冲突和独立复核人。当前这些字段尚未完成，所以邀请状态保持 planned-not-sent。

## 七、最小记录格式

每条外部材料单独记录以下字段：

- 记录 ID；
- 日期与所见材料版本；
- 复核角色及利益冲突；
- 依据类型：法规、经办、机构记录、亲历、研究或推测；
- 纠正的原句或表格项；
- 支持、反驳或要求分支；
- 影响的方案：A、B、C 或共同基线；
- 谁受益、谁承担成本；
- 最坏受影响者；
- 停止或缩小条件；
- 是否允许匿名引用；
- 撤回或更正状态；
- 处理决定与回写位置。

不得收集与比较无关的身份证号、完整社保记录、病史、财务账户、精确住址或老人服务档案。培训机构不得取得招生线索，用人单位不得取得可识别转行者材料，各类复核者不得查看其他参与者的原始身份材料。

## 八、停止线

出现任一情形，本轮停止于材料准备或退回修改：

- 没有分清养老机构、居家社区、长期护理保险和医疗护理岗位；
- 零经验入门、评价、证书和上岗路径互相冲突却被写成确定事实；
- 把主动辞职者默认写成有失业保险收入，或把后置补贴写成辞职当月生活费；
- 要求参与者真实辞职、停保、付费报名、接受岗位或接触老年人；
- 缺少在岗护理员和老年服务对象／权益视角，却输出安全或服务质量结论；
- 只有家属或权益实践者材料，却声称已经取得服务对象本人体验、可接受性或关系连续性的外部复核；只有权益预审时，只能输出法律伦理问题并把本人视角登记为缺席；
- 以培训学员、公共责任任务或“试用”替代正常招聘、工资和机构人员配置；
- 未经验证即让新人独立完成身体接触、移位、喂食、清洁、用药协助或其他可能伤害服务对象的任务；
- 带教、夜班、困难对象或服务中断持续转嫁给少数现有护理员；
- 基本保障读取就业、培训成绩或公共责任记录；
- 平均转行率改善，但老年人安全、关系连续性、护理员健康、基本权利或最坏受影响者明显恶化；
- 方案 B 以显著更低成本取得方案 C 的大部分效果，却仍以理念理由扩大制度；
- 把一次上海养老护理员复核外推成劳动模块或整个项目已经验证。

## 九、当前状态

本材料已经固定匿名情境、三套方案、共同问题、七类视角、敏感性分支、最小记录和停止线，但仍缺：
