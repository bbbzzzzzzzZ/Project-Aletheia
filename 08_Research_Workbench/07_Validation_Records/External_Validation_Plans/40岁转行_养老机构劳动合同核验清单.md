# 40 岁转行养老机构劳动合同核验清单

> 本清单以普通养老机构直接用工的一线养老护理员为主线，同时要求把一般机构、高端/医疗化机构、劳务派遣/中介和长护险定点服务分开。它不把合同宣传、招聘页面或项目推测当作合同事实，也不要求提供企业后台截图。合同难以取得或只写薪资合计时，允许使用分层证据并明确保留未知项。

## 一、需要取得的材料

优先顺序如下：

1. 去标识化劳动合同或正式录用文件；
2. 若合同尚未签订，取得去标识化的录用说明、培训协议和工资说明；
3. 无法取得文件时，取得招聘方或经办部门的书面答复，并记录日期、身份和原文；
4. 个人办理时可提供去标识化的参保记录或补贴申请回执。

不得上传身份证号、完整社保账号、银行卡号、住址、联系人电话、老人服务档案或未去标识的个人信息。

## 二、逐项核对字段

| 字段 | 要核对的内容 | 不能用什么替代 |
|---|---|---|
| 用人主体 | 养老机构法定主体、实际工作地点、是否劳务派遣或中介派单 | 招聘平台发布者名称 |
| 机构分层 | 一般机构、高端/医疗化或专业化机构，护理专业、年龄、身高、健康和证书要求及其任务依据 | “高端”“包吃住”或职位标题 |
| 劳动关系 | 劳动合同、劳务协议、试用期、合同期限和解除条件 | “入职”口头说法 |
| 培训与待考 | 培训公司与养老机构的关系、收费方、培训期间是否计薪、“待考”系统和法律效力 | “培训后就能上岗”的广告语 |
| 岗位任务 | 观察、模拟、受监督实践和独立照护分别允许做什么 | 职位名称或证书名称 |
| 工资构成 | 基础工资、全勤、住宿、餐费补贴、提成、发放日期和最低保障 | “4000 起”“月入过万”等区间 |
| 工作时间 | 班次、夜班、休息、加班、待命、食宿是否影响工作时间认定 | 页面上的“包吃住” |
| 社会保险 | 缴费主体、起缴月份、缴费基数、试用期是否缴纳、换机构如何衔接 | 招聘页上的“五险一金”标签 |
| 费用与返还 | 培训费、体检费、住宿费、服装费、押金、退款和离职后的追缴 | 口头承诺 |
| 补贴关系 | 证书、连续就业六个月、申请期限、个人申请材料和补贴归属 | 把补贴直接计入首月工资 |
| 退出与交接 | 退出培训、离职、换机构、已排班任务和服务对象交接的条件与成本 | “不能随时离开”的笼统说法 |

## 三、必须向用人方或经办方追问的问题

- 待考状态对应哪个系统，能否进行任何身体接触、移位、喂食、清洁或用药协助？
- 培训期间是否建立劳动关系、是否计薪、发生事故由谁负责？
- 4000 元中哪些是合同固定项，哪些随出勤或食宿条件变化？提成按什么计算？
- 社保是否从入职当月缴纳，实际缴费单位和基数是什么？
- 从 C 机构转到 D 机构时，怎样保证社保不断档？原机构退出、新机构入库的允许间隔是多少？
- 中间转灵活就业、短暂停保或重新培训后，六个月连续就业和补贴申请是否重新计算？
- 普通机构岗位、长护险定点服务、技能提升补贴和正式入职补贴是否属于同一用工路径？分别由谁申请、何时起算？
- 招聘广告的合计薪资如何拆成基础工资、绩效/提成、全勤、食宿折价和其他项目？无法拆分时是否可以提供工资单或书面说明？

## 四、证书与路径分支

- 普通养老机构就业：是否要求证书由具体机构和任务决定，可能先入职、后培训；
- 长期护理保险服务：按长护险的服务人员资格、登记和服务记录要求另行核验；
- 证书补贴路径：连续职工社保、连续就业六个月和个人申请条件只在对应补贴规则下核验，不能当作普通养老机构就业的统一前置条件。

## 五、证据等级

- **高**：合同、工资单、参保记录、补贴回执、官方经办书面答复；
- **中**：机构正式书面说明、培训协议、去标识化办理截图；
- **低**：招聘广告、口头说明、短视频、平台评论或单个网络经验。

低等级材料只能生成待核问题，不能填入现制基线的确定字段。

## 六、当前状态

本清单是核验工具，不是合同审查意见，也不构成就业、社保或补贴建议。尚未取得合同或经办回执，当前验证状态仍为 `material-preparation / not-ready / validation_effect: none`。
