# 外部验证方案

本目录只保存尚未启动的外部验证方案，不保存验证结论。方案文件不是现实材料、参与者意见或验证记录；只有实际材料进入、参与者知情同意并留下可追溯记录后，才可以在上一级验证登记中另行记录状态。

当前首次且唯一的方案是：

- [`40岁转行_首次外部验证方案.md`](40岁转行_首次外部验证方案.md)：固定一组转行事实与现制基线，比较现制、局部修补和 Aletheia 候选三套方案，邀请转行者、培训机构、用人单位、社会保障实践者及劳动研究人员复核。

本目录未发送邀请、未招募参与者、未收集访谈、未改变任何人的就业、培训、社会保障或公共责任状态，也不产生 `validated`、`in-validation` 或任何实施授权。

出生与亲职场景不进入本目录的现实验证。它只允许[法律、伦理和匿名情境评审](../../../06_Criticism_and_Failure/Lifecycle_Walkthroughs/04_出生与亲职_人生周期内部走查.md)，并明确禁止现实制度试验。
