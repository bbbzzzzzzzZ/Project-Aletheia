# 外部验证方案

本目录只保存尚未启动的外部验证方案，不保存验证结论。方案文件不是现实材料、参与者意见或验证记录；只有实际材料进入、参与者知情同意并留下可追溯记录后，才可以在上一级验证登记中另行记录状态。

当前首次且唯一的方案材料包括：

- [`40岁转行_首次外部验证方案.md`](40岁转行_首次外部验证方案.md)：总方案与状态入口；比较现制、局部修补和 Aletheia 候选三套方案。
- [`BASE-40-SH-CARE-2026-01_上海养老护理员现制基线.md`](BASE-40-SH-CARE-2026-01_上海养老护理员现制基线.md)：固定上海市、40 岁普通企业职工主动离职后转向养老护理员的同一现制时间线，并保存官方来源与待核事实。
- [`40岁转行_上海养老护理员阶段性调查整理.md`](40岁转行_上海养老护理员阶段性调查整理.md)：把现有官方事实、单个公开样本、网络观察和 AI 分析分层，形成资格失真、劳动条件、岗位匹配与剩余真实供给不足的待检验框架。
- [`40岁转行_养老机构劳动合同核验清单.md`](40岁转行_养老机构劳动合同核验清单.md)：将合同、培训与待考、工资构成、社保起缴、提成、费用和退出条件列为当前 P0 核验字段。
- 合同核验不要求完整企业后台截图；普通养老机构就业、长护险服务和考证补贴已经拆为不同路径，招聘薪资合计宣传中的未知项须保留，不得自行拆分。
- [`../../06_Current_Round_Source_Notes/2026-09-13_上海养老护理转行现制补充确认.md`](../../06_Current_Round_Source_Notes/2026-09-13_上海养老护理转行现制补充确认.md)：记录六项最新岗位与补贴陈述，作为现金流、社保连续性和培训责任的待核线索。
- [`40岁转行_上海长护险居家与机构成本表核对.md`](40岁转行_上海长护险居家与机构成本表核对.md)：确认机构标准自 2025-09-01 起为 25/35/45，拆开两组含义不同的 40/80，并用 40、65、80 三种居家服务价格作透明算术；运营成本继续待核。
- [`40岁转行_上海长护险招聘样本表.md`](40岁转行_上海长护险招聘样本表.md)：登记十条广告、六个具名发布企业，区分同企业重复页面、服务收费与劳动报酬，并列出合同、订单、工时、社保和培训核验字段。
- [`40岁转行_上海养老护理员统一复核材料.md`](40岁转行_上海养老护理员统一复核材料.md)：向七类不可替代视角提供同一情境卡、三方案、问题、记录字段和停止线。
- [`../../06_Current_Round_Source_Notes/2026-09-14_上海养老护理入职补贴与机构岗位样本核对.md`](../../06_Current_Round_Source_Notes/2026-09-14_上海养老护理入职补贴与机构岗位样本核对.md)：将官方入职补贴办法、用户整理的技能/激励补贴图和招聘截图分层；普通机构直聘为主线，长护险、派遣和考证补贴为独立分支。
