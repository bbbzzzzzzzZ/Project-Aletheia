# 04 · Source Extractions

本目录保存从原始长对话中形成的非规范提取记录。它回答“从哪里提取了什么、哪些内容没有采用、提取结果被路由到哪里”，但不直接构成 Aletheia 的当前理论结论。

## 提取纪律

1. 区分用户直接表述、用户粘贴的既有分析、AI 回答与后续重构；
2. 把个人经验、概念解释、事实判断、规范主张和机制建议分层记录；
3. AI 给出的思想家归属、历史数字、心理解释和“普遍规律”一律视为待核查；
4. 涉及健康、诊断、家庭隐私或个人存在感的内容，不因与理论有关就复制到公开项目；
5. 只有经过当前第一原则、反例和状态审查的命题，才能复制到 `03_Aletheia_Framework/`；
6. 原始长对话仍保留在原位置，本包只保存必要的来源元数据和提取记录。
7. 用户授权继续整理不等于逐句确认 AI 的后续扩写；必须记录明确接受、明确修正、仅行动授权和未确认的区别。

## 来源标签

新增对话提取笔记统一使用 `[U]`（用户直接表述）、`[UM]`（用户区块中归属混合）、`[A]`（AI 扩写）和 `[R]`（当前项目重构）。标签只记录来源层级，不代表事实已核验或命题已被项目接受。
