# 哲学理论基础与制度推论

> 本文整理 Project Aletheia 已确认的理论层内容。它不改写已经冻结的《第一原则 v1.0》，也不把下述经验假设或制度推论写成事实证明、现实授权或可直接执行的制度。

## 一、四种命题的层级

### 1. 价值判断

Aletheia 把人理解为目的，而不是被制度、组织、市场或他人利用的材料。人会为了生存而合作、为了需求而承担责任，并且是拥有自主性的自由个体。因此，没有人应当被迫通过被管理、被束缚或被胁迫才能生存。

任何人都不应仅凭自己的私人理由，就取得使用、支配或牺牲他人存在的权力。共同体可以维护共同生存条件，可以协调合作，也可以在必要时限制伤害；但它不能把人的生存本身变成服从某个个人、组织或抽象目标的交换条件。

### 2. 事实判断

- 人的需求是流动的，会随时间、环境、身体、关系和资源条件变化；
- 人并不总能明确自己真正的需求；
- 人也不总能判断自己的需求是否合理、正确或能够实现；
- 因此，表达需求、理解需求、判断需求、实现需求和承担后果不能被压缩成同一个步骤。

事实判断描述人的处境，不自动产生某项权利、责任、公共资源或制度权限。

### 3. 经验假设

若制度只保障共同生存底线，而不统一个体需求、人生目的和发展方向，则个体更可能自愿合作，冲突更少，制度也更稳定。

这是一项可被现实经验支持、修正或推翻的假设，不是已经完成的社会科学证明。检验时必须同时观察：谁获得选择、谁承担成本、谁被遗漏、强制是否减少、合作是否真实自愿，以及错误发生后能否退出和修复。

### 4. 制度推论

制度应当以共同生存保障为底线，以个体自主为空间，以自愿合作、配合和激励为主要机制，以权利边界和程序正义为约束，以可修正性为保障。

其目标不是让所有人服从一套统一生活方式，而是使每个人不必被管理、束缚或胁迫着生存，同时能够为了共同生存而自由合作。

这只是制度方向。具体机构、资源、任务、授权、补偿和法律程序仍属于下游候选机制，不能由本段直接推出。

## 二、主体、选择与错误

弱者不必先拥有完整、稳定或专业化的主见，才拥有主体资格。任何人都应当保有：

- 选择相信谁的权力；
- 接受哪一种解释或定义的权力；
- 改变选择、质疑解释和退出关系的权力；
- 在理解风险并共同选择的范围内，承担自己选择错误的责任。

选择错误的责任不等于人格惩罚，也不等于失去基本保障、表达权、救济权或重新选择的资格。一个人可以为自己的选择承担合理后果，但不能仅凭自己的选择就获得牺牲未同意他人的权力；共同选择也必须说明共同承担的对象、风险、期限和退出条件。

强者的智慧、能力、领导力和较有说服力的意见可以被承认。自愿跟随也可以成立。但能力、声望和追随不能自动转化为永久职位、跨领域支配、替别人定义人生或控制监督、申诉和修复的权限。

## 三、共同需求与创新回流

Aletheia 以共同体的共同需求为先，但“共同需求优先”只首先保护共同生存、基本自由和公共运行所必需的条件，不等于压制个体需求发展，也不把所有个人需要都公共化。

创新可以来自两条路径：

1. 第四层外部协作与发展需求：个人或团队需要公共设备、实验空间、专业协作、资金或长期组织支持；
2. 第五层自主产生的私人便利、消费偏好或市场需求：它可能零散、偶发，甚至只是因为不愿重复劳动或想偷懒而产生。

第四层和第五层的区别不在于创新是否高级，也不在于动机是否高尚，而在于创新产生阶段是否需要外部稀缺资源的公共支持。第五层的私人或市场创新也可能后来产生广泛公共价值。

公共创新回流链如下：

```text
组织支持的发展需求，或私人便利与市场需求
→ 发明、知识、技术或组织创新
→ 被更广泛采用
→ 产生公共必要性
→ 经公共正当性程序认定
→ 回流第一层、第二层，必要时进入第三层
→ 创造者获得署名、贡献承认与期限相称的有限回馈
```

回流的方式可以包括开放知识、公共采购、公共许可、可负担供给、基础设施化或公共生产。公共化不能被理解为无偿没收创造者成果，也不能因为创新后来成为公共需求，就抹除创造者、协作者和知识来源的贡献。

公共必要性取决于创新后来承担的社会功能，不取决于它最初是否出于利他动机，也不取决于它最初属于第四层还是第五层。

## 四、劳动主体与效率回馈

劳动者不只是提供结果的执行工具，也应当是工作方式、风险、时间、评价和改进的主体。制度应积极响应劳动者对以下事项提出的改善：

- 工作方式；
- 工作分析与专业判断；
- 工作时间与恢复；
- 工作安全与责任边界；
- 评价方法与错误修正。

劳动者在有安全保障、明确边界和见证或记录条件下，应当可以尝试新的工作方法、组织安排和技术改进。制度也应让劳动者知道自己的安全责任、专业边界、第三方风险和可退出条件。

照护、清洁、维护等劳动不能因为不可见、重复或低市场价格而被低估。市场价格可以评价交换，不能决定劳动者人格。

技术和组织创新带来的效率提升与时间节约，通常来自劳动者的协作、经验、试错和社会知识，不能默认由组织单方占有。其分配应由共同体和劳动者协商，优先用于：

1. 缩短工时；
2. 增加休息和恢复时间；
3. 提高报酬；
4. 改善劳动条件；
5. 提升公共福利。

禁止把效率提升单方面转化为无偿增产、隐性加班或新的监控要求。具体分配比例和程序仍未确定。

## 五、冲突、稀缺与不可逆伤害

制度不能消除所有冲突，也不能保证所有人同时得到自己希望的结果。它至少必须公开说明：

- 目标是什么；
- 依据和证据是什么；
- 谁会受到影响；
- 代价与机会成本由谁承担；
- 有哪些替代方案；
- 是否需要补偿；
- 错误如何纠正；
- 什么时候暂停、回滚或重新决定。

在冲突无法完全消除时，应优先避免不可逆、不可退出、无法补偿和会扩大支配关系的伤害。共同体的选择不能因为是多数意见，就自动正当；强者的判断也不能因为更有能力，就自动压过弱者的基本选择权。

## 六、理论边界

本文确认的是理论层方向，不是：

- 对所有人的统一人生目的；
- 已被经验验证的人性定律；
- 具体公共服务清单；
- 具体劳动工时、积分、轮换或派工方案；
- 对创新成果的固定收益年限或分配公式；
- 现实法律、行政机关或公共共同体的授权。

《第一原则 v1.0》继续保持原有语义冻结；本文属于下游理论解释和制度推论，不得反向修改冻结文本。具体机制若要继续研究，必须另行说明其成本、受影响者、竞争方案、停止线和可逆性。
