# Module Dependency Graph

本依赖关系已经作为项目方向接受；后续压力测试可以通过正式修订调整它，但不得静默改写。

```text
第一原则 / 术语基线
  ├─→ 需求模型 ─→ 决策模型 ─→ 民主与代表
  ├─→ 权力模型 ─→ 宪制司法 ─→ 行政授权
  ├─→ 责任模型 ────────────→ 审计与救济
  └─→ 资源模型 ─→ 公共财政 ─→ 任务预算

公共信息宪政 ─→ 民主 / 行政 / 财政 / 司法
AI 治理 ─────→ 仅辅助上述模块，不取得最终授权

行政授权 + 任务预算 + 信息依据
  └─→ 劳动 / 教育 / 经济 / 政治等应用模块

所有模块 ─→ 压力测试 ─→ 反馈修正 ─→ 再授权或退出
```

## 依赖规则

1. 下游模块可以发现上游问题，但不能静默改写上游原则。
2. 专业事实判断不替代价值决定；民主决定不替代事实核查。
3. 预算、数据、算法、能力和贡献记录都不能自行生成授权。
4. 紧急权限只能由预先规定的规则触发，并自动进入复核与回收流程。
