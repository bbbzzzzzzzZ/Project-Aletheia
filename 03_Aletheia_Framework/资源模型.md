# 资源模型

## 目标

区分“谁能使用、管理、收益、转让和排除”这些不同权利，避免用“公有 / 私有”一个词掩盖资源的实际控制结构。

## 初步分类

| 资源 | 核心特征 | 第一原则约束 |
|---|---|---|
| 身体与个人时间 | 与人格和生命不可分离 | 默认由个人决定，不作为共同体财产 |
| 个人生活资料 | 支撑个人生活、隐私与发展 | 基本使用和安全不应被任意剥夺 |
| 基本保障资源 | 支撑食物、住所、基础医疗、教育、人身安全、必要服务及其他生命、尊严与基本参与条件 | 获得底线不以劳动、任务或履责表现为条件 |
| 互惠性公共运行权益 | 高于基本底线、与某项公共协作直接相关的非基本权益 | 不预设清单；与履责相关时须直接相关、相称、限期、可申诉且可恢复 |
| 自然与生态资源 | 有稀缺、不可逆和跨代影响 | 管理者不等于所有者；必须考虑外部性 |
| 公共基础设施 | 依赖持续维护、具有广泛共同利益 | 管理、使用、监督和收益权应拆分 |
| 生产与组织资源 | 支撑协作、创新和交换 | 控制权不能无限转化为对人的支配 |
| 数据 | 可复制但会影响隐私、判断和权力 | 目的限定、最小收集、可审计与删除 |
| 知识 | 可传播、累积并依赖前人成果 | 学习研究开放与贡献承认、有限回馈并存 |

## 配置用途与时间尺度

同一种资源还应按其准备回应的时间尺度和用途分账：

| 用途 | 主要目标 | 必须防止的替代 |
|---|---|---|
| 即时救济 | 停止已经发生、当前可避免的严重伤害，恢复最低生活条件 | 只宣布长期方案，却让当前伤害继续扩大 |
| 预防投入 | 阻止新的受害者出现或同类伤害反复发生 | 用不确定的未来收益掩盖当前成本与失败风险 |
| 长期能力建设 | 形成基础设施、知识、人员能力和持续维护条件 | 把受影响者永久写成被动接受者，或无限延期验收 |
| 象征与激励投入 | 表达公共承认、引导注意或鼓励某类行动 | 用可见度、荣誉或指标替代实际改善与受害者救济 |

四类用途不是固定优先级，也不必互相排斥。同一方案可以一边提供最低救济，一边阻止伤害继续发生，并逐步形成由当地使用者能够参与维护的长期能力。资源有限时，决策者必须公开为什么压缩某一部分，而不能把“救眼前的人”和“建设未来”预设为只能二选一。

象征与激励投入并非天然无效，但应额外说明：它通过何种可检验机制改善谁的处境、效果需要多久、失败时损失什么，以及同一资源还有哪些直接或预防用途。公共承认不能证明获承认者具有更高人格价值。

## 权利束

面对每类资源，不先问“它属于谁”，而依次问：

- 谁可以接近和使用？
- 谁负责维护和承担风险？
- 谁可以获得收益？
- 谁能改变用途、转让或排除他人？
- 决定会影响谁与未来多久？
- 即时救济、预防、长期能力与象征激励分别占用多少，机会成本由谁承担？
- 直接受影响者能否参与定义用途、检验效果和提出替代方案？
- 控制关系何时复核、归还或终止？

受影响者参与资源设计是一项程序资格，不是换取救济的劳动条件。当事人不愿、不能或暂时无力参与时，不因此失去基本保障；参与实施高风险任务仍须另行满足能力和授权条件。

## 保障资格与物质短缺

基本保障的规范资格不表示资源无限，也不证明任何保障篮子都能即时足额交付。发生灾害、供应中断或容量不足时，必须分别记录“权利仍成立”和“交付事实上失败”，不得用降低统计口径假装已经兑现。

负责供给的机构即使无法立即补足资源，仍须承担：公开缺口、不确定性与恢复预期；采用可质疑的公平排队或配给；保护最坏受影响者；提供替代、申诉与修复；削减非必要消耗并恢复容量。短缺本身不取消人格底线，也不自动生成个人的具体任务义务。若需启动有约束力公共责任分支，仍须完成公共必要性、机构先行责任、公平分配、本人能力、合理条件、替代、豁免、延期与申诉审查。具体保障篮子、服务标准、配给次序和地域责任保持开放。

## 基本保障与互惠性公共运行权益

食物、住所、基础医疗、教育、人身安全和必要服务属于基本保障类别。拒绝劳动、任务失职或逃避互惠责任，都不得被用来取消这些底线。

某些高于基本底线的互惠性公共运行权益，只有在与某项公共协作直接相关、限制与具体行为相称、持续时间有限、允许独立申诉且有明确恢复程序时，才可与履责状态相关。这是一个可研究的权益类别，不是已确定的清单、评分或扣减公式。

## 未决问题

- 基本保障的实物、服务和现金边界；
- 互惠性公共运行权益的范围、直接相关性、相称后果、记录期限与恢复程序；
- 稀缺公共资源的排队、抽签、专业评审与需求优先级；
- 即时救济、预防和长期能力建设的最低份额与动态调整程序；
- 象征与激励投入如何证明效果，并与直接救济公开比较机会成本；
- 个人占有、长期使用与永久所有之间的关系；
- 市场交易如何避免购买公共权力或垄断基本条件；
- 知识回馈如何追踪贡献而不建立永久收费和审查体系。
