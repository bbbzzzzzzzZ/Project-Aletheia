# 03 · Aletheia 核心框架

本目录保存项目对根问题的当前答案。它是后续制度设计的上游约束，但仍处于可评审、可修订的 `0.x` 阶段。

```text

↓
世界观与制度生成语法 ── 人—关系—社会—制度、任务生命周期与制度形成循环如何连接
↓
第一原则
├── 需求模型 ── 谁的需求、如何表达、如何成为共同需求
├── 责任模型 ── 谁对条件、判断、执行、有限互惠、影响与修复负责
├── 权力模型 ── 基本权利、事实权力与授权权限怎样区分，权限何时退出
├── 资源模型 ── 资源权利束及即时救济、预防、长期能力与象征投入如何分账
```

## 当前两套循环

```text
任务生命周期的共同入口：
需求、请求或已认定的公共必要事项
↓
分流并审查受影响者、权利、资源、风险与替代
↓
任务封套、角色与能力
↓
├─ 普通自愿任务：邀请 → 知情承诺 → 有限授权
└─ 有约束力公共责任任务：公平分配审查 → 豁免 / 延期 / 替代 / 申诉
                         → 具体任务义务认定 → 有限授权
↓
执行、监督、验收、修复、交接、关闭
↓
权限、数据与资源控制退出；既有修复责任保留

制度形成与修正：
重复、结构性、跨主体或高后果问题
↓
需求来源与合理可发现的实质受影响群体
↓
方案、事实、权利和替代比较
↓
事项适配的公共决定与有限试行
↓
多个案例或任务的反馈、申诉与独立审计
↓
继续 / 修订 / 暂停 / 补偿 / 废止
↺
```

两套循环通过规则与证据双向连接：制度规定任务如何成立、授权和申诉；任务结果与失败反向触发制度复核。它们都不是自动流程，完整规范入口只在 [`世界观与制度生成语法.md`](世界观与制度生成语法.md) 维护。

项目已接受具备现实能力的成员原则上承担有约束力但有限的互惠公共责任，但这不等于具体任务已经分配。公共必要性认定、公共组织与维护责任、一般互惠责任与具体任务义务不能自动跳转。普通自愿任务以本人知情承诺为前提；有约束力公共责任任务必须走独立分配分支，逐项满足公平、能力、合理条件、替代、豁免、延期和申诉要求。紧急例外继续单独处理。

《世界观与制度生成语法》保存目的轴、两套循环及其接口；《研究与推理方法》约束命题如何产生和修订；《第一原则》与各模型保存当前答案。方法不能替原则作价值决定，原则也不能豁免自己接受证据和反例审查。
