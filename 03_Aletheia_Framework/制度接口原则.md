# 制度接口原则

本文件所列接口方向已经由项目发起者确认；具体制度连接仍须逐项审计。

任何两个制度模块连接时，必须说明：输入、输出、新增的事实影响、授权来源、责任承担者、监督与救济、期限和退出。

## 五个优先接口

1. **宪法—民主**：民主决定做什么，宪法规定不能怎样对待人；普通多数不得取消基本主体地位。
2. **民主—行政**：行政可以发现和报告问题，但不能自行确认公共需求、扩张任务或创造永久权限。
3. **行政—财政**：先有公共任务和授权，后有预算；任务完成、失败或失效时预算应缩减或退出。
4. **信息—AI**：AI 建议必须可解释、可挑战、可替代，并由能够理解和负责的人确认。
5. **激励—平等**：奖励只能指向具体行为和有限回报，不得形成公民等级、政治特权或跨代固化。

接口审计不是一次性验收。实际运行出现新的信息垄断、预算依赖、身份锁定或退出成本时，应重新进入授权和修正循环。
