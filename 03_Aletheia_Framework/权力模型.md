# 权力模型

## 三个不能合并的概念

| 概念 | 工作定义 | 正当性含义 |
|---|---|---|
| 基本权利 | 人及受影响者不因承担任务才取得的表达、异议、申诉、请求救济、基本保障和时间自主等规范资格，并包含使其能够实际行使的程序资格 | 权利及其程序资格不由任务或机构授权产生；程序只能正当协调其行使，不能成为权利来源 |
| 事实权力 | 无论是否获得正当授权，能够显著或持续地非对称控制他人选项、规则、资源、数据、身份与资格入口、评价、议程或救济可得性的实际能力 | 事实存在不证明正当；合法、非法和尚未评价的事实权力都应被识别 |
| 授权权限 | 经可追溯正当程序，为有限任务或特定公共职能取得、可以对他人、公共规则、数据或资源产生约束性影响的制度权限 | 只能在授权封套内行使；不包括基本权利，也不等同于能力或事实控制 |

一般说服、偶然影响或平等协商不因产生结果就自动属于事实权力。反过来，数据入口、基础设施、资源依赖、分类标准、算法排序或救济入口造成的持续控制，不因没有正式头衔就可以被忽略。

## 资格、判断与权限的角色边界

| 活动 | 主要资格或角色 | 性质与边界 |
|---|---|---|
| 表述需求、请求协作 | 每个人 | 基本资格；不产生命令他人或调用公共资源的权限 |
| 表达影响、异议、监督线索与请求救济 | 合理可发现的实质受影响者 | 基本程序资格；不自动产生总体决定权、裁决权或执行权 |
| 形成共同问题、目标与取舍 | 受影响群体相称参与，由事项适配的正当程序形成决定 | 参与资格与公共决定权限必须分开；不要求全体一致，也不得让需求提出者单方决定他人负担 |
| 提供事实、风险与方案判断 | 具备相关能力者，接受同行和公众质疑 | 专业判断须可说明和复核；能力不产生目标垄断权或永久权限 |
| 作出约束性公共决定 | 获得明确授权的程序或角色 | 授权权限；不得超出事项、对象与期限 |
| 在普通自愿任务中调用资源、处理数据或执行 | 具备能力、作出知情承诺并获得相应授权者 | 授权权限；不得用一种权限夹带另一种权限 |
| 在有约束力公共责任任务中执行 | 具体任务义务经正当分配、本人具备现实能力并另获有限授权者 | 分配义务不等于授予权限；豁免、延期、替代与申诉不因授权程序而消失 |
| 监督、紧急暂停、裁决与命令救济 | 分别获得限定授权且相互独立的主体 | 都是不同授权权限；申诉者拥有请求资格，不因此拥有裁决权限 |

基本权利清单仍待完善。个人拥有请求救济和获得有效程序的资格，不表示其自然拥有暂停他人、认定事实、裁决责任或调用补偿资源的权限。

## 授权封套

每项授权权限必须写入一个完整封套。持续公共职能可以按复核周期授予，但也必须限定事项与边界：

```text
需求来源
受影响者
授权者与授权程序
有限任务或特定公共职能
目标、事项与不做什么
允许的行动、数据与资源
禁止事项
能力要求
期限与里程碑
公开与留痕义务
监督、申诉和紧急暂停
退出、交接与数据清除
失败后的修复责任
```

具体任务还须写明验收标准、地点、时间、报酬、指挥关系、第三方影响、退出条件、任务分支及实质变更再确认。普通自愿任务另须写明邀请与每名承担者的知情承诺；有约束力公共责任任务另须记录具体义务的分配依据、公平比较、能力核验、合理条件、豁免、延期、替代与申诉。封套内已说明的通常操作无需逐项重建全部程序，但实质变化、任务关闭后重启或加入新任务时，必须重新审查适用分支、确认或分配，并重新授权。

## 事实权力审计

授权审计不能只核对正式文件，还应比较实际控制：

- 谁控制身份、资格、数据、标准、排序、基础设施、资金、议程和救济入口；
- 这种控制是否显著或持续缩小他人选择，并造成难以承受的退出成本；
- 正式权限到期后，数据、关系、资源、技术依赖或标准制定能力是否仍被保留；
- 谁能够在不留下授权记录的情况下改变规则或阻止复核；
- 事实权力是否超过、规避或倒过来塑造了授权权限。

发现事实权力不等于预判其必然违法，但制度必须说明保留、拆分、公开、限制、补偿或移除它的理由。

## 防止跨域转化

财富、贡献、能力、声望、照护关系、事实控制或紧急角色不能自动购买或倒签其他领域的授权权限。尤其禁止：

- 专业能力转化为人格等级；
- 经济财富转化为额外基本政治权利；
- 贡献记录转化为永久治理资格；
- 家庭责任转化为对成员人生的所有权；
- 临时危机权限转化为常态治理权。

在普通自愿分支中，能力信息授权、联系授权、任务承诺和执行权限是四个独立步骤；前一步不得自动生成后一步。在有约束力公共责任分支中，能力信息只能形成候选范围，不能自动产生具体任务义务；公平分配决定也不能自动生成执行权限。

## 有约束力公共责任与紧急权限的独立分支

有限互惠公共责任的原则性存在已经接受，但公共必要性认定、机构维护责任、成员身份或现实能力均不自动产生某项具体任务义务。具体分配必须证明公平、能力适配、合理条件，提供替代、豁免、延期、通知、独立复核与申诉；执行还须另获有限授权。普通自愿任务不得省略邀请和承诺，有约束力任务也不得伪造承诺。

紧急权限继续作为独立例外：必须说明启动事实、必要性、最小侵害、替代方案、适用对象、豁免、期限、补偿、独立复核、自动失效与追责，不能用“紧急”绕过常态公共责任分配。

基本权利以及食物、住所、基础医疗、教育、人身安全和必要服务等基本保障，不因拒绝、失职或逃避互惠责任而成为可撤销权限。某些非基本互惠性公共运行权益可以与履责相关，但具体限制必须直接相关、相称、限期、可申诉且有明确恢复程序，不能借授权机制建立永久身份等级。

## 退出不是删除历史责任

任务关闭、授权到期、撤销或特定公共职能失去条件后，授权权限应退出或重新授权，数据和资源按封套归还或删除。退出终止相应未来角色职责和权限，但不抹除此前已经发生的伤害、修复与补偿责任或必要的安全交接。修复责任继续存在，也不表示原有指挥、数据或资源权限可以继续保留。

## 应用提示：主体社区

在以特定群体需求为优先的社区中，必须继续拆分：

- 居民与主要使用者对生活目标、可接受取舍和效果评价的参与权；
- 专业人员对工程、医疗、教育和安全事实的判断责任；
- 公共机构对基本保障、资源配置和跨区域连接的责任；
- 服务提供者在具体合同和授权内的执行权限；
- 独立主体对申诉、暂停、修复和补偿的救济权限。

任何一方都不得把其中一种资格转化为对居民生活的总体管理权。机制草案见 [`../04_Institution_Design/Shared_Mechanisms/主体社区与城市渐进可达机制.md`](../04_Institution_Design/Shared_Mechanisms/主体社区与城市渐进可达机制.md)。

## 未决问题

- 权限拆分到何种程度仍能保持行动效率？
- 基本权利及其程序资格的最低清单和正当行使程序是什么？
- 事实影响达到何种显著性、持续性和非对称程度，才应作为事实权力进入审计？
- 监督链怎样避免无限递归或同一集团控制？
- 长期基础设施如何在任务有限性下维持连续责任？
- 紧急授权的最小门槛和不可逾越边界是什么？
- 谁有权作出具体公共责任任务分配，分配、执行授权与申诉怎样保持独立？
- 互惠性公共运行权益的限制与恢复分别需要何种授权和证据？
