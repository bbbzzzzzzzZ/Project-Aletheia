# 世界观与制度生成语法（迁移入口）

> **状态：已归档。本文不再是现行定义来源。**

旧文件曾把“项目怎样看人和共同生活”与“共同事项怎样形成任务或规则”放在同一篇文档里。即使文字声明流程不是自动因果，这种结构仍容易让人的困惑、痛苦或需要一出现就被程序语言接管。

现行内容已经拆为两个相互区分的入口：

- [`世界观.md`](世界观.md)：用普通语言说明人、关系、社会与制度的位置，并保留倾听、自主行动、关系调整、自愿合作和不制度化的空间；
- [`制度生成语法.md`](制度生成语法.md)：只处理已经独立越过共同协调入口门槛的事项，说明任务或规则怎样有限成立、复核和退出。

两者之间没有默认箭头。人的经验不因被表达就成为候选公共事项；候选事项也不自动成为任务、个人义务或执行权限。

本路径仅为旧链接和历史记录提供迁移说明，不保存现行流程，不应被根导航、框架摘要或检索系统当作当前基线。旧版内容的采用背景仍可在 [`../DECISION_LOG.md`](../DECISION_LOG.md) 的 `D-008`、`D-016` 与 [`../CHANGELOG.md`](../CHANGELOG.md) 的历史版本记录中追溯。
