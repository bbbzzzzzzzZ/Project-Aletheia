# 责任模型

## 定义

责任是对请求、承诺、角色、判断、决定、授权、行动和影响建立可追溯归属。责任不是人格惩罚、服从要求或权力奖章，也不会自动生成授权权限。

必须先区分：

- **面向未来的职责或义务**：说明谁在什么条件、范围和期限内应当说明、判断、决定、执行、监督或维护；
- **影响发生后的问责与修复责任**：说明谁应停止扩大伤害、公开理由、纠正、恢复条件、补偿或承担其他相称后果。

退出一项未来角色，不抹除退出前已经产生的伤害及其停止、修复或补偿责任；反过来，存在修复责任也不能无限延长原任务权限。

## 责任的来源

| 来源 | 可能产生什么责任 | 不产生什么 |
|---|---|---|
| 提出协作请求 | 说明需求、条件、成本与已知影响 | 独自完成一切的义务 |
| 明确承诺角色 | 在约定范围内完成、报告与退出交接 | 对组织或对象的永久服从 |
| 接受特定公共职能 | 在事项、权限和复核周期内履行组织、维护、公开与交接职责 | 机构或任职者对该领域的永久所有权 |
| 专业事实判断 | 说明依据、不确定性、利益冲突与错误修正 | 决定所有人的最终目标 |
| 共同决定 | 对是否形成任务、优先级、可接受风险与公共资源配置负责 | 把多数选择等同为所有人同意 |
| 授予权限 | 说明对象、事项、范围、期限、监督和撤回 | 把任务存在等同为执行者自然拥有权力 |
| 获得执行权限 | 按边界使用资源、留痕、报告风险 | 对权限对象的所有权 |
| 监督与裁决 | 接受证据、说明结论、保护申诉 | 免于被监督 |
| 造成实际影响 | 停止扩大伤害、修复与学习 | 取消基本人格与生存资格 |
| 共同条件的受益、依赖或成员关系 | 为具备现实能力的成员形成有限互惠公共责任的一般依据，并提出公共必要性、机构维护和公平分担问题 | 自动指定承担者、任务、时间或以成员身份无限征用 |

## 公共责任的四个判断

| 层次 | 核心判断 | 不能自动推出什么 |
|---|---|---|
| 公共必要性认定 | 某项共同条件或服务是否必须维护，最低服务、替代方案、可接受降级和资源机会成本是什么 | 唯一组织方式、特定机构所有权或个人义务 |
| 公共组织与维护责任 | 经正当决定后，哪些机构或角色负责融资、设计、招募、采购、储备、维护、监督、救济与连续性 | 把组织失败、短缺和待命负担静默下沉给一线人员、家庭或某类成员 |
| 有限互惠公共责任 | 具备现实能力的成员原则上是否应公平分担公共必要条件的维持 | 具体任务、统一工时、永久待命或能力越高责任越无限 |
| 具体公共责任任务义务 | 某一成员在某一时间是否须承担某项有约束力任务 | 仅凭必要性、共同依赖、受益、成员身份、能力登记或机构方便就认定已经成立 |

项目已接受有限互惠公共责任的一般原则；其余判断仍须依次单独成立，不能构成自动因果链。具体任务义务至少必须同时说明：有效的公共必要性、机构已履行的组织与维护责任、公平分配、本人相关现实能力、合理任务条件、替代、豁免、延期、总负担、补偿、期限、独立复核与申诉。

## 同一事件中的多条责任线

需求出现后，不能仅凭“谁有需求”直接确定责任。应分别识别需求体验者、提议者、局面创设者、直接受益者、直接负担者、第三方受影响者、执行者、决定与授权者。同一主体可以处于多个位置，但不同责任不能互相抵销。

| 关系位置 | 可能形成的责任或资格 | 不能推出什么 |
|---|---|---|
| 提出协作请求者 | 说明条件、成本、已知风险和预期影响；履行约定回报 | 命令特定他人满足需求 |
| 局面或依赖创设者 | 对可预见且由其行为造成的依赖、风险或持续成本承担预防、保障与修复 | 对他人的所有权或无限责任 |
| 直接受益者 | 准确承认贡献来源，履行约定补偿，不把他人劳动自然化为身份义务 | 强制性的情感感谢、人格负债或服从 |
| 执行者或帮助者 | 普通任务中自主同意或拒绝；公共责任任务中陈述能力、负担和正当理由；执行后对过程及独立伤害负责 | 以“只是执行”为由免责，或因承担、拒绝、延期、替代任务被固定为较高或较低身份 |
| 决策者与授权者 | 对目标、方案、风险接受和权限边界负责 | 把责任全部转移给一线执行者 |
| 第三方影响的造成者 | 按因果关系、控制力、获益、可预见性和可避免性承担停止、说明、修复或补偿 | 以双边同意、贡献承认或“只是执行”为由免除第三方责任 |
| 第三方受影响者 | 取得知情、异议、申诉、救济和补偿请求资格；根据实质影响参与共同方案 | 因受到影响就自动承担任务，或自动拥有总体决定权和专业执行权 |

项目采用可以制度化的最低表述：承认贡献来源、遵守约定回报、不得抹除承担者的劳动和主体性。是否要求某种内在情感上的“感谢”，属于伦理争议，当前不写成可强制义务。

第三方受影响者不是因为“受到影响”就成为责任主体；其首先拥有知情、异议、救济和补偿请求资格，且不因未参与双边协作而失去反对伤害的资格。

局面创设责任应结合控制力、可预见性、受益程度、对方是否能够同意以及是否存在替代方案判断。它不能从单一因果关系直接推出无限责任，也不能把所有生育、照护或帮助行为概括成同一种动机。

双边关系中的贡献承认也不决定事件的整体道德性质。某人付出成本，不表示其行为正当；某人接受帮助，不取消第三方的异议与追责资格。

## 需求—责任—权限边界

```text
主体感受到需求
→ 产生表达、解释、请求和自主行动资格

请求协作、创设局面、作出承诺或造成影响
→ 分别产生说明、成本、过程、影响和修复责任

具备现实能力的共同体成员
→ 原则上承担有约束力但有限的互惠公共责任
→ 不自动指定具体任务

有限任务或特定公共职能成立 + 责任主体明确 + 能力适配 + 正当授权
→ 产生相应的有限授权权限

任务结束、撤销、授权到期或公共职能失去条件
→ 授权权限退出或重新授权；未完成的修复责任继续存在
```

因此：

```text
需求 ≠ 他人的自动义务
受益 ≠ 对帮助者的服从
承认贡献 ≠ 赞同行为的整体道德性质
承担责任 ≠ 获得授权权限或支配权
需求来自他人 ≠ 执行者失去独立道德责任
```

## 一项任务的责任矩阵

```text
需求责任：谁提出或确认问题？
专业事实判断责任：谁评估事实、风险和方案？
共同决策责任：谁决定是否形成任务、优先级与可接受风险？
授权责任：谁向特定主体授予何种范围与期限的权限？
执行责任：谁完成具体行动？
监督责任：谁检查边界与结果？
修复责任：失败或伤害后谁停止、补偿与改进？
```

角色可以重叠，但重叠越多，越需要独立复核。

## 自愿承诺、公共责任分配、实质变更与例外

### 普通自愿任务

普通任务只能在任务封套明确、能力匹配完成、每名承担者收到邀请并作出知情承诺后，为其授予执行权限。能力登记、匹配、联系和任务承诺是不同步骤。

### 有约束力公共责任任务

有限互惠公共责任并不依赖每项任务的自愿承诺，但具体任务义务必须经独立分配程序成立。程序须逐项确认：

- 公共必要性仍有效，机构已经履行组织、雇佣、培训、工具、储备、替代与维护责任；
- 分配公平并比较总负担、既有承担、风险、时间、地域与可替代者；
- 本人具有当下、相关、可复核的现实能力，且任务条件在安全、时间、训练、工具、支持、补偿和恢复方面合理；
- 健康、照护、年龄、能力、心理健康、创伤、安全、隐私及其他相称理由可以进入豁免、延期或替代；
- 本人获得可理解通知、陈述理由、独立复核和申诉，且不以取消基本保障迫使执行。

具体任务义务成立后，仍须另行授予执行所需的有限权限。义务不是权限，分配决定也不是无限指挥权。

当事人无法独立理解或确认时，应先提供支持性决定条件；确需替代判断，只能限定在保护、照护或服务所必需的最小事项与期限，披露利益冲突并接受独立复核。代理不能虚构普通劳动承诺、放弃当事人的基本权利，或把被照护者自动指定为任务承担者。

封套内已经说明的通常操作无需逐项重建程序。目标、工作量、风险、地点、时间、报酬、资源、数据用途、指挥关系、第三方影响、退出条件或权限发生实质变化，任务关闭后重启，或承担者加入另一个任务时，原有依据不能自动延伸。应重新说明变更并由受影响者复核；普通自愿任务由承担者再次确认；有约束力公共责任任务重做公共必要性、机构先行责任、公平分配、现实能力、合理条件、正当理由、豁免、延期、替代与申诉审查；两者都须由授权程序重新授权。

有约束力公共责任任务不能伪装成普通任务承诺；紧急例外也不能伪装成常态公共责任分配。紧急例外的启动事实、必要性、最小侵害、替代、豁免、补偿、期限、复核、自动失效和追责都要单独成立。

## 责任边界

- 只对可说明的范围负责，不能用模糊“集体责任”无限扩张。
- 区分故意、疏忽、合理错误、不可预见事件和系统性失败。
- 追责针对行为、权限和修复，不以饥饿、无家可归或社会死亡为工具。
- 食物、住所、基础医疗、教育、人身安全、必要服务及其他基本权利不因拒绝劳动、失职或逃避互惠责任而取消。
- 拒绝单项任务、提出异议、申诉或使用正当豁免，不等于逃避责任。只有具备现实能力者在多种合理分担方式可用且正当理由已经审查后，仍长期、无正当理由拒绝任何合理分担，才可讨论逃避互惠责任；记录和批评只针对具体行为，不固定人格。
- 某些非基本互惠性公共运行权益若与履责相关，必须证明直接相关、相称、限期、可申诉和可恢复；具体清单与后果不在本模型中预定。
- 责任记录应最小化、可申诉、有用途限制和必要的失效规则。
- 退出终止相应未来角色职责和权限，但保留退出前已经发生的修复责任及必要的安全交接；交接必须限定对象、最小范围、期限、替代安排和独立申诉，不得因机构未培养替补而无限延期。修复责任也不能借机维持原有数据、资源或指挥权限。

## 未决问题

- 不可预见影响的责任阈值；
- 多主体因果链中的责任分配；
- 历史不正义与跨代修复；
- 有限互惠公共责任的成员边界、总负担与跨地域、跨代适用范围；
- 具体公共责任任务义务的分配、豁免、延期、替代、补偿、期限与申诉程序；
- 长期无正当理由拒绝任何合理分担的证据门槛，以及如何排除制度不公与隐性障碍；
- 互惠性公共运行权益的范围、直接相关性、相称后果、记录期限与恢复程序；
- 公共必要性认定与机构维护责任分别由何种程序、证据和主体承担；
- 如何判断一次变更已达到需要重新承诺与授权的“实质”程度；
- 无人愿意承担关键任务时，如何保持责任正当性。
