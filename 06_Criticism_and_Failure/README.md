## 应用层压力测试

- [`制度压力测试协议.md`](制度压力测试协议.md)：统一记录现行基线、旧制度有效功能、竞争方案、收益与恶化、常态和转换成本、支撑条件、可选验证方式、风险门槛、停止与回滚；它不是实施路线。
- [`劳动任务系统压力测试.md`](劳动任务系统压力测试.md)：把旧劳动经济对话中的反例转成可证伪案例、通过边界和立即停止条件，不把设想当作现行机制。
- [`道德外包、定义权与退出成本压力测试.md`](道德外包、定义权与退出成本压力测试.md)：用假设情境检查需求成本外包后的污名、资源与定义权的自我复制、退出成本转嫁、过去自愿被偷换成未来授权，以及善意代言让当事人消失。
- [`基本保障、有限公共责任与关键服务连续性压力测试.md`](基本保障、有限公共责任与关键服务连续性压力测试.md)：检验保障条件化、机构责任外包、任务分支混线、公平分配、拒绝认定、权益关联、任务封套扩张、安全交接和物质供给失败。

## 风险记录格式

每项风险应记录：触发条件、作用机制、早期信号、受影响者、可逆性、预防、应急响应、停止规则、未解决问题和证据。
