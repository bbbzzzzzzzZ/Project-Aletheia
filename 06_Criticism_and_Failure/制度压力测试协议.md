# 制度压力测试协议

本协议的原有检查维度、首批场景和输出要求已经由项目发起者确认；本轮新增的制度工程比较卡、可选验证方式与风险门槛来自外部反馈后的研究修订，仍待作者、实践者和受影响者复核。测试结论必须由后续实际材料与演练产生。

本协议不是实施路线，也不证明 Project Aletheia 已经优于现行制度。它只规定：候选机制若要从文字走查进入现实研究，至少要交代哪些比较、成本、依赖、停止与回滚条件。

## 一、原有压力维度

每个场景继续依次检查：

1. 权力：谁获得了新增事实控制或授权权限？
2. 信息：什么被公开、保密、遗漏或由算法解释？
3. 资源：谁获得、失去或被迫承担机会成本？
4. 责任：错误、违法、决策、执行和修复责任如何分账？
5. 时间：权限与负担持续多久，怎样自动终止？
6. 异化：临时工具是否变成永久机构、身份等级或自我维持目的？

首批场景：战争、AI 失控、经济危机、贡献评分异化、多数民主伤害少数。每次测试必须同时记录通过条件、失败条件、停止线、受影响者复核和待补证据。

## 二、制度工程比较卡

每一项候选机制进入现实比较前，须建立一张范围明确的比较卡。没有地域、时期、机构、服务对象或现行规则边界时，只能登记为研究问题，不能宣称“新制度优于旧制度”。

| 比较字段 | 必须回答什么 |
|---|---|
| 1. 场景与现行基线 | 当前是谁、依据什么规则、用哪些资源完成同一功能；数据覆盖什么地域、时期和人群 |
| 2. 旧制度有效功能 | 现行安排已经提供哪些协调、专业安全、服务连续、保险、责任追踪或救济功能；哪些功能不可在转换中丢失 |
| 3. 具体失败与因果假设 | 要解决的到底是哪项可观察失败；为什么认为候选改变会影响它；什么事实会推翻该解释 |
| 4. 竞争方案 | 至少比较候选机制、较小幅度的局部修补和维持现状；不得只用理想方案对比现制最坏个案 |
| 5. 预计改善与可能恶化 | 哪些人、哪些结果预计改善；哪些效率、安全、关系、自由或连续性可能变差；何种结果表示不优于现行安排 |
| 6. 常态与转换成本 | 分开记录日常运行、法律调整、培训、数据迁移、双轨运行、监督申诉、回滚准备、旧机构退出和机会成本 |
| 7. 资源与承担分布 | 资金、人员、时间、照护、数据、设施和专业能力从哪里来；成本是否转给家庭、一线人员、其他地区、未来使用者或退出者 |
| 8. 支撑条件 | 需要哪些合法权限、预算、培训、专业标准、独立监督、申诉、备用服务、证据保全和修复能力 |
| 9. 阶段、停止与回滚 | 当前只允许材料回溯、桌面推演、影子记录还是低风险试点；进入、暂停、退出、恢复原服务、补偿和复核条件分别是什么 |

比较结果必须写成可被推翻的命题：

> 在边界条件 X 下，候选机制预计改善 Y，但可能恶化 Z；若出现结果 F，就不应进入风险更高、影响更真实的验证方式或任何现实干预，而应返回现行安排、局部修补方案及上游定义重审。

## 三、可选验证方式与风险门槛

以下是按风险和问题选择的验证方式，不是依次实施的社会转型阶段，也不预设固定行业、机构、数量、时长或扩张顺序。方式可以组合、重复、跳过或因停止线而终止；凡涉及现实参与或影响真实服务，独立复核都应贯穿准备、运行和结束，而不是最后才出现。

- **A · 现行材料回溯。** 固定被比较的现实流程、版本、时间和适用人群，记录旧制度已经解决的功能及其失败；资料不足时停止在此。
- **B · 桌面推演。** 用明确假设比较多套方案、最坏受影响者、资源约束和失败链；推演通过只说明可以继续准备证据。
- **C · 影子记录。** 在不改变真实服务、临床指挥、照护关系或基础设施控制的前提下，测试分类与记录是否可行；不得把影子输出用于派工、授权、处罚或取消保障。
- **D · 有限低风险试点。** 只有合法权限、专业安全、知情参与、独立申诉、备用服务、停止与回滚均成立时才可提出；高风险核心任务不得因内部走查顺利而直接进入现实干预。
- **E · 独立复核。** 对任何涉及现实材料、参与者或服务影响的方式，逐组检查受益、受损、退出、未满足需要、近失事件、成本转移和事实权力残留；结果可以是缩小、暂停、回滚或不再推进。

不是每个机制都需要使用全部方式。现实风险越高，越不能跳过合法权限、专业安全、知情参与、备用服务和独立复核；任何信息不足、停止线或更小替代方案，都可以结束该候选路径。

## 四、共同停止与回滚底线

- 没有具体的现行基线，不得宣称候选制度更好；
- 未说明旧制度有效功能由谁接替，不得进入现实试点；
- 未说明转换成本、资源来源和受损分布，不得把价值赞同写成实施承诺；
- 没有合法权限、专业安全、独立申诉、备用服务和回滚能力，不得进行现实干预；
- 医疗、长期照护、消防、能源等高风险服务不得从文字走查直接进入现场试验；
- 平均指标改善但最坏受影响者、基本权利、服务安全或承担者负担恶化时，应停止而不是扩张；
- 停止试验不得等于停止基本服务；须保存证据、接续服务、退出权限并修复已发生损害；
- 一个场景成立不得外推为整个模块或整套社会制度成立。

## 五、每次测试的输出

每次测试至少保存：被比较版本、现实基线来源、竞争方案、预计改善与恶化、资源和成本分布、受影响者意见、事实权力变化、进入门槛、停止线、回滚记录、尚缺证据和下一次复核日期。

三份现有五机制走查仍是内部假设材料，不构成现实比较：

- [长期照护](Mechanism_Walkthroughs/长期照护_五机制内部走查.md)；
