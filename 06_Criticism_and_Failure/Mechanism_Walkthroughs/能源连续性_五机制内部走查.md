# 能源连续性：五个候选机制内部走查

> **内部假设走查｜不对应真实电网或事故｜不提供工程操作指令**  
> 本文只检查公共最低、专业任务、紧急权限、跨区支援和透明降级能否被分开。任何工程、安全、法律或容量条件都须由现实专业与受影响者材料核验。

## 一、场景输入与需要拆开的需求

假设严重天气导致某区域多个关键节点故障，医院、供水、照护机构、家庭生命支持设备、通信和一般居民用电受到不同程度影响。故障范围、恢复时间和备件情况尚不完全清楚，通信间歇中断。

常态核心团队、已承诺待命者和跨区支援已经部分启动，但事件可能超过既有容量。瓶颈可能来自人员、设备、备件、燃料、道路、网络或现场安全，不能预设“多派人”即可解决。算法、告警或运营商声明不能自动宣布紧急状态。

| 需要或主张 | 暂定归属与本步结论 |
|---|---|
| 生命安全和必要公共功能的最低能源连续 | 公共需求主张，具体范围待认定 |
| 运营者维持收入、声誉和原服务量 | 组织目标，不自动等于公共最低 |
| 家庭保持全部正常用电 | 同时包含公共最低与私人偏好，须拆分 |
| 医院、供水、照护、通信和家庭生命支持负载 | 按不行动后果分别审查 |
| 维修和调度人员的安全、休息与恢复 | 个人需要，也是任务安全条件 |

### 转型验证前置卡（尚未完成）

- **现实基线：** 核对具体运营规程、关键负载、互助协议、备件与燃料、疲劳、停电后果、法定紧急权限和事故调查；
- **不可丢失功能：** 秒级安全控制、专业隔离与维修、最低负载连续、跨区协调和责任追踪；
- **竞争方案：** 比较改善现有储备与互助、局部流程修补、候选五机制和维持现状，同时计入环境与区域成本；
- **当前允许的验证方式：** 桌面演练或不控制真实设备的影子日志；不得直接操作电网、改变负载排序或扩大数据权限；
- **停止与回滚：** 安全、最低供给、支援地区覆盖、数据边界或事实控制恶化时停止；真实运行继续服从现有合法专业体系。

## 二、角色与利益冲突

| 角色 | 正当关切 | 需要防止的冲突或事实权力 |
|---|---|---|
| 居民与关键服务使用者 | 最低安全、信息、救济和恢复 | 信息与表达能力不均，最受影响者被平均数遮蔽 |
| 能源运营者 | 专业运行、维修、数据和安全 | 以基础设施与数据控制形成事实治理权 |
| 公共决定与紧急授权主体 | 确定公共优先和临时权限 | 以紧急持续扩权或替运营者免责 |
| 医疗、供水、照护和通信机构 | 说明关键依赖和最低负载 | 每个机构都把自身列为最高优先 |
| 维修与调度人员 | 安全执行、留痕、停止越权指令 | 恢复压力侵蚀疲劳与安全边界 |
| 支援地区和机构 | 提供人员、设备与备件 | 支援损害本地最低覆盖 |
| 私人供应商 | 履行合同、供应设备与技术 | 危机获利、数据控制和长期依赖 |
| 独立调查者 | 审查权限、损害、事故和修复 | 依赖运营者提供唯一证据 |

## 三、三类制度输出

### 公共决定

记录生命安全和必要公共功能的最低能源范围、暂定负载优先、共同资源、承接结构、透明降级、补偿、申诉和复核。它不点名维修人员，也不授予线路、控制系统、住户数据或强制进入权限。

### 具体责任分配

分别记录运营者、公共协调主体、合同供应商和支援网络的组织职责；再从已接受岗位、排班、待命和互助承诺中形成有限任务。普通成员只能在另行满足全部条件时考虑低风险辅助事项，不能承担高压、带电或调度控制任务。

### 执行授权

按具体设施、线路、区域、时段和任务，限定隔离、切换、现场进入、数据、设备和资源权限；紧急权限须有独立来源、最小范围、实时记录、自动失效和事后审查。

公共认定的“接受／否定／延期补证”仍不同于上述三类制度输出。暂时接受关键负载优先，也不等于某名工程人员已经有任务或权限。

## 四、五个机制依次走查

### 机制一：公共必要性认定与另行机构承接

候选认定对象是“维持生命安全和必要公共功能的最低能源能力及安全恢复”，不是全区域立即恢复正常消费。

- **接受**：限期确认医疗、供水、必要照护、危险温度下基本避险、家庭生命支持设备和最低通信等候选最低范围；具体项目仍须现实证据核验。
- **否定**：商业收入、付费等级、政治声誉或运营者原服务量不能单独决定公共优先；否定相应优先主张不取消最低安全保护。
- **延期补证**：事实不完全时采用限期临时决定，公开不确定性、暂定顺序、补证责任和复核时间。

承接形式另行比较现有运营者、跨运营者网络、公共应急协调、限期修复项目和受约束外部供应。运营者可以提供专业事实并执行，但不能同时单方定义公共最低、宣布紧急、分配全部成本并最终审查自己。

**内部结果：** 可形成临时公共决定和承接比较；最低能源范围、优先顺序和外部成本仍为信息不足。

**停止线：** 把运营者等同公众；按收入、声望或付费等级确定最低保护；认定机关自动获得工程执行权；没有复核日期的长期紧急承接。

### 机制二：公共任务定义与任务封套

至少拆成：故障定位与隔离；高风险现场检查与维修；关键负载排序和受控降级；移动电源、燃料、备件和交通物流；居民信息、避险和必要转介；离线记录、恢复核对和独立事故审查。

每个封套写明资格、地点、风险、最长持续、停止条件、拟申请的设备、线路、数据和资源权限种类，以及不得申请的收费、征收、长期土地使用、普遍监控和无关数据范围。是否允许相应控制由机制四另行授权。即时现场安全判断与公共负载优先决定必须分开。区域、危险等级、数据用途或强制进入范围变化时重新审查。

若瓶颈是备件、燃料、道路或网络，人力任务应退回资源和方案环节，而不是继续增加人员。

**内部结果：** 可以形成多种有限任务和“非人力瓶颈”的返回路径；工程字段和安全条件仍为信息不足。

**停止线：** 笼统写“恢复供电”；任务夹带人员或广泛控制权；人员数量被当作所有瓶颈答案；安全、对象、区域或数据变化后沿用旧封套。

### 机制三：具体承担与公平分配

候选顺序是：

1. 激活明确岗位、排班和条件性待命承诺；
2. 核验当下能力、团队条件、疲劳、设备和现场安全；
3. 请求已约定跨区互助并检查支援地最低覆盖；
4. 发出普通自愿邀请；
5. 调整非关键任务、负载和恢复顺序；
6. 只对剩余、可以安全拆分的事项审查有限公共责任个案或独立紧急例外。

高压维修、调度控制和专业判断只能由具备当前资格、团队条件并另获具体授权的人承担。能力登记、旧资格、退休身份、所在地和日历空白都不形成待命或执行义务。一般公众或无资格者不得承担高风险专业任务；对于具备当前资格但未预先承诺的人，能否在全部个案条件另行成立后进入有限公共责任候选，本走查不作采用或排除决定，须退回上游审查。

**内部结果：** 岗位、待命和跨区互助路径可继续准备外部验证；高风险任务向一般公众或无资格者分配触发停止；合格但未预先承诺者是否可能进入任何有约束力个案，退回上游审查。

**停止线：** 资格或位置自动征召；无资格者进入高风险现场；支援地最低服务未检查；安全停止、疲劳和申诉因恢复速度被取消；能力信息被当作待命名册。

### 机制四：最小执行授权、变更与退出

权限须限定具体线路、设施、区域、时段，允许的隔离、切换、现场进入、数据访问和资源调用，以及不可跨越的专业安全和基本权利底线。只有既有预授权或独立紧急授权已经成立时，秒级调度才可能临时集中控制；公共优先、证据、投诉、外部审计和事后定责仍须保持功能分离。

不得自动附带永久调价、一般征收、长期土地控制、普遍进入私人空间、完整居民档案或对未承诺人员的一般调度权。通信中断时可以使用最小离线记录，恢复后须核对版本、解释缺失、限制访问并按期限处理。扩大区域、延长时间、改变风险、强制进入或增加数据用途属于实质变化。

**内部结果：** 任务级和紧急最小授权可以形成候选接口；强制进入、负载控制、离线数据和法定授权仍为信息不足。

**停止线：** 运营者或算法自行扩大权限；工程资格自动生成控制权；紧急权限与事故无关或危机后仍保留；同一控制网络垄断信息、预算、执行、投诉和事故定责。

### 机制五：关键服务连续性、降级与紧急压缩

候选组合包括：稳定核心调度和维修团队；条件明确的待命与恢复；跨区互助、移动电源和关键备件；关键负载优先、透明轮流降级和必要转介；对依赖电力维持生命与基本安全者提供替代服务；公开未满足需要、预计恢复、不确定性和申诉；紧急协调权限自动到期并外部审计。

公平不等于所有地区停电时长机械相同。如果平均轮换会使医院、供水或生命支持设备失效，应按后果调整并公开理由，同时防止财富、声望和政治关系成为隐性优先级。

容量告警或算法只能提示风险，不能自动宣布紧急、切换关键负载、派工或延长权限。慢性维护不足和备件欠账不能通过连续宣布紧急而外包给一线人员。

**内部结果：** 核心团队、互助、透明降级和严格紧急的组合可继续准备外部验证；最低负载、公平排序和紧急终止仍为信息不足。

**停止线：** 隐藏停电和最坏受影响者；负载优先按财富或政治关系；慢性欠投资变成个人紧急义务；支援掏空支援地；疲劳、交通、风险和恢复不计入负担；紧急权限不退出。

## 五、反例检查

| 反例 | 应当输出 |
|---|---|
| 更多人员无法解决备件、燃料、道路或网络中断 | 退回资源与方案环节，不继续派人 |
| 居民自愿维修或接电 | 参与意愿不替代资格、团队条件和授权；触发安全停止 |
| 平均停电时间相同反而伤害生命支持用户 | 重新比较后果与最低保护；公平不等于机械平均 |
| 秒级调度无法逐步审批 | 可以使用预先限定或紧急最小权限，但须自动失效并事后独立复核 |
| 完全公开设施细节产生安全风险 | 分层公开标准、理由、影响和结果，不公开可被滥用的脆弱细节 |
| 跨区支援使支援地跌破最低容量 | 停止或缩小支援，重新比较区域伤害 |
| 备用发电降低即时风险却增加污染和长期依赖 | 把外部成本和替代方案返回公共决定与资源比较 |

## 六、需要的现实证据与参与

- 实际网络拓扑、故障类型、失效链、备件和恢复路径；
- 医疗、供水、照护、通信和家庭生命支持设备的真实依赖；
- 不同停电后果、最坏受影响者和未被现有数据看见的需要；
- 常态人员、轮换、待命、疲劳、事故和恢复记录；
- 跨区互助协议、支援容量和支援地风险；
- 关键负载排序的工程、权利和公平依据；
- 公众是否实际接受投资、费率、税费、备用容量或透明降级的代价，以及运营者是否把成本外部化给困难地区和未来维护；
- 紧急负载控制、现场进入、资源调用和数据访问的现实法律边界；
- 安全保密与公众可解释性的分层方法；
- 居民、生命支持用户、医疗和照护机构、维修与调度人员、支援地区、工程安全、环境、公平和法律实践者复核。

## 七、走查结论

本场景能够区分公共最低、运营者利益、专业任务、低风险辅助、紧急权限和连续性降级，也暴露出“人员不足”可能是错误入口。

它没有形成一般公众参与高风险能源维修的结论。高风险维修要求当下资格、团队条件和另行授权；一般公众或无资格者不得进入。具备当前资格但未预先承诺的人，能否在全部个案条件另行成立后进入有限公共责任候选，继续保持开放。即时重大危险需要独立紧急程序，不能由容量状态或算法自动触发。

主要未决问题是：最低能源范围和关键负载排序；秒级集中控制与独立复核；强制进入与资源调用边界；安全保密与公众解释；跨区支援、透明降级和损害补偿；断网记录与事后核对。

**总体内部结果：** 专业角色、承诺储备、跨区互助与透明降级“可继续准备外部验证”；一般公众高风险派工和算法自动紧急“触发停止”；最低负载、公平排序及紧急法定边界“信息不足”。`validation_effect: none`。
