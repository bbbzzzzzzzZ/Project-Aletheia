# 长期照护：五个候选机制内部走查

> **内部假设走查｜不描述真实照护机构｜不是现实验证**  
> 本文只检查五个候选机制能否阻止“照护缺人，所以直接让家庭、熟悉者或有能力者补位”的跳跃。它不定义照护标准、专业范围或现实责任。

## 一、场景输入与需要先拆开的需求

假设某地区服务机构报告持续人员流失，部分长期照护对象可能面临最低照护中断。服务同时包括专业高风险任务、持续进入身体或住所的关系型任务，以及可拆分的低风险辅助任务。部分服务对象依赖熟悉团队形成沟通、信任和生活知识连续性；突然换人可能造成伤害。

一名核心照护者因疲劳和自身照护责任申请退出，机构没有准备充分替补。不同家庭的资源和关系差异很大，不能预设家庭成员免费补位。当前不是灾害性紧急状态；即时重大生命危险须另启独立紧急例外。

| 需要或主张 | 暂定归属与本步结论 |
|---|---|
| 最低安全照护与必要的关系连续能力 | 公共需求主张，仍须认定最低范围 |
| 机构排班、培训、预算和人员缺口 | 组织需求与机构先行责任，不自动变成成员义务 |
| 服务对象对生活方式、身体接触、空间和人员的表达 | 本人需要与基本程序资格 |
| 照护者休息、恢复和退出 | 个人需要，也是任务安全条件 |
| 指定某一熟悉人员永久服务 | 不自动属于公共最低范围 |

本文不知道：现实最低照护标准、专业与辅助任务边界、服务对象对关系连续性的不同理解、替补和培训容量、支持性决定规则、家庭成本分布和实际伤害数据。

### 转型验证前置卡（尚未完成）

- **现实基线：** 记录公共资金、家庭无偿照护、人员流失、工资与工时、未满足需要、关系连续、投诉、伤害和退出；
- **不可丢失功能：** 最低安全照护、熟悉关系与隐性知识、本人参与、专业边界和持续救济；
- **竞争方案：** 比较改善正常岗位与培训、调整现有服务、团队连续方案、候选五机制和维持现状；
- **当前允许的验证方式：** 材料回溯、共同定义问题与影子记录；不得中断现有照护、改变身体接触或强迫家庭补位；
- **停止与回滚：** 服务对象拒绝、照护者急性安全风险、未满足需要增加或家庭成本被隐藏时停止；由现有服务和备用安排接续。

## 二、角色与利益冲突

| 角色 | 正当关切 | 需要防止的冲突或事实权力 |
|---|---|---|
| 服务对象 | 表达目标、生活方式、拒绝、反馈和安全 | 在“保护”名义下失去表达与参与 |
| 家属或支持者 | 帮助沟通、提供事实 | 便利、控制或经济利益替代本人意愿 |
| 照护者 | 按封套执行、报告风险、休息、恢复和退出 | 关系承诺被解释为永久责任 |
| 服务机构 | 资源、人员、培训、替代、投诉和修复 | 隐藏缺口或依赖可靠者长期补洞 |
| 公共出资与决定主体 | 确定最低范围和共同成本 | 只设标准、不提供资源 |
| 专业判断者 | 评估安全和能力条件 | 从专业判断越界决定本人生活目的 |
| 独立复核者 | 核验缺口、投诉、伤害和责任 | 与机构共享资金或任命网络而失去独立性 |

## 三、三类制度输出

### 公共决定

记录最低安全照护、必要关系连续性、共同资源、承接结构、可接受降级、公开的未满足需要和复核日期。它不指定某一家庭或照护者长期负责。

### 具体责任分配

分别记录公共出资者和服务机构的组织维护责任、知情接受岗位或排班者的有限任务、承诺储备和跨机构支援。家庭成员、熟悉者或有能力者不因身份自动取得任务。有限公共责任个案仍只是剩余研究候选。

### 执行授权

按服务对象、任务、时段和空间分别限定身体接触、住所进入、最小记录、设备和协调权限。财产、账户、一般医疗和生活决定权不随照护任务自动产生。

公共认定的“接受／否定／延期补证”仍在这三类输出之前。接受最低照护并不表示某个熟悉照护者已经有任务或权限。

## 四、五个机制依次走查

### 机制一：公共必要性认定与另行机构承接

需要审查的是“最低安全照护和必要关系连续能力”，而不是“维持该机构原有全部服务量”或“补足它预设的全部岗位”。关系连续性可以进入质量与安全判断，但不能变成服务对象永久占有某一照护者。

认定可能输出：

- **接受**：限期确认最低安全照护和必要关系连续能力，并说明共同成本、降级、申诉和复核；
- **否定**：否定“指定某人永久服务”或机构原服务规模是公共最低的主张，不取消本人基本照护；
- **延期补证**：机构的短缺、最低范围或某项新增服务证据不足时，先采取临时保护、公开未满足需要并限定补证日期。

承接机构须另行比较。现有机构不能因为最先报告短缺，就独占最低标准、承接资格和缺口认定。

**内部结果：** 可以形成认定和承接的分离记录；最低范围、关系连续性标准和承接资格仍为信息不足。

**停止线：** 把照护对象的困难私人化；把机构岗位数直接等同公共最低；由机构自证缺口并取得额外派工权；不给资源只宣布“社会负责”。

### 机制二：公共任务定义与任务封套

不能生成笼统的“去照护机构帮忙”。至少比较：

1. **专业照护封套**：限定专业操作、资格、团队和安全条件；
2. **关系或团队连续封套**：限定稳定团队、本人参与、换人频率、重叠交接和结束条件；
3. **低风险辅助封套**：限定陪同、物资、环境或生活支持中可以做和不得做的事项；
4. **替补培养封套**：由机构承担培训、带教、知识记录和后备能力；
5. **独立质量与投诉封套**：不由日常执行机构独占最终认证和裁决；
6. **方案零**：现有服务或权利救济已经能回应，不新建个人任务。

所有封套都要明确：不得替本人作一般生活、财产或医疗决定；住所进入、身体接触和完整记录访问不是默认权限；关系连续性不能无限延长某个人任务；对象、风险、身体接触、地点、数据或期限变化时重新审查。

**内部结果：** 单次任务封套不足以完整表达本场景，须保留关系或团队封套与持续服务结果；可继续准备外部验证。

**停止线：** 把照护切成可互换分钟而破坏信任；任务封套夹带具体熟悉者；以“关系连续”掩盖开放式永久责任；高风险与辅助任务混写。

### 机制三：具体承担与公平分配

候选顺序是：

1. 改善正常岗位、报酬、安全、休息、恢复和人员条件；
2. 减少非必要行政任务并建立替补培养；
3. 使用已知情接受的核心团队、轮换和待命安排；
4. 使用承诺储备和跨机构支援；
5. 比较临时、透明且不伤害最低安全的服务降级；
6. 最低缺口仍存在时，才审查有限公共责任个案候选。

本走查不能产生有约束力照护任务。一般公众或无资格者不得承担专业护理、医疗判断或高风险转移；对于具备当前资格但未预先承诺的人，能否在全部个案条件另行成立后进入专业或辅助任务候选，本走查不作采用或排除决定，须退回上游审查。强制进入住所和身体接触还须另有独立、具体而相称的合法依据，不能仅由公共责任推出。

家庭身份、过去自愿、与服务对象熟悉、本人可靠、有空或具备能力，都不是任务来源。服务对象拒绝某位承担者时，机构先重新匹配或调整方式；拒绝不能取消最低服务，也不保证无限指定某个人。

**内部结果：** 正常岗位、承诺团队以及自愿或已承诺的低风险辅助分支可继续准备外部验证；任何未预先承诺的有约束力个案与家庭补位分支退回上游。

**停止线：** 未核验机构先行责任即要求成员补位；家庭被迫无偿承担；高风险任务派给无资格者；关系连续性无限阻止照护者退出；基本照护与感恩、配合或家庭贡献挂钩。

### 机制四：最小执行授权、变更与退出

候选权限只包含特定服务对象、时段和空间，最小照护记录，明确允许的设备、物资、身体接触和紧急报告入口。明确排除财产、账户、一般医疗和生活决定权，以及与任务无关的家庭、社交和健康信息。

服务对象应获得可理解信息并尽可能表达，必要时先提供支持性决定。只有确有依据时才使用范围最小、可复核并可终止的替代决定。

照护者退出时，只有本人仍能安全承担且服务对象没有拒绝，才进行对象清楚、范围最小、期限明确的安全交接；出现急性健康、安全或伤害风险时可以先暂停。寻找替补、安排重叠时间和培训首先是机构责任，没有替补不得延迟已经生效的退出。期限届满后检查钥匙、账号、数据、财产接触和基于信任关系形成的事实控制。

**内部结果：** 权限封套和退出检查可形成候选记录；身体接触、住所、数据与支持性决定的现实规则仍为信息不足。

**停止线：** 照护任务自动产生一般替代决定权；本人能表达却被家属或专业者取消；因信任关系保留钥匙、数据、财产接触或私人影响；用没有替补无限延迟退出。

### 机制五：关键服务连续性、降级与紧急压缩

候选组合包括：稳定核心团队而非固定单一人员；计划轮换、恢复和后备；由服务对象参与的重叠交接；承诺储备和跨机构支援；透明公布等待、转介、降级和未满足需要；只在即时严重危险时启用范围有限、自动失效的紧急增量。

关系连续性应观察本人是否仍能辨认、沟通、信任并安全适应服务团队，不能简化为“同一个人出勤次数”。同时，关系稳定不能保护正在伤害服务对象的人，也不能永久占用承担者。

**内部结果：** “团队连续＋本人参与＋真实退出”的组合可继续准备外部验证；单一熟悉者永久负责触发停止。

**停止线：** 慢性缺员反复续成紧急；家庭承担被隐藏；更换率或平均覆盖掩盖服务对象伤害；核心人员长期超负荷；投诉和质量最终由执行机构自证。

## 五、反例检查

| 反例 | 应当输出 |
|---|---|
| 熟悉照护者正在实施伤害 | 安全暂停、独立投诉和替代；连续性不能压过安全 |
| 服务对象更喜欢轮换团队 | 由本人共同定义可接受连续性，不由机构单方规定 |
| 熟悉者不具备新增医疗任务资格 | 关系信任不替代资格、团队条件和授权 |
| 家属与服务对象对人员选择相反 | 家属便利不自动代表本人；提供支持性决定和独立复核 |
| 机构已合理履责但区域仍长期短缺 | 只允许继续审查资源、降级和候选机制，不自动产生个人任务 |
| 追求低更换率压迫照护者 | 返回团队结构、恢复和退出设计；不得以连续性为由无限调用 |

## 六、需要的现实证据与参与

- 服务对象对最低照护、关系连续和可接受换人的不同理解；
- 未满足需要、近失事件、伤害、投诉及困难对象被拒收记录；
- 照护者实际工作、待命、情绪负担、疲劳、恢复和退出原因；
- 工资、岗位、培训、流失、替补和跨机构支援记录；
- 专业、高风险、身体接触和低风险辅助任务的现实边界；
- 支持性决定和最小替代决定的专业与法律要求；
- 家庭、正式照护者和服务对象之间的成本分布；
- 公共出资、家庭无偿投入、机构节省、人员流失与关系连续成本是否在不同主体之间静默转移；
- 服务对象、残障者、家庭照护者、正式照护者、机构管理者、专业人员和独立维权者的共同复核。

## 七、走查结论

本场景把“人员不足”拆成公共最低、机构责任、关系或团队任务、承担路径、有限授权和连续性安排。它暴露出单次任务封套不能替代关系型服务设计，也没有证明任何有约束力照护任务成立。

主要未决问题是：关系连续性怎样由服务对象共同定义；拒绝与即时安全冲突时怎样复核；具备资格但未预先承诺者能否进入任何有限公共责任个案；团队连续与个人退出怎样同时保护；机构先行责任达到什么证据门槛。

**总体内部结果：** 关系或团队封套、承诺团队、自愿或已承诺的低风险辅助与最小授权“可继续准备外部验证”；家庭自动补位、一般公众或无资格者承担高风险任务、单人永久连续“触发停止”；未预先承诺者的有限公共责任个案“退回上游／信息不足”。`validation_effect: none`。
