# 体验过拟合与解释闭合风险

## 风险定义

个人体验是发现制度问题的重要入口，但一个解释能够带来“终于说通了”的感觉，只能说明它具有内部解释力，不能单独证明其事实正确、具有普遍性或适合制度化。

## 失败链

```text
持续存在的不协调感
↓
某个概念带来强烈解释满足
↓
把解释满足误认为真理证明
↓
只收集支持材料并重新解释所有反例
↓
将个人经验推广为普遍人性
↓
形成无法被外部证据修正的闭合理论
```

## 早期信号

- 要求一个理论解释全部体验，不允许保留残差；
- 只有一个候选解释，没有竞争假设；
- 不同思想家的概念被组合使用，却没有核查原始语境；
- 反对意见总被解释成对方“不理解”或制度压迫的进一步证明；
- 个人经验被直接写成对所有人的描述；
- AI 的赞美性分析被当作人格测评或学术证据；
- 受影响者的不同经验没有进入理论修订；
- 研究没有临时停止条件，只能不断追求完全吻合。

## 特别容易发生的概念滑移

```text
需求 → 请求 → 共同任务 → 他人义务
受益 → 承认贡献 → 情感感谢 → 人格负债
承担任务 → 具有能力 → 获得权限 → 取得身份地位
已经适应 → 已经同意 → 没有伤害 → 制度正当
局部交换价格 → 全部社会价值 → 人格价值
```

每个箭头都必须独立论证，不能依靠语言连续性自动通过。

## 预防与修正

- 同时记录内部解释力与外部证据状态；
- 为重要命题保留至少一个有竞争力的替代解释；
- 主动寻找最强反例、失败案例和不同群体经验；
- 区分“解释了我的体验”和“代表多数人”；
- 对来源标注直接表述、AI 推断、二手转述和已核验事实；
- 为每项命题说明适用范围、置信度和可推翻条件；
- 用有限版本和复核日期代替等待最终完整理论；
- 让制度对象、执行者和第三方分别检查理论是否遗漏其经验。

## 暂停条件

当某项解释持续排斥受影响者证词、与可靠证据冲突、无法提出可证伪条件，或已经被用于限制他人却没有外部复核时，应暂停其制度化使用。

暂停并不否定最初体验，而是把它恢复为等待其他解释竞争的研究问题。
