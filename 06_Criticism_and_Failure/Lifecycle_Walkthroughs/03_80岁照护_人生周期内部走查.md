# 80岁照护：人生周期内部走查

> **内部假设走查｜不是养老安置方案｜不是现实验证**

## 一、固定场景

假设一名 80 岁老人开始需要日常生活支持。主场景中，他能够理解信息并表达自己希望在哪里生活、由谁进入住所、接受哪些帮助。家庭关系、健康状况、住房条件和照护强度尚未固定，必须分别进入分支，不能只由年龄推定失能或无决定能力。

本走查检查三种可能：亲属愿意且现实上能够共同生活或照护；亲属存在但不方便或不愿承担；老人没有可承接的亲属关系。本文不设家庭照护工时、养老院床位比例、费用标准、探访频率或能力评估分数。

## 二、先确定老人是主体

- 老人的需要由本人优先表达；年龄不取消其住所、关系、医疗、财产、隐私和退出决定。
- 需要帮助表达时，先提供可理解信息、辅助沟通和可信支持者。
- 只有具体决定确实无法理解且存在现实风险时，才讨论范围和期限最小的替代判断，并接受独立复核。
- 接受家庭或公共照护不产生服从、财产让渡、感恩债务或机构所有权。

## 三、需求归属与承接层次

长期照护回应的是任何人都可能进入的共同脆弱处境。基本照护作为公共需要时，由公众承担最低范围、共同成本和持续承接的第一责任，公共系统不能把无法由家庭完成的部分退回给当下老人。

家庭可以作为默认首先询问的稳定关系承接者；亲属愿意、现实条件允许且老人接受时，共同生活通常更能保持熟悉关系。但“首先询问”不等于血缘自动生成无限、无偿、不可退出的具体任务，也不使家庭取得替老人决定一切的权限。

公共系统需要维持可以组合的在家支持、社区服务、临时喘息、专业上门照护、适老住房和居住型照护机构。养老机构应当是适合老人生活、保持关系和参与社区的住所与服务，不是以安全或管理便利为名禁锢老人的场所。

## 四、三条分支

### 分支一：老人和家人都愿意共同生活

记录老人接受的具体照护、家人真实能力与时间、公共上门或喘息支持、专业任务边界以及紧急替代。亲属承诺形成相应关系责任，但可以在说明、交接和替代安排下调整或退出；公共服务不能以“有孩子”为由自动拒绝。

### 分支二：家人不方便或不愿共同生活

先询问老人希望继续独居、进入社区支持住房、接受上门服务还是申请照护机构。家庭不能因为不亲自照护而把老人遗弃在危险中，公共系统也不能通过羞辱或无限义务迫使某一位子女补位；当前关系中已经发生的承诺、财产安排、伤害或修复责任另行判断。

### 分支三：孤寡或没有可承接关系

公共系统必须提供可以申请且真实可达的照护选择、联系人和救济入口。是否入住机构由老人决定；明确即时危险可以触发最小临时保护，但危险稳定后必须返回本人参与、期限复核和可退出安排。

## 五、反例与返回路径

| 情形 | 内部返回路径 |
|---|---|
| 老人愿意独居并能在支持下安全生活 | 提供可选择的上门、社区与紧急联系，不因年龄强制入住 |
| 子女愿意陪伴但无法完成专业护理 | 关系陪伴与专业任务分开；公共系统提供合格照护 |
| 家庭照护者疲劳或需要退出 | 启动喘息、替代和有限交接，不以亲情无限延长 |
| 老人与子女对住所选择不同 | 老人意见优先；具体风险由独立证据判断，不以“为你好”代替 |
| 机构以防跌倒为由普遍锁门 | 检查个别风险、较小替代、期限和复核；普遍限制触发停止 |
| 老人认知能力发生变化 | 先支持性决定；只对无法理解的具体事项作最小替代，不一次性取消全部决定权 |
| 亲属照护后要求接管财产 | 照护不自动产生财产、医疗、住所或社交决定权；另行授权与监督 |

## 六、停止线

- 把年龄、疾病诊断或机构入住自动等同于无决定能力；
- 因老人没有子女、子女不方便或家庭关系不主流而降低基本照护；
- 将公众的照护责任整体转嫁给女性亲属、某一名子女或无偿家庭劳动；
- 用没有替补无限阻止家庭照护者、专业人员或老人退出某一安排；
- 以安全为名实施无个别依据、无期限、无申诉的禁闭、监控或关系切断；
- 将亲属、机构或专业资格自动转换为财产、医疗或生活的全面决定权；
- 以过去贡献、子女贡献或服从程度决定基本照护质量。

## 七、尚缺证据与参与

需要取得在家、社区和机构照护的现实需求与成本；老人对关系稳定、自由、安全和隐私的实际排序；家庭照护时间、疲劳与退出；专业人员配置和劳动条件；适老住房和社区可达性；机构限制、投诉、伤害和替代路径；支持性决定的现实做法。

至少需要居家老人、独居老人、机构居住者、家庭照护者、一线照护人员、养老机构、社区服务、老年医学与康复人员、残障与支持性决定实践者、公共财政及法律研究人员分别复核。

## 八、内部结论

当前原则能够把老人本人决定、稳定关系、家庭承诺、公共基本照护、专业任务和机构权限分开。家庭优先保持关系可以作为一条生活路径，但不能成为公共系统退出、血缘自动派工或机构支配老人的依据。
