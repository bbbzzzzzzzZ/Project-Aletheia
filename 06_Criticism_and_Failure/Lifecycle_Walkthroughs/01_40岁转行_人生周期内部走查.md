# 40岁转行：人生周期内部走查

> **内部假设走查｜不是就业政策｜不是验证结论**  
> 本文只检查“一个成年人能否退出旧职业并重新选择方向”在项目内部是否产生不必要的保障、任务或资格跳转。现实比较另见[首次外部验证方案](../../08_Research_Workbench/07_Validation_Records/External_Validation_Plans/40岁转行_首次外部验证方案.md)。

## 一、固定场景与明确排除

假设一名 40 岁成年人目前有稳定职业，决定离开原行业，暂时没有下一份工作，也尚未确定是否学习一项新技能。他具备独立表达和决定能力，没有正在发生的重大健康危机，原岗位没有尚未处置的即时第三方生命安全事件。

本次主场景明确不加入育儿、老人照护或患病家属照护负担；若以后研究这些处境，应作为单独分支，不得在本轮用一个未给出的“照护责任”限制转行。

本文不设学习期限、公共责任工时、培训津贴、资格年龄、交接天数、岗位配额或录用比例。

## 二、先区分六件事

| 问题 | 本轮内部边界 |
|---|---|
| 是否离开旧行业 | 默认由本人决定；机构不能以职业需要定义其终身方向 |
| 基本保障是否继续 | 在 Aletheia 候选场景中连续存在，不以工资、就业或转行成功为条件 |
| 是否承担公共责任 | 适用与其他有现实能力成员相同的一般规则；转行、学习或暂时不工作不新增责任债 |
| 是否学习 | 由本人选择进入、暂停、转向或退出；学习记录不自动进入任务池 |
| 是否具备新岗位资格 | 只按具体任务的现实风险和能力要求判断；年龄、旧职业和学习经历都不是自动结论 |
| 是否获得岗位与权限 | 资格不等于岗位，岗位不等于具体任务，具体任务不等于无限执行权限 |

“社保中断”只属于现行制度基线需要核验的现实条件，不是 Aletheia 另设的一层机制。项目内部只需说明基本保障连续，并诚实记录这种安排需要怎样的资源与交付能力。

## 三、场景路径

### 1. 提出退出

本人可以辞去或结束普通岗位。一般交接依正常、合理和诚实原则完成：告知必要状态，归还资源、账号和权限，不故意制造可预见损害。

若正在执行与第三方安全直接相关且不能瞬间中断的有限任务，可以形成范围和期限明确的安全交接；“暂时没有替补”不能无限延长旧岗位，也不能把机构长期缺员变成本人的永久责任。

### 2. 过渡与探索

退出后，本人可以休息、观察、尝试低风险活动、直接寻找新工作、学习新技能，也可以暂时不知道要做什么。基本保障不因这些选择改变。

一般有限公共责任仍须经过公共必要性、机构先行、公平分配、现实能力、合理条件、豁免、延期、替代和申诉，不能因为“现在没有职业”就自动取得此人的时间。

### 3. 学习、资格与上岗

需要区分：

1. **重新学习**：本人学习新知识或技能；
2. **资格核验**：只有具体工作会给第三方带来显著安全风险时，才核验与该任务相称的能力；
3. **上岗训练**：进入具体组织后，为工具、流程、团队和现场风险提供必要适应训练；
4. **任务授权**：取得岗位或资格后，仍按具体任务授予有限权限。

普通低风险工作不应复制高风险行业的准入门槛。医疗、电力、司法等高风险角色可以要求更严格的学习、监督实践与资格验证，但不得以年龄本身代替能力证据，也不得由既有岗位数量封死学习和申请资格的入口。

## 四、竞争分支与反例

| 情形 | 内部返回路径 |
|---|---|
| 只是想离开，还不想学习或工作 | 允许停留在探索期；不把暂时无目标视为人格或责任失败 |
| 新职业是低风险普通工作 | 使用最小能力说明和正常上岗适应，不制造统一再认证 |
| 新职业涉及第三方重大安全 | 进入相称的资格、监督实践和有限授权；不能因转行意愿跳过安全 |
| 用人单位只因年龄拒绝进入申请程序 | 要求说明与具体任务相关的真实能力或资源理由；年龄替代判断触发复核 |
| 旧单位长期找不到替补 | 机构承担连续性和招聘责任；完成有限安全交接后允许退出 |
| 学习记录显示能力很强 | 只能在本人另行选择用途后提供必要证据；不能自动派工或授权 |
| 转行者当期无法承担某项公共任务 | 进入延期、替代、豁免或申诉，不影响基本保障 |

## 五、停止线

- 用取消食物、住所、基础医疗、教育或必要服务迫使继续就业、学习或服从派工；
- 因失业、转行或暂时无目标而增加公共责任额度；
- 把学习、能力记录、职业资格或年龄自动转换成具体任务；
- 用岗位配额永久关闭学习和资格申请入口；
- 用“职业连续性”无限阻止个人退出；
- 把普通交接扩张为终身说明、竞业支配或任务外数据控制；
- 把一次学习困难、求职失败或任务延期写成人格等级。

## 六、现实证据与不可替代复核者

需要取得：不同地区和就业类型的现实退出成本；收入、住房、医疗与社会保障连续性；培训成本、完成率和实际转岗结果；年龄与跨行业招聘条件；机构培训与上岗成本；合理交接和安全关键任务退出的现实做法；现有公共就业和职业教育已经提供的有效功能。

至少需要转行者、培训机构、用人单位、社会保障实践者以及劳动与就业研究人员分别复核。任何一组意见都不能代表其他组，也不能由 AI 替代。

## 七、内部结论

当前原则可以支持“退出旧职业—保障连续—自由探索—必要时重新学习—风险相称资格—具体岗位授权”的分离结构，也能排除“转行即失去保障”“无业即增加公共任务”“年龄即无资格”和“单位缺人即不得退出”。
