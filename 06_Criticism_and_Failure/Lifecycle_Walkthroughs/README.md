# 人生周期内部走查

## 这组文件是什么

本目录用四个完全假设的人生阶段，检查 Project Aletheia 的原则和候选机制能否在时间变化中继续区分：本人选择、需求归属、公共保障、具体承担、任务资格、执行权限和退出。

它们不是现实案例、法律意见、伦理结论、社会实验或验证记录。所有人物、关系、能力、资源和制度条件均为待核验假设；任何内部判断都不得用于现实派工、福利处理、亲职决定、照护安置或职业准入，也不改变项目的验证状态。

## 固定顺序

1. [`01_40岁转行_人生周期内部走查.md`](01_40岁转行_人生周期内部走查.md)：职业退出、重新学习、基本保障、公共责任与新岗位入口；
2. [`02_18岁转衔_人生周期内部走查.md`](02_18岁转衔_人生周期内部走查.md)：教育结束、继续探索、职业选择与成年公共责任；
3. [`03_80岁照护_人生周期内部走查.md`](03_80岁照护_人生周期内部走查.md)：老人本人决定、家庭关系、公共照护与机构边界；
4. [`04_出生与亲职_人生周期内部走查.md`](04_出生与亲职_人生周期内部走查.md)：生育决定、知情、亲职申请、儿童保障与安全边界。

40 岁转行另有一份[首次外部验证方案](../../08_Research_Workbench/07_Validation_Records/External_Validation_Plans/40岁转行_首次外部验证方案.md)。方案尚未启动；建立方案不等于已经招募、验证或取得结论。出生与亲职只允许法律、伦理和匿名情境评审，明确禁止现实制度试验。

## 每份走查必须保留的内容

- 固定的假设场景和明确排除项；
- 本人、关系主体、公共系统和专业角色各自的位置；
- 需求归属、保障责任、具体承担与权限之间的区分；
- 至少一条竞争分支或反例；
- 对基本权利、时间、家庭关系、年龄或能力歧视的停止线；
- 尚缺证据和不可由 AI 替代的复核者；
- `hypothetical-unverified`、`not-ready` 与 `validation_effect: none` 的状态边界。

## 统一结果词

| 内部结果 | 只表示什么 | 不表示什么 |
|---|---|---|
| **结构可记录** | 在当前假设下，各类主体、责任和返回路径能够分开书写 | 不表示制度合法、公平、安全或可行 |
| **退回上游** | 需求、责任、资源、资格或权限依据不足 | 不表示本人失去保障或请求帮助资格 |
| **触发停止** | 已越过第一原则禁区或领域安全底线 | 不表示可以对当事人作现实处分 |
| **信息不足** | 不能在现有材料中选择方案 | 不允许由 AI、年龄、职业、血缘或家庭身份填空 |

任何文件均不得写成“走查通过”“已验证”或“可以实施”。机制参数、福利细目、审查标准和惩罚办法不进入第一原则；它们只能留在下游候选文件并接受独立复核。
