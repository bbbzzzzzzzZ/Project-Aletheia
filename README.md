# Project Aletheia

Aletheia 是一个开放的制度研究项目，研究：共同需求出现后，谁决定如何回应，谁具备完成条件，谁承担代价，又由谁纠错。

当前内容包括规范主张、待检验的解释、候选机制与有限案例材料。项目尚未证明任何一套完整社会制度可行。当前精简版修订于2026-09-25。

## 先读哪里

- **普通读者十分钟版**：[这个项目到底在说什么](00_先读这里/00_这个项目到底在说什么.md)。先读这一篇即可。
- **研究者**：[Core：核心原则与推导关系](00_先读这里/08_Aletheia_Core_v0.1_核心原则与推导关系.md)，由文内链接进入诊断方法、失败地图和养老示范。
- **参与贡献者**：[失败史与修订纪律](00_先读这里/07_失败史与修订纪律.md)。先选一个可回答的问题，注明材料、反对意见与可能改变的结论。

## 本次整理原则

- 当前入口只保留“现在还承认的定义”和“正在使用的机制草案”。
- 历史版本不删除，统一压缩保存。
- 人话版不追求防住所有误解，只先讲清楚主干。
- 正式模型服务于人的理解，而不是要求人服务模型。
- 机制草案不得反向改写第一原则。
- 规范层、理论层、验证层和制度工程层必须分开标注，不能互相冒充。
- 项目自己的理论、机制和解释权也必须允许被质疑、废弃和重写。

## 重要提醒

`02_当前机制` 中的文件是候选机制和制度草案，不代表已经完成现实验证，也不代表可以直接实施。

如果某个机制与 `01_核心定义` 中的第一原则冲突，应优先保留第一原则，把机制标为待修订。
