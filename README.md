# Project Aletheia

> **Project Aletheia 研究人想怎样生活、人与人怎样共同生活，以及制度应当在什么地方介入和停下。**

`Aletheia` 取自希腊语 `ἀλήθεια`。本项目借用“揭示 / 去蔽”的意象：不是替人规定应当如何生活，而是先理解人的需要及其关系；只有确实需要共同协调时，才研究怎样让需要、责任与权力保持边界。

它把自身定位为一项“文明操作系统”的基础研究，而不是一部从具体制度开始的社会法典。

当前工作版本：`0.3.0`（第一原则 v1.0 与验证脚手架）  
更新日期：`2026-08-25`

## 项目研究什么

项目的起点不是某一种制度，而是具体的人怎样生活、人与人怎样相处。它先分别追问：

- 一个人正在经历什么，想怎样生活？
- 人与人的关系怎样支持、限制或伤害这种生活？
- 哪些共同生活条件值得社会维护？
- 只有确实需要稳定协调时，制度是否必要，又应当在哪里停下来？

前三类问题不会自动生成公共事项、任务或个人义务。人的困惑可以停留在倾听、理解、自主行动、关系调整或自愿合作；没有进入制度不是失败。项目的这一基本方向见[世界观](03_Aletheia_Framework/世界观.md)。只有某件事另行满足共同协调入口门槛后，才使用[制度生成语法](03_Aletheia_Framework/制度生成语法.md)，继续追问谁受到影响、谁承担代价、谁实际拥有决定力，以及这种决定力何时结束。完整研究结构见[研究索引](PROJECT_INDEX.md#researchers)。

> 制度应当帮助人共同生活，而不是把人变成制度需要的材料。

## 项目不是什么

- 不是一套已经完成、等待执行的社会蓝图；
- 不是以某位哲学家或某种意识形态为权威的注释工程；
- 不是用“公共利益”替每个人定义幸福；
- 不是把劳动、能力或任何评价变成人格等级；
- 不是完整法典，也没有可直接执行的实施方案。

## 对外核心命题

根 README、普通读者总纲和公众文章只共同使用以下七条。项目发起者已确认这七条的当前普通语言方向；完整理论论证仍以[第一原则](03_Aletheia_Framework/第一原则.md)为准，其十一公理与禁区已经形成 [v1.0 规范语义冻结](03_Aletheia_Framework/第一原则_v1.0_语义冻结.md)。冻结不表示经验验证、机制采用或现实授权已经完成。

1. **人先于身份和功能。** 职业、能力和贡献只能说明人的一部分，不能决定人的高低，也不能封住以后改变方向的可能。
2. **自己最有资格说明自己的需要，但需要不是命令。** 别人可以帮助理解事实和后果，却不能替本人拥有他的人生目的；表达需要也不会自动产生支配别人的权利。
3. **先判断这是谁的需要，再分清谁做了什么。** 私人需要由本人先负责；经确认的公共需要由公众先负责。表达、组织、承诺、执行和造成影响的人，再各自承担能够说明的责任；正在求助不等于要为整个公共系统负责。
4. **基本生活不靠履责换取，共同责任必须有限而公平。** 共同需要不能直接指定某个人；还要说明为什么由他承担、条件是否合理，以及遇到困难能否换一种方式。
5. **帮助不是施舍，接受帮助也不等于欠下人格债务。** 真实付出应当被看见，但不能把帮助变成永久服从，也不能把人按贡献排成高低。
6. **有能力、有资源或有影响力，不等于有权替别人决定。** 为完成一件事暂时交出的行动范围必须说清边界，并在事情结束或条件改变时归还。
7. **决定做什么、谁来承担、谁能行动不能混成一步；制度错了必须能改。** 现实结果、异议和受损经验都应使规则可以修改、暂停或结束。

## 研究内容放在哪里

项目同时维护三类内容：

- [研究框架](03_Aletheia_Framework/README.md)保存完整论证、反例和可修订的问题；
- [公众思想书](07_Writing/Thought_Book/README.md)用日常语言回答“为什么”；
- [制度白皮书](04_Institution_Design/Project_Aletheia_制度白皮书.md)连接各模块，研究“怎样进入制度”；[机制层总览草案](04_Institution_Design/Project_Aletheia_机制层总览草案.md)研究公共认定、任务、承担、授权、连续性与纠错可能怎样衔接；[制度设计目录](04_Institution_Design/README.md)保存下层专题机制。

公众入口不展开积分、计算公式、控制矩阵或内部术语清单。责任怎样记录和计算，集中在[责任与贡献评价机制](04_Institution_Design/Incentive_System/责任积分、贡献积分与领域专业评价.md)；公共权力怎样检查集中，集中在[权力控制机制](04_Institution_Design/Political_System/十环节权力集中控制矩阵.md)。这些文件目前仍是研究草案，不是已经验证或可以直接执行的制度。

完整目录、机制、案例、来源和贡献入口见 [`PROJECT_INDEX.md`](PROJECT_INDEX.md)。历史材料与当前文件的关系见 [`MIGRATION_MAP.md`](MIGRATION_MAP.md)。

## 当前状态

项目已经确定研究方向和部分边界，但许多现实冲突、分配办法、监督方式和实施条件仍未解决。没有现行实施基线，也不能从任何一份草案直接推出法条、固定参数或普遍答案。

哪些文件可作为当前依据、哪些仍待验证，见 [`DOCUMENT_STATUS.md`](DOCUMENT_STATUS.md)；版本变化见 [`CHANGELOG.md`](CHANGELOG.md)；参与规则见 [`CONTRIBUTING.md`](CONTRIBUTING.md)。
