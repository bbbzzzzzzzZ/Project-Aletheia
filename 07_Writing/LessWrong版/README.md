# LessWrong 版

## 建议形式

把 Aletheia 写成一组可反驳命题、因果模型和失败测试，而不是宏大宣言。

## 必须包含

- 概念的操作性区分；
- 竞争假设与可能证伪证据；
- 激励、Goodhart、信息不对称、机制套利和规模问题；
- 对最强反对意见的钢人化版本；
- 最小可行试验及停止规则。

## 避免

哲学名词堆叠、未经证据的人性断言、只描述理想参与者、把价值选择伪装成技术中立。
