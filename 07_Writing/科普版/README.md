# 科普版

## 面向读者

第一次接触制度哲学、只愿意投入约十分钟的普通读者。

## 叙事入口

从四个生活问题切入：谁替你定义需要什么？承担责任是否意味着别人能控制你？有能力是否意味着必须随时工作？基本生存能否成为服从的筹码？这些是叙事入口，不是另一套核心命题。

## 写作要求

- 使用具体场景，少用术语；
- 每个概念给出一个“不是”；
- 保留项目仍未回答的问题；
- 只展开项目总纲中的同一套公众命题，不在正文复制内部分类或计算办法；
- 不用“彻底解决”“完美制度”等承诺。
