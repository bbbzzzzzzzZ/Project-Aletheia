# 序：如果今天重新设计人类社会

> 文稿状态：本文由同名 RTF 轻度转写，并将原书稿表述调整为 Project Aletheia 的思想书候选序言。源稿作者构成、第一人称表述与外部事实尚待逐段确认。

如果今天，人类文明消失了。

没有国家，没有法律，没有学校，没有市场，也没有货币。

只有一群刚刚重新聚集在一起的人。

那么，第一个问题会是什么？

很多人会说，是食物。

有人会说，是安全。

有人会说，是住房。

这些都没有错。

但我越来越觉得，在这些问题之前，还有一个更根本的问题：

> 我们准备怎样看待彼此？

一个人首先是什么？

是医生吗？

是工人吗？

是老板吗？

还是学生？

为什么我们介绍一个人，总是先介绍他的职业、收入、学历、国籍，而不是他这个人？

如果今天重新开始，我们还会这样设计吗？

很长一段时间，我并没有打算发起一个关于制度的研究项目。

我只是不断遇见一些让我无法理解的事情。

为什么帮助别人的人，反而更容易被轻视？

为什么全职妈妈常常被认为“没有工作”？

为什么服务员越有礼貌，就越容易被认为这是理所当然？

为什么劳动者创造了社会，却越来越难从劳动中获得尊严？

后来，我开始寻找不同的解释，但这些解释并没有替我结束问题。

也许，我们真正出现问题的，不只是经济，不只是教育，甚至不只是某一项制度。

更深的问题是：我们为什么已经习惯用职业、收入、身份和市场价格衡量一个人的价值？

于是，我开始做一个思想实验。如果今天一切都可以重新设计，人能不能更了解并修订自己的生活，人与人能不能合作而不互相占有，制度又能不能只在需要时介入，并在出错后退回来？

我不知道答案。

Project Aletheia 也不会宣称已经给出了答案。

它只是记录一个普通人不断提出问题、不断修正自己、不断尝试寻找答案的过程。

如果这些问题能够引发你的思考，如果其中任何一个想法能够被比我更专业的人继续完善，那么它就已经完成了自己的使命。

因为真正重要的，从来不是这个项目本身，而是那些值得我们重新思考的问题。
