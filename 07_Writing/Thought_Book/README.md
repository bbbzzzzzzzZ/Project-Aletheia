# 思想书

## 定位

思想书面向希望理解 Aletheia “为什么这样看世界”的普通读者。它从人、关系、自我认识、职业与身份等日常经验展开，不以制度条款为主，也不承担学术证明和实施细则。

它与研究框架、制度白皮书并行写作，但不是新的理论真源。写作中发现的新命题，应先返回 `00`—`03` 层评审，再作为项目主张进入本书。

## 当前候选稿

- [`序言_如果今天重新设计人类社会.md`](序言_如果今天重新设计人类社会.md)（作者语言与事实来源待确认）

## 主要问题

1. 为什么一个人不能被一种职业或身份概括？
2. 人怎样在关系中认识自己的需求，又怎样保留修订生活的权利？
3. 为什么帮助、服务和依赖常被误写成人格等级？
4. 为什么教育应帮助人发现自己，而不是过早确定人生用途？
5. 人的需求怎样成为合作，而不变成对他人的命令？
6. 制度怎样改变人与人的关系，又怎样接受人的生活经验检验？

## 语言规则

- 先用作者能够确认的日常语言写清问题，再补必要术语；
- 保留具体经验中的疑问，不用宏大理论过早封闭解释；
- 不把 AI 的延伸、赞美或体系化包装成作者已经接受的观点；
- 若一句话“意思相近但作者自己读不懂”，它尚未完成转写；
- 思想家与研究只用于澄清和检验，不用于替作者发言。

## 与其他产出的边界

| 产出 | 主要回答 | 不承担 |
|---|---|---|
| 研究框架 | 命题是什么、理由和反例是什么 | 公众叙事与完整实施 |
| 思想书 | 为什么产生这些问题、它们怎样彼此关联 | 法典、参数与学术定论 |
| 制度白皮书 | 原则如何转化为制度模块与接口 | 替每个人定义正确生活 |
