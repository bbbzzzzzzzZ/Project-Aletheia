# Project Aletheia 项目总纲

> 这是一份面向普通读者的十分钟总纲。它只回答四件事：为什么研究、目前相信什么、研究中的问题怎样连接、哪些地方还没有答案。它不是已经完成的社会蓝图，也不是可以直接执行的制度方案。

## 一、为什么研究

这个项目最初面对的，不是一张制度设计表，而是一些很普通、却很难绕过去的问题。

一个人替另一个人做了对方不愿意、不能够或暂时无法完成的事，为什么这份帮助有时没有带来平等，反而把帮助者固定成“本来就该做这件事的人”？为什么照护、清洁、服务和维持日常生活的工作不可缺少，承担这些工作的人却可能被看低？为什么职业、收入、能力和贡献原本只是对某些行为的描述，最后却常常变成对一个人价值的判断？

这些问题不只发生在劳动中。人在教育里可能过早被一种成绩或一种职业定义；在组织里可能因为掌握信息、资源或专业知识而取得超出任务的支配力；在公共生活里，也可能以“大家都需要”为理由，把某项责任直接变成某个人无法拒绝的任务。我们一边依靠彼此，一边又很容易把这种依赖变成身份、等级和服从。

Project Aletheia 因此不先问“应该建立哪一种制度”，而先问：人想怎样生活？人与人怎样相处？当彼此的需要发生联系时，怎样合作才不会让一方拥有另一方？社会要支持什么，制度又应当在什么地方停下来？

项目目前选择“人—关系—社会—制度”作为研究顺序。人不是为了填补制度中的位置而存在。用原始对话中的话说：“社会是因为人而存在，而不是社会需要人。”制度只是帮助共同生活得以维持和修正的工具；它可以创造条件、协调冲突、组织公共事务，却不应替每个人规定什么才是正确的人生。

这项研究也不把人想象成完全孤立的个体。一个人的自由依赖食物、照护、知识、交通、基础设施和许多看不见的劳动。承认相互依赖，意味着人需要讨论共同责任；但共同责任若没有范围，也可能变成对个人时间、身体和人生方向的无限征用。怎样同时保留基本保障、个人自由和有限的共同责任，是这个项目必须正面处理的矛盾，而不是可以用一句口号消除的矛盾。

项目要研究的，正是共同生活中那些经常被省略的步骤：谁在表达需要，谁会受到影响，什么值得大家一起处理，谁承担具体行动，谁因此可以做什么，又怎样防止这段行动范围变成对别人的长期支配。

如果这些问题被压成一句口号，就容易出现几种跳跃：有人有需要，便被理解为可以命令别人；社会有需要，便被理解为可以直接指定某个人；有人有能力、财富、知识或资源，便被理解为自然有权替别人决定。Aletheia 希望把这些跳跃重新拆开，使每一次承担和控制都必须说明理由、范围和结束条件。

所以，这不是一套等待执行的答案，而是一项仍在形成中的研究。它必须回到具体生活中接受检验：它究竟帮助了谁，代价由谁承担，谁被遗漏，谁实际上控制了别人，错误发生以后能不能改。

## 二、核心命题

以下七条是项目当前唯一一套对外核心命题。根 README、普通读者总纲和公众文章都使用同一组说法，不再另列一套公众原则。完整论证仍由研究文件保存；这里的表达也不等于已经被现实充分证明。

### 1. 人先于身份和功能

制度面对的首先是人，而不是劳动力、岗位、能力或贡献单位。职业可以说明一个人此时承担什么工作，却不能概括他的全部可能；能力可以说明他是否适合某项任务，却不能决定他作为人的高低；贡献可以被记录和感谢，却不能换算成更高的人格价值。

人也不是一次完成的成品。人可能在不同阶段重新认识自己，发现新的兴趣和能力，改变生活方向。教育和社会条件应当为这种变化留下空间。不过，“人仍然能够发展”只表示可能性没有被完全关闭，不表示每个人都有义务不断提高、不断竞争或把自己变成更有效率的工具。

### 2. 自己最有资格说明自己的需要，但需要不是命令

一个人最接近自己的感受、处境和生活目的，因此应当首先有机会说明自己需要什么。别人可以帮助他辨认事实、理解后果，也可以在受到影响时提出异议，但不应越过他，替他拥有他的人生目的。

需要获得表达，并不意味着所有需要都必须被满足，也不意味着提出需要的人可以直接命令别人或占用共同资源。表达只是让问题有机会被看见。它是否需要大家一起处理，要看它会影响谁、需要什么、是否伤害别人，以及代价由谁承担。

### 3. 先判断这是谁的需要，再分清谁做了什么

一项需要在谁身上发生、由谁说出来，不一定表示它只属于这个人。一个人想要某种只服务自己偏好的东西，这首先是他自己的需要；别人可以答应，也可以拒绝。一个病人需要基本医疗回应，却不只是这个病人的私人麻烦。医生和其他人也会生病，公众需要为所有人共同维持医疗回应能力，因此这类公共需要先由公众负责。

这里的“先负责”并不等于亲自完成全部工作。公众负责，不等于每个人立即领到同一项任务；患者正在求助，也不等于他要为医院、人员和整套医疗系统的存在负责。需要属于谁，是责任判断的起点；谁组织、谁答应承担、谁实际做、谁作决定、谁造成后果，还要再分别说清。

这样既不会把公共需要推回给当下最困难的人，也不会让私人偏好因为被说出来就自动变成别人的义务。一个人在做得到而且安全的范围内，仍应参与处理真正属于自己的需要；但这不能被偷换成“遇到困境都是他自己的责任”。

### 4. 基本生活不靠履责换取，共同责任必须有限而公平

一个人的基本生存与基本权利，不应因为他没有贡献、拒绝某项任务或未能履行互惠责任而消失。基本保障不是对良好表现的奖励，也不是迫使人服从的筹码。它保护的是人能够继续生活、表达异议、寻求救济和重新参与共同生活的最低条件。

与此同时，共同生活不能永远只靠别人承担。公共需要先由公众共同承接，并落到明确的组织、资源和维护责任；在这些责任已经履行之后，做得到的人原则上需要公平分担一部分共同责任。但“大家需要这件事”并不会自动推出“必须由这个人做”。还要说明事情为什么确实需要共同处理，为什么由他承担，条件是否合理；遇到健康、照护或其他现实困难时，也必须允许换一种方式。

### 5. 帮助不是施舍，接受帮助也不等于欠下人格债务

疾病、衰老、残障、失能和照护需要，并不是某一类人的特殊缺陷，而是任何人都可能进入的处境。人与人的帮助可以跨越时间和对象：今天照顾别人的人，未必由同一个人在未来偿还；接受帮助的人，也不因此欠下永久服从或低人一等的身份债务。

帮助中的真实付出应当被看见，但基本照护不能只按个人功劳结算。否则，互助会从共同生活的条件变成支配关系：帮助者可以要求服从，受助者则必须不断证明自己值得活下去。这正是项目希望避免的结果。

### 6. 有能力、有资源或有影响力，不等于有权替别人决定

有些资格属于每个人，例如基本生活、表达异议和请求帮助；它们不是完成任务以后才得到的奖励。与此同时，一个人或机构也可能因为控制资源、信息、机会或投诉入口，实际上影响别人的选择。这样的影响即使没有正式头衔，也不能被忽略。

为了完成一件事，人们有时会暂时把一部分行动范围交给某个人或机构。但它只能用于这件事，必须受到别人检查，并在事情结束或条件改变时归还。拥有能力、财富、知识、声望或现实影响力，都不会自动带来替别人决定的权利。

### 7. 决定做什么、谁来承担、谁能行动不能混成一步；制度错了必须能改

共同决定只回答“我们暂时要做什么”，不会自动指定某个人承担，也不会自然让执行者取得更多支配范围。由谁承担、他是否适合、为了完成事情可以做什么，都要分别说明。受到影响的人、了解专业事实的人、实际做事的人和检查结果的人，也不必是同一批人。

制度同样不是一次设计完成的。任何规则都可能遗漏某些人、低估某些代价，或者让少数人逐渐控制过多事情。因此，制度只能作为当前选择接受检验，并根据结果、负担、异议和失败，决定继续、修改、补偿、暂停或结束。能够承认错误并退回前一步，不是制度失效，而是制度仍受人约束的表现。

## 三、模型怎样连接

七条核心命题说明哪些边界不能越过；研究中的模型则提供几种互相校正的观察角度。它们不是一条把人的问题送进制度的流水线。

首先是人的生活和关系。研究会问：谁正在经历什么？他希望被理解、自己尝试、调整关系，还是明确请求别人一起做一件事？很多问题可以停在这里。倾听、陪伴、拒绝、撤回、私人帮助和自愿合作，都是完整的回应，不是因为“还没进入制度”而不完整。

只有当一件事另行显示出共同影响、权利保护、公共资源、持续风险或明确的结构化协作请求时，研究才把它当作候选共同协调事项。即使如此，也仍可以决定不建立新任务或新规则。

对确需共同协调的事项，几个观察角度会同时提出问题：

- 还有谁会受到影响，谁可能没有被听见？
- 需要什么资源，稀缺和代价由谁承担？
- 这件事包含哪些不同需要，它们分别属于个人、组织还是公众？提出、判断、决定、实际行动和纠正又分别由谁负责？
- 谁正式获得了有限的行动范围，谁实际上控制入口、过程和结果？
- 现实中谁受益、谁受损、谁被遗漏，哪里需要暂停或重来？

这些问题互相校正，没有固定先后。资源不足可能要求缩小目标；发现新的受影响者可能要求重新讨论；实际做事的人发现条件不成立，可以要求改变安排；结果表明最初理解错了问题，则应退回人的经验和关系层，而不是强迫流程继续。

一次具体行动要回答“这一次做什么、由谁做、可以做到哪里”；反复出现的问题可能需要暂时形成一条共同规则，回答“以后遇到类似情况怎样处理”。共同规则可以给具体行动提供边界，却不能自动指定某个人；一次行动的成败可以帮助修改规则，却不能单独证明规则永远正确。

研究层把世界观与制度生成语法分开保存：[世界观](../../03_Aletheia_Framework/世界观.md)说明项目怎样看人、关系、社会与制度，并保留无需新建共同任务或规则的回应空间；[制度生成语法](../../03_Aletheia_Framework/制度生成语法.md)只在共同协调理由另行成立后使用。其他模型的定义、证据和关系见[研究者索引](../../PROJECT_INDEX.md#researchers)。

## 四、哪些尚未确定

Project Aletheia 目前仍处于研究草案阶段。方向明确不等于办法已经完成，更不等于经过现实证明。

**谁应当参与共同选择，仍未确定。** 受到直接影响的人应当有发言机会，但间接受影响的人、儿童、失能者、未来世代和没有被组织起来的人怎样进入讨论，又怎样避免被代表者占有，仍没有统一答案。了解专业事实的人应当说明风险，却不能因此替别人决定生活目的；不同问题究竟适合怎样作出共同选择，也需要分别验证。

**基本生活、共同责任和必要服务怎样同时维持，仍未确定。** 项目坚持基本生活不能成为迫使人服从的筹码，也确认公共需要应先由公众负责。但哪些需要真正属于公众，公众的责任怎样变成明确机构、资源和持续服务，之后什么才可以由成员公平分担，遇到健康、照护和其他困难时怎样换一种方式，关键服务怎样不中断，都需要现实参与者共同研究。基本保障具体包括什么，严重短缺时怎样公平分配，同样没有固定答案。

**怎样限制过度控制，又不让必要工作停摆，仍未确定。** 资源、信息、专业知识、基础设施和投诉入口都可能让少数人逐渐控制过多事情。什么时候必须重新检查，检查者又由谁检查，长期工作怎样保持连续而不把临时位置变成永久支配，紧急时集中的决定力怎样及时归还，这些问题只能在具体领域中检验。

**关于人的假设和整套框架能否成立，也仍未确定。** 项目把人理解为仍有可能认识自己、学习和改变方向的主体，也相信合作不必建立在人格等级上。这些是工作假设，不是已经证明的人性定律。它们需要在不同文化、生命阶段、能力条件、组织规模和现实冲突中检验，更需要听取真正承担照护、服务和制度代价的人怎样评价。

目前的案例只能帮助发现问题，不能证明整套框架正确。一次成功不能推出普遍有效；一次失败也要分辨是原则有误、办法失当、现实条件不足，还是最初理解错了需要。外部批评、反例和失败记录都应当帮助项目修改，而不是被当成冒犯。

因此，本文不能推出所有需要都应得到满足、所有任务都能完全依靠自愿、某一种组织或分配方式是唯一答案，也不能推出任何具体计量或实施办法已经成立。项目当前能确定的，只是研究应从哪里开始，以及每前进一步不能忘记什么：从具体的人及其关系开始；让需要能够表达，却不让需要直接变成命令；让责任能够说清，却不把责任变成人格惩罚；让完成事情所需的行动范围能够产生，也能够被看见、限制和收回；让任何制度在现实结果和受影响者面前保持可修改。
