# 项目总纲

本目录形成 Project Aletheia 的简短导航性总纲，帮助读者进入研究框架、公众思想书和制度白皮书三条成果轨道。劳动、教育、经济、政治及跨模块的制度白皮书研究位于 [`../../04_Institution_Design/`](../../04_Institution_Design/)；项目总纲本身不构成第四条成果轨道或新的定义源。

## 当前状态

本目录尚未建立 3–5 页项目总纲。原候选序言已路由到 [`../Thought_Book/`](../Thought_Book/)，避免把公众思想叙事与制度总纲混为同一文体。

## 目标

形成 3–5 页的 Project Aletheia 总纲，只回答：为什么研究、第一原则是什么、模型如何连接、三条成果轨道如何进入、哪些仍待验证。

## 建议结构

1. 问题与项目定位；
2. 需求—责任—权力逻辑链；
3. 九条第一原则；
4. 六个核心模型；
5. 劳动、教育、经济、政治四个应用；
6. 失败风险与研究路线。

## 不进入正文

完整法条、参数、算法、历史长叙述、哲学史综述和全部机制分支。
