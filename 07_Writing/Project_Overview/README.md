# 项目总纲

本目录保存 Project Aletheia 的简短导航性总纲，帮助普通读者理解项目，再进入研究框架、公众思想书和制度白皮书三条成果轨道。项目总纲是派生表达，不构成第四条成果轨道或新的定义源。

- [`项目总纲.md`](项目总纲.md)：3–5 页普通读者版本，只回答为什么研究、同一套 `5–7` 条普通语言核心命题、整体怎样连接、哪些尚未确定。
- [`../Thought_Book/`](../Thought_Book/)：公众思想叙事。

## 当前状态与边界

总纲已建立，当前保持 `draft` 与 `fact_check: pending`。项目发起者已经确认第二节七条核心命题，作者审阅因此记为 `partial`；为什么研究、模型连接、未决范围及具体措辞仍未逐段确认。它把现行原则合并为唯一一套对外共用的普通语言核心命题，不另立正式公理；思想书、科普稿和平台稿不得再建立平行核心清单。如与根治理文件或 `03_Aletheia_Framework/` 不一致，以上游文件为准。

总纲正文不写完整法条、固定参数、积分公式、控制矩阵、内部分类名称、算法、历史长叙述、哲学史综述或全部机制分支；这些内容只链接相应机制或研究文件。第一人称与作者化表达须经作者逐段确认后，才能升级审查状态。
