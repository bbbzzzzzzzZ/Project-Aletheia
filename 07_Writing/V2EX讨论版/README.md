# V2EX 讨论版

## 建议形式

一次只讨论一个可落地问题，例如：

- 基本保障不绑定工作后，必要劳动从哪里来？
- 能力池怎样避免变成全民待命数据库？
- 谁可以代表“用户需求”或“公共需求”？
- 知识开放怎样仍给创造者回馈？

## 帖子结构

真实问题 → 当前假设 → 最小机制 → 预期反例 → 希望社区挑战的三点。

## 讨论纪律

优先收集漏洞、反例、工程成本和替代方案，不把质疑者归类为不理解项目。
