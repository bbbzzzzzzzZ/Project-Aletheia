# 外部探索讨论稿

本目录保存以发现反例和取得外部反馈为目的的非权威文章。它们不是项目定义入口，也不因公开发布而自动成为已接受结论。

## 当前稿件

- [《一个公共事项，为什么要分成三步？》](公共决定之后还缺哪三步.md)：以夜间急救为生活例子，讨论公共需求归属、具体承担和行动权限为什么不能自动合并，并公开专业能力、预先承诺与退出等未决问题。

公开版本和反馈统一登记到 [`EXTERNAL_FEEDBACK_REGISTRY.md`](../../08_Research_Workbench/07_Validation_Records/EXTERNAL_FEEDBACK_REGISTRY.md)。两篇用户提供外发正文已经保存在 [`Publication_Snapshots/`](../../08_Research_Workbench/07_Validation_Records/Publication_Snapshots/)；它们是历史版本，不作为当前定义源。

当前项目的《一个公共事项，为什么要分成三步？》是吸收反馈后的修订稿，已随 GitHub `v0.3.0` 研究快照公开，并单列为 `PUB-2026-003`；它不是旧版知乎正文，也不表示知乎页面已经同步更新。未来在其他平台重发或编辑旧页面时仍须保留版本记录，不能覆盖历史快照。

公众讨论继续保持 `in-validation`：两份用户提供快照和反馈修订已经入库，但评论时点与正文版本尚不能逐条核对。普通读者评论不能证明制度可行，也不能替代作者审阅、事实核查，以及患者或服务对象、一线人员、照护者和相关实践者复核。
