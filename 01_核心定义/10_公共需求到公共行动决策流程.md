# 公共需求到公共行动决策流程

## 文档定位

本文整理一条从“公共需求形成”到“公共行动执行与复核”的决策流程。

它属于理论层与制度工程层之间的流程模型，不是第一原则，不直接推出任何具体制度，也不确认某种固定治理方式。它的作用是说明：公共需求成立以后，不能直接生成公共权力；必须先公开能力与约束，展开可比较方案，筛掉越过权利边界的方案，再由共同体对方案、成本、缺口和授权边界一并作出决定。

## 一句话核心

公共需求不是命令的来源，而是公共讨论的起点。

一项需求即使具有公共性质，也仍需回答：

- 是否需要公共介入；
- 公共介入需要哪些资源与能力；
- 有哪些可选方案；
- 谁获得权力；
- 谁承担责任；
- 谁支付成本；
- 是否把缺口转嫁给无退出权者；
- 是否越过基本权利边界；
- 如果失败，如何反馈、修正或退出。

## 节点说明

### 1. 环境

公共需求不是凭空出现的。它来自全社会的自然环境、人口结构、技术条件、资源分布、文化习惯、制度安排和历史后果。

因此，公共需求判断不能只看“有人提出了什么”，还要看这个需求是在什么条件下形成的。

### 2. 公共需求形成

公共需求形成，指某些个人需求、群体需求或共同脆弱性开始呈现为公共问题。

这一阶段只说明问题进入公共讨论，不说明任何方案已经正当，也不说明任何公共权力已经完整成立。

### 3. 公共需求成立与公共权力必要性确认

公共需求成立，意味着该需求可能具有共同脆弱性、共同运行必要性或公共影响。

但公共需求成立不等于公共权力已经获得完整授权。它只说明：需要判断是否存在公共介入的必要性，以及公共介入应被限制在什么范围内。

这里必须区分：

```text
公共需求成立
≠
任何公共权力都正当
≠
任何满足方式都正当
≠
可以直接分派个人责任
```

### 4. 能力与约束公开

进入公共行动前，必须公开现有条件：

- 已有人力；
- 可用资源；
- 组织能力；
- 时间约束；
- 技术条件；
- 专业能力；
- 财政或物资缺口；
- 对市场、家庭、上级政府、国际组织或其他外部主体的依赖；
- 当前已有主体正在承担的隐性成本。

能力不足不是失败本身。真正危险的是能力不足却不公开，然后把缺口改写成个人道德失败、家庭责任、劳动者奉献或市场自然结果。

### 5. 方案空间展开

公共系统不能只拿出一个方案，然后要求公众接受。它至少应展开若干可比较方案。

#### 方案 A：内部自建

由公共系统自己建立能力、人员、机构、预算和执行流程。

需要说明：

- 成本是否可承受；
- 能力建设需要多久；
- 是否形成新的官僚系统；
- 如何防止自建系统垄断解释权。

#### 方案 B：外包给市场或社会

由企业、社会组织、专业机构或志愿组织承接部分任务。

需要说明：

- 公共责任是否仍可追踪；
- 服务条件是否可持续；
- 执行者劳动条件是否被压低；
- 市场利润是否挤压第一层和第三层需求；
- 投诉、退出、复核和能力维持责任由谁承担。

外包不是责任消失。公共体系仍需对任务是否具备可持续完成条件负责。

#### 方案 C：多中心联合治理

由公共系统、地方共同体、专业机构、市场主体和受影响者共同参与。

需要说明：

- 各主体权限如何分配；
- 谁负责协调；
- 谁承担最终能力缺口；
- 弱势参与者是否拥有真实表达和退出条件；
- 多中心是否变成无人负责。

#### 方案 D：跨国组织或上级政府借力

当本地能力不足时，可以请求上级政府、跨区域组织、国际机构或外部专业系统协助。

需要说明：

- 外部权力进入的边界；
- 本地共同体保留哪些决定权；
- 借力是否变成依赖；
- 外部标准是否压过本地受影响者经验；
- 退出或结束协助的条件。

#### 方案 E：暂缓或放弃

暂缓或放弃必须保留为合法选项。

如果当前能力不足、代价过高、风险不可控、权利边界不允许，或者会制造比原问题更严重的问题，那么暂缓或放弃不是逃避责任，而是一种诚实决策。

但暂缓或放弃也必须说明：

- 哪些需求会继续未满足；
- 谁将继续承担代价；
- 是否需要临时最低保护；
- 何时重新评估；
- 什么条件改变后可以重启。

## 每个方案都必须公开的账单

每个方案至少列明：

| 项目 | 要回答的问题 |
|---|---|
| 资源账单 | 需要多少人、钱、时间、设备、知识和组织能力？ |
| 成本账单 | 成本由谁承担？是否集中到某些群体？ |
| 权力账单 | 谁获得决定权、管理权、解释权、数据权和执行权？ |
| 责任账单 | 谁承担第一责任、组织责任、执行责任、监督责任和失败修复责任？ |
| 风险账单 | 可能失败在哪里？谁最容易受伤？ |
| 权利边界 | 是否侵犯基本保障、身体、时间、自主、退出和申诉？ |
| 转嫁检查 | 是否把公共缺口推给家庭、低薪劳动者、志愿者、市场底层或无退出权者？ |
| 能力维持 | 人员、资金、训练、休息和监督是否能长期维持？ |

## 权利边界筛选

方案即使有效，也不能因此自动正当。

以下情形应被硬性淘汰或退回修改：

- 以基本保障作为服从交换；
- 无限征用个人时间、身体或家庭责任；
- 把公共责任缺口长期转嫁给无退出权者；
- 把评价工具扩张成人格等级；
- 取消受影响者的知情、申诉、复核和退出；
- 用公共目的掩盖不可逆伤害；
- 让执行者承担责任，却不给资源、权限和安全条件。

## 授权缺口检查

有能力不等于有权力。

有公共目的也不等于可以越过授权。

因此，在公共选择之前，必须标注：

- 哪些行为已有正当授权；
- 哪些行为需要新增授权；
- 哪些权力不得授予；
- 哪些权力只能临时授予；
- 哪些权力需要更强同意、补偿或复核；
- 哪些部分即使有多数支持也不能越过基本权利。

授权缺口不能被能力、效率、紧急性或道德正确感自动填补。

## 公共选择与具体授权

公共选择不是只选择“做不做”，而是同时选择：

- 采用哪个方案或方案组合；
- 接受哪些成本；
- 承认哪些缺口；
- 谁获得哪些具体权限；
- 谁承担哪些具体责任；
- 谁拥有监督、复核和暂停权；
- 多久后重新检查。

如果方案被否决、条件变化、资源不成立或授权无法完成，应进入反馈修正，而不是绕过程序强行执行。

## 执行

执行阶段只能在授权范围内行动。

执行中如果出现资源变化、风险扩大、任务偏离、受影响者状态变化、执行者过载、外部依赖失效或新问题，应触发反馈修正。

执行不能以“已经决定”为由吞掉现实变化。

## 结果与主体一致性复核

复核采用[诊断与反证方法](../00_先读这里/05_反证条件与测试方法.md)中的“联系有效／局部联系失效／材料不足”判断。主体分工本身不构成断裂，服务不足也不能直接证明责任转嫁；先检查决定、履责条件、质疑与回应的联系，再单独评价实际服务和负担。

复核不只问结果是否完成，还要问：

- 原始需求是否被回应；
- 权力主体是否越权；
- 责任主体是否承担了相称责任；
- 成本是否被转嫁；
- 执行者是否过载；
- 受影响者是否仍有申诉和退出；
- 公共系统是否公开了真实缺口；
- 是否产生新问题。

如果需求主体、权力主体、责任主体和成本承担者之间的关系无法追踪、无法质疑、无法纠错，说明主体链出现断裂。

## 反馈修正

反馈修正不是失败后的装饰环节，而是公共行动的一部分。

反馈可能导致：

- 重新识别需求；
- 重新公开能力缺口；
- 修改方案；
- 缩小授权；
- 暂停执行；
- 补偿受损者；
- 更换承接主体；
- 承认无法满足；
- 产生新的公共需求。

因此，公共行动不是一次性闭环，而是持续接受现实检验的暂时安排。

## 未决问题

- 公共需求成立的最低标准如何设定，才不会把私人需求随意公共化？
- 能力与约束公开到什么程度，才既能监督又不制造不必要的信息风险？
- 方案空间展开需要多少替代方案，才不至于拖延紧急行动？
- 暂缓或放弃的正当条件如何判断？
- 多中心联合治理中，最终能力缺口由谁承担？
- 当公众选择了较低成本但较差服务的方案时，如何保护无退出权者？
- 跨区域或跨国协助怎样避免形成新的支配关系？
- 结果复核如何避免只看指标，而不看主体是否被牺牲？
