# 01_核心定义

这一层保存当前仍然承认的正式定义。

如果 `00_先读这里` 是“我到底在说什么”，这一层就是“这些话在项目内部怎样被精确定义”。

## 文件说明

- [第一原则.md](第一原则.md)：补齐的完整规范正文；十一项公理和禁区按冻结说明使用。
- `01_第一原则_v1.0_语义冻结.md`：当前第一原则的冻结范围和变更纪律。
- `02_需求归属与公共需求责任.md`：私人需求、公共需求、组织需求等责任归属问题。
- `03_需求模型.md`：需求分类与五层需求框架。
- `04_责任模型.md`：第一责任、执行责任、组织责任、配合责任等区分。
- `05_权力模型.md`：自主权、协作权、事实权力和授权权限。
- `06_资源模型.md`：资源、公共资源、分配与边界。
- `07_决策模型.md`：公共决定、受影响者和程序问题。
- `08_哲学理论基础与制度推论.md`：从哲学判断到制度推论的当前表述。
- `09_术语表.md`：术语索引。
- `10_公共需求到公共行动决策流程.md`：公共需求成立后，如何公开能力、展开方案、筛选权利边界、检查授权缺口、执行与复核。

## 使用规则

这一层可以精确，但不应该替代人话版。

如果一个正式定义读起来过重，应先回到 `00_先读这里`，确认它到底是在回答哪个普通问题。
