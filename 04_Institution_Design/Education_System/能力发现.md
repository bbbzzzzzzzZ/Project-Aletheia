# 能力发现

## 原则

能力发现是让人接触多种活动、获得反馈并选择是否继续发展的过程，不是尽早给人贴上终身标签。

它首先服务本人认识可能方向、学习和实现自己的想法与需求，不以向公共任务系统输送人力为首要目的。

## 个人能力图谱

探索可以形成一份默认私有、由本人控制的个人能力图谱。它不是完整人格档案，也不是职业结论，可以记录：

- 本人观察到的兴趣、需求和希望继续探索的方向；
- 具体实践证据与外部反馈；
- 已形成能力、学习过程、适用条件与不确定项；
- 本人暂不愿发展、公开、被联系或使用的范围。

本人观察与外部认证应分栏；本人可以修订、删除、拒绝评价或停止记录。个人能力图谱不自动进入就业、福利、政治或公共责任系统。

## 机制方向

- 提供低门槛、多领域、可重复尝试的实践机会；
- 记录具体任务中的证据，不用职业名称概括整个人；
- 同时呈现兴趣、熟练度、学习速度、环境条件和个人意愿；
- 认证可更新、可失效、可通过多条路径获得；
- 允许人暂停、转向、失败和重新开始；
- 能力信息由本人控制用途，不自动进入公共调用名单。

## 与公共任务的接口

只有本人对具体能力字段、证据、查看者、任务用途、联系范围和期限另行授权后，最小必要信息才可进入劳动模块的 [`能力池`](../Labor_System/能力池.md)。进入能力池只允许形成任务匹配邀请；本人仍须对每项任务另行接受或拒绝。

```text
能力发现 → 个人能力图谱（默认私有） → 细粒度授权 → 公共能力池
```

## 风险

- 测评把当前资源差异伪装成天赋差异；
- AI 推荐形成自我实现的限制；
- 稀缺教育资源只投资“高潜力者”；
- 能力标签变成身份、就业和政治资格。

## 待验证

怎样在不浪费高风险训练资源的同时，为新人和非典型学习者保留进入路径？
