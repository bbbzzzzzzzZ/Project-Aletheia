# Education System

本模块回答：如果人的人生属于自己，教育如何在一生中帮助人认识需求、理解世界、发展能力并参与共同生活，而不是预先把人分配到职业和身份。

本模块继承 [`人是什么`](../../00_Core_Question/人是什么.md)、[`人真正需要什么`](../../00_Core_Question/人真正需要什么.md)、[`第一原则`](../../03_Aletheia_Framework/第一原则.md) 与 [`需求模型`](../../03_Aletheia_Framework/需求模型.md)，并用教育实践检验“本人需求表达”和“不得替人定义幸福”是否可行。

核心阅读顺序：[`教育目标.md`](教育目标.md) → [`生命周期教育.md`](生命周期教育.md) → [`自我认识教育.md`](自我认识教育.md) → [`能力发现.md`](能力发现.md) → [`教育制度设计.md`](教育制度设计.md)。

其中《自我认识教育》负责区分个人意义、共享叙事、事实解释与公共理由，并训练对“宣称价值—实际激励”的辨识；《教育制度设计》负责让学习者及其他受影响者进入规则、资源、原型和效果评价的共同设计，而不是只接受安排。

## 当前问题稿

- [`儿童公共照护与成长自主.md`](儿童公共照护与成长自主.md)（`question`）：研究公共支持、家庭责任、稳定依恋与儿童逐步扩大的表达／拒绝／选择如何并存；明确排除儿童公共资产化、统一机构养育和父母人生所有权。

问题稿用于标记需要研究和试验的边界，不表示本模块已经选择某种统一照护制度。
