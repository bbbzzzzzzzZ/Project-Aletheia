# 儿童公共照护与成长自主

## 文档定位

本文建立问题边界，不提出统一养育方案。它研究公共支持怎样减轻儿童和家庭面临的照护风险，同时保护稳定关系、家庭责任与儿童逐步增长的表达、拒绝和选择能力。

历史聊天中的公共照护设想只能产生研究问题，不能证明某种共同养育模式已经有效。儿童不是公共资源，照护者也不是可持续调用的人力；任何试验都必须从儿童安全、关系连续、自愿参与、最小干预和可用救济出发。

## 一、为什么需要单独研究

如果照护完全被当作家庭私事，儿童获得的安全、教育和支持可能过度取决于家庭资源；长期照护也可能默认集中给某一位母亲、父亲、亲属或低报酬劳动者，使其退出工作、学习和社会生活。

如果公共机制直接接管家庭，又可能把支持变成机构化管理，削弱稳定依恋、个体差异和家庭关系，并以儿童保护之名取得对其生活目的的决定权。

因此，本议题不在“完全家庭化”和“完全公共化”之间二选一，而是同时追问：

- 哪些基本条件应由共同体保证，不取决于家庭财富与服从；
- 家庭成员必须承担哪些保护、陪伴和照护责任；
- 怎样让照护责任不永久压在某一个人身上；
- 儿童怎样随能力发展逐步参与关于自己生活的决定；
- 公共支持怎样补充而不吞并稳定关系；
- 发生忽视、暴力、控制或机构伤害时，谁能及时保护、复核与修复。

## 二、必须同时成立的边界

### 1. 公共支持不等于公共所有

儿童获得住所、营养、健康、教育、游戏、关系和保护的条件，可以由共同体共同保障；但出资、服务和保护责任不产生对儿童身体、身份、信仰、能力或未来人生的所有权。

不得把儿童描述为“公共资产”“未来人力”或制度投资回报。儿童的基本保障不以未来贡献、服从、展示能力或参与公共任务为条件。

### 2. 家庭责任不等于人生所有权

父母和其他照护者对儿童负有保护、陪伴、基本照护、寻求帮助和避免伤害的责任。责任不自动转化为替儿童永久决定信仰、亲密关系、职业、身份和生活目的的权限。

家庭对儿童的重要性也不能被抽象化为某一种固定家庭结构。评价重点应是关系是否安全、稳定、可依赖、尊重儿童，并存在外部支持和救济。

### 3. 稳定依恋不等于单一照护者独占

儿童可能需要少数稳定、可预测、持续回应的关系。公共支持应减少关系中断和照护耗竭，而不是用不断轮换、匿名管理或流水线服务替代稳定依恋。

同时，稳定关系也不意味着所有照护只能由一个家庭成员无偿提供。家庭、可信赖的亲友、专业照护者、学校和社区支持可以形成有边界的支持网络，但必须让儿童知道谁在负责、怎样求助以及关系变化时如何过渡。

### 4. 成长自主是逐步发展的行使能力与决定参与空间

儿童的人格与基本权利不由年龄、能力考试或机构逐步授予。随儿童的理解、表达、情境和决定影响而变化的，是权利的行使方式、支持强度、决定参与权重与保护程序。制度应逐步扩大其可实际使用的空间：

- 获得适龄信息并提出问题的机会；
- 表达喜欢、不适、恐惧、关系需要和生活目标的渠道；
- 拒绝非必要接触、展示、研究和公共活动的可行渠道与实际支持；
- 在日常安排、学习、隐私、社交和身份表达中的选择范围；
- 对影响较大的决定获得支持、独立意见、复核与申诉的机会。

“逐步扩大”不能退化为单一年龄表或能力考试。决定的风险、可逆性、时间紧迫性、第三方影响和儿童本人的理解均需分别判断。儿童意见具有应被认真回应的地位，但不要求儿童独自承担成人和公共机构的保护责任。

## 三、表达、拒绝与支持性决定

儿童的沉默、顺从、依赖或无法离开，不能自动解释为同意。本人暂时无法清楚表达时，应使用熟悉且可理解的沟通方式、可信任支持者、替代与辅助沟通，并观察持续的舒适、抗拒和关系变化。

不同事项需要不同门槛：

| 事项 | 最低边界 |
|---|---|
| 日常生活与学习选择 | 尽量由儿童直接选择，说明现实限制并提供替代 |
| 公开展示、采访、研究与数据使用 | 明确说明用途，允许拒绝和撤回，不以教育或服务为条件 |
| 医疗、照护与安全措施 | 提供适龄解释，听取儿童意见；必要代理须范围最小并可复核 |
| 信仰、身份与长期人生方向 | 不以家庭、学校或机构权威提前固定；随成长保留接触多种信息和修订空间 |
| 高风险或不可逆决定 | 需要更强的独立专业意见、利益冲突披露、冷静期与救济；具体标准待研究 |

“为了你好”不能替代说明、倾听和最小限制。儿童拒绝某个活动、照护者或机构时，至少应记录理由、检查伤害和利益冲突，并提供不依赖原决定者的求助入口。

## 四、公共支持的候选范围

以下只是需要比较和试验的支持模块，不是默认由同一机构集中提供：

- 可负担的托育、课后支持、临时替代和家庭喘息服务；
- 营养、健康、心理支持、特殊需要适配与紧急保护；
- 面向家庭成员的照护知识、经济支持和休息安排；
- 儿童可直接使用的适龄信息、保密求助、独立倡导与申诉；
- 支持亲友、邻里和专业人员参与但不模糊责任人的关系网络；
- 家庭发生疾病、失业、迁移或危机时，尽量维持儿童住所、学校与稳定关系；
- 对长期承担照护者的劳动条件、报酬、安全、监督和更换机制。

每种方案都须比较家庭内支持、分散服务、社区节点和机构服务的效果，不能因行政管理方便而默认集中安置。

## 五、自愿参与与试验边界

公共照护项目进入试验前至少应满足：

- 家庭获得真实可选的替代方案，不以领取基本保障换取参加；
- 儿童得到适龄说明，持续表达不适或拒绝时有独立复核；
- 参加、退出、投诉和更换服务不会导致住所、教育、医疗和家庭支持中断；
- 服务提供者、效果评估者、监督者和申诉处理者不得由同一主体全部控制；
- 不以标准化人格、统一作息、统一信仰或“便于管理”消除个体差异；
- 数据收集最小化，儿童影像、经历和能力信息不被用于宣传、评分或未来调度；
- 先确定停止、过渡和关系修复方案，再扩大规模。

家庭同意不能覆盖儿童能够表达的持续反对，儿童的即时同意也不能免除成人对安全和剥削风险的审查。两者冲突时需要独立、有限且可复核的支持性决定程序，具体机制仍待研究。

## 六、反机构化压力测试

| 假设情境 | 必须检查 |
|---|---|
| 公共项目规模扩大、照护者频繁轮换 | 儿童能否保持少数稳定关系，谁对关系中断和过渡负责 |
| 家庭拒绝项目的价值观或课程 | 儿童是否仍获基本服务，家庭退出是否损害儿童的信息与求助权 |
| 儿童拒绝被展示、评估或参加集体活动 | 拒绝是否真实可行，是否因此受到惩罚、标签或资源降级 |
| 项目宣传“共同培养未来人才” | 是否把儿童能力、劳动和未来贡献当作公共回报 |
| 家庭资源少或照护者需要工作 | 公共支持是否成为事实上的强制安置，是否存在居家与分散支持 |
| 儿童改变信仰、兴趣或身份表达 | 住所、照护、家庭联系和教育机会是否保持稳定 |
| 家庭或机构被投诉伤害 | 儿童能否绕开被投诉者求助，保护与事实认定是否及时且独立 |

## 七、立即停止与修复条件

出现以下任一情形，应暂停相关项目或权限并启动独立保护与复核：

- 以儿童属于集体、家庭或机构为由否认其人格与基本权利；
- 强制离开家庭，或反过来以家庭完整为由放任持续伤害；
- 依赖匿名轮换、隔离和统一管理，导致稳定关系持续中断；
- 以基本住所、营养、医疗或教育惩罚家庭及儿童的拒绝、退出或投诉；
- 强迫儿童劳动、表演、公开身份、接受信仰或参加研究；
- 公共照护的运转依赖某些家庭成员或低权力照护者无期限、无支持地牺牲；
- 机构同时控制照护、教育、数据、评估、监督、申诉与全部证据。

停止项目不能简单把儿童和照护责任退回原家庭。必须继续保障安全住所、照护、教育、医疗和稳定关系，保存证据、解释变化、提供过渡，并对已经造成的伤害承担修复责任。

## 八、未决问题

- 哪些照护条件属于每个儿童的公共底线，如何避免地区和家庭资源决定差异？
- 家庭照护责任、机构公共组织与维护责任、专业责任和有能力成员的有限互惠公共责任分别如何限定，责任缺位时谁先保护、谁后追责？
- 儿童的意见在不同风险和可逆性决定中应具有什么权重？
- 如何评估稳定依恋和关系连续，而不规定单一家庭或照护模式？
- 怎样支持家庭照护者继续工作、学习和休息，又不把儿童当作待安置负担？
- 如何让儿童拥有独立求助渠道，同时防止机构以保护为名扩大监控和接管？
- 公共照护怎样与主体社区、共同学校及跨社区生活连接，避免形成儿童隔离区？
- 哪些试验可以小规模、可逆地开展，哪些风险不应通过试验来学习？

## 九、已确认的家庭与儿童制度接口

`D-020` 已确认生育、婚姻、亲职与儿童权利不得相互自动推出：生育决定属于孕育者的身体自主；婚姻不自动产生生育义务、亲职资格或儿童支配权；亲职围绕儿童利益、稳定关系、现实照护和非伤害边界形成；儿童是独立权利主体；公共育幼分担照护压力但不取得儿童所有权。

本文件继续负责公共照护的风险、试验和反机构化问题；专题原则入口见 [`生育、婚姻、亲职与儿童保障分离原则.md`](生育、婚姻、亲职与儿童保障分离原则.md)。具体亲职审查、探望、住房、记录、公共育幼和替代照护参数仍保持开放。
