# 激励制度

本模块的反等级与公共合作激励方向已经由项目发起者确认；具体激励方式和效果仍待研究。

- [`激励反等级原则.md`](激励反等级原则.md)：贡献、记录和便利不得生成公民等级。
- [`公共合作激励与参与保障.md`](公共合作激励与参与保障.md)：合作怎样改善需求、时间、安全与服务，并保护拒绝、异议和举报。
- [`责任积分、贡献积分与领域专业评价.md`](责任积分、贡献积分与领域专业评价.md)：用三套记录、四层功能实现年度责任结算、领域贡献累计、质量评价和领域专业参考，并限制衡量结果的用途。
