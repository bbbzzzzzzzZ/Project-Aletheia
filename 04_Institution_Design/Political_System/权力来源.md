# 权力来源

## 当前命题

基本权利是公共决定必须尊重的规范边界和参与资格，不是机构授予授权权限的来源。正当公共权限来自可追溯的公共决定与授权程序，用于有限任务或特定公共职能，并受事项、对象、能力、行为、资源、期限、复核和退出约束。它不来自财富、血缘、职业、知识、贡献、武力事实或“更理解人民”的自我宣称。

未经授权却能够显著或持续地非对称控制身份入口、议程、数据、资源、评价或救济的事实权力，也必须单独识别；没有正式头衔不等于没有权力，存在实际控制也不等于获得正当授权。

任务授权是正当权限来源进入具体任务、形成执行权限封套的通用过程，不只来自公共授权。普通自愿任务可以依据合同、资源权利人同意或组织内经正当限定的角色授权；公共任务则必须依据公共决定或公共职能授权形成公共任务授权。无论来源为何，现实能力、能力证据、任务资格、承担依据与执行权限都须分别成立。

## 制度形成与公共职能授权

```text
重复、结构性、跨主体或高后果问题
→ 识别需求来源与合理可发现的实质受影响者
→ 审查基本权利、事实权力、证据、替代方案和不行动后果
→ 通过事项适配程序作出暂时公共决定
→ 向明确机构或任职角色授予特定公共职能
→ 有限试行、监督、异议、申诉与周期复核
→ 继续 / 修订 / 撤销 / 日落，并审计残留事实权力
```

持续公共职能可以跨越单个任务，但任职者仍须明确接受角色，权限必须按周期重新审查。规则或机构存在不能直接调用某个执行者。

## 普通自愿任务授权

```text
在现行规则下形成任务封套
→ 现实能力与任务资格匹配、邀请
→ 每名承担者知情承诺
→ 分别授予任务所需的有限权限
→ 执行、监督、申诉、验收与交接
→ 任务关闭，权限退出；既有修复责任保留
```

## 有限公共责任任务授权

```text
公共必要任务与机构先行责任成立
→ 公平分配范围与合理份额审查
→ 个案通知，审查现实能力、任务资格、健康、照护、时间、地点、风险和条件
→ 换班 / 延期 / 替代 / 豁免 / 异议 / 独立申诉
→ 个案责任决定
→ 分别授予任务所需的有限权限
→ 执行、监督、交接、退出与修复
```

该分支的责任来源不是虚构的本人同意，但非本人承诺也绝不等于无程序派工。公共必要性、机构供给责任、成员身份、能力记录或服务缺口都不能单独产生执行权限。紧急例外仍须使用另行规定的更高门槛分支，不得用有限公共责任常态化紧急权力。

## 三种正当性不能混为一谈

- **目标正当性**：问题与目标是否来自并尊重受影响者。
- **程序正当性**：授权、参与、信息、少数保护和救济是否成立。
- **结果与能力正当性**：方案是否可行、相称并产生可接受结果。

其中任何一项都不能独自替代另外两项。

## 未决问题

- 基本权利的内容与修订程序；
- 多层共同体之间的授权与冲突；
- 无法直接参与者和未来世代如何被保护；
- 国家暴力与最终强制的边界；
- 长期公共机构如何保持连续而不形成永久身份权力。
