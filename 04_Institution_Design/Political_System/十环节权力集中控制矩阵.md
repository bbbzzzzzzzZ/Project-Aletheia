# 十环节权力集中控制矩阵

本矩阵的十环节、三级风险、自动纠偏和紧急例外方向已经由项目发起者确认。它是识别公共项目事实权力集中的框架，不是已经验证的组织法、统一分数或机构数量要求。

## 一、审查对象

矩阵审查的不是一个主体有多少职位名称，而是其能否直接或间接决定、阻止、筛选、延迟、修改或隐藏关键环节。任命与考核、预算依赖、数据和系统权限、合同控制、唯一入口、否决能力及报复能力都属于实际控制证据。

“同一主体”包括个人、机构及受共同实际控制、共享重大利益或能够协调行动的关联主体。把同一控制网络形式上拆成子公司、承包商、代理人或多个部门，不构成真实分权。

## 二、十环节

| 编号 | 关键环节 | 核心问题 | 原则责任 | 必须保留的分离 |
|---|---|---|---|---|
| ① | 议题入口 | 什么问题进入公共决策？ | 公众、受影响者及合法需求提出入口 | 不由项目执行者或重大受益者垄断 |
| ② | 信息形成 | 哪些事实、数据和预测进入决定？ | 专业与信息提供者，接受来源和反证审查 | 不由执行者或利益受益者最终自证 |
| ③ | 方案制定 | 怎样解决问题，有哪些替代？ | 专业团队、规划者及受影响者共同设计 | 与最终批准及重大直接利益保持复核距离 |
| ④ | 预算与资源配置 | 投入多少、资源给谁？ | 获得限定授权的财政或资源配置程序 | 与执行者、供应商及重大受益者分离 |
| ⑤ | 项目执行 | 谁把方案转化为行动？ | 项目责任单位和具体执行者 | 与独立质量验证、投诉和正式监督分离 |
| ⑥ | 质量记录与验证 | 实际发生了什么，是否达到标准？ | 执行者产生原始记录；独立质量职能验证完整性和结果 | 不允许执行者独占最终质量认证或删除原始记录 |
| ⑦ | 投诉与反馈入口 | 谁能提出问题，问题是否真实进入系统？ | 内部渠道加外部独立入口 | 被投诉对象不得成为唯一入口或删除记录 |
| ⑧ | 监督与审计 | 是否越权、失职、浪费或隐瞒？ | 独立监督、审计及必要的联合审计 | 与被监督对象及其控制网络分离 |
| ⑨ | 事实调查与责任认定 | 事实如何查明，责任由谁裁决？ | 调查者形成证据与事实报告；独立裁判者作最终责任决定 | 高后果事项中调查与最终裁判不得由同一主体完成 |
| ⑩ | 贯穿式利益控制 | 谁会从各环节的决定和结果中获得重大利益？ | 持续利益申报、受益所有权识别、回避与利益冲突审查 | 具有重大利益者不得参与相关最终批准、监督、定责或追缴决定 |

⑩不是只在项目末尾检查一次的普通环节。项目启动、议题进入、预算、采购、变更、验收、追偿和利益追缴都须重新检查利益关系。依法公开的正常工资、固定公共报酬或与决定结果无关的一般待遇，不单独构成重大利益冲突；未披露的关联交易、受益所有权、资产增值、债权债务、回扣及能显著影响公正履职的关系进入审查。

## 三、运行、质量与监督

现场运行负责人回答“现在怎样安全、连续地完成任务”，可以在授权封套内协调流程、调用既有资源、记录异常、组织纠正并暂停即时危险操作。

现场质量职能回答“记录是否真实、过程是否稳定达到标准”，可以巡查、抽样、验证原始记录、分析趋势、要求纠正计划和复查结果，并可绕过运行负责人上报重大风险。巡回是一种任务和方法，不必形成永久身份。

独立监督回答“是否存在越权、侵害、隐瞒或责任逃避”，不接管日常排班、项目预算或一般流程管理。三者可以共同发现和记录问题，但日常指挥、最终质量自证、独立调查和责任裁判不得集中。

## 四、三级风险

### 一级：普通职责重叠

同一主体承担两个相邻且低风险的运行环节，例如执行与日常流程协调，可以在任务规模和资源条件确有必要时保留，但须有明确责任线、不可删改的原始记录、外部抽查和独立投诉入口。

### 二级：高风险重叠

以下组合直接触发职责与利益回避审查、权限拆分方案和独立复核：

- 议题入口 + 信息形成；
- 预算配置 + 项目执行；
- 项目执行 + 最终质量验证；
- 项目执行 + 唯一投诉入口；
- 监督审计 + 最终责任认定。

审查可以证明某项有限重叠在当前规模下确有必要，但必须提出功能性替代保障，不能只说明“机构不同”。

### 三级：关键权力集中

同一主体或关联控制网络同时控制三个及以上实质独立环节，原则上触发外部联合审计和权限拆分。控制四个及以上环节，或者控制下列任一组合，应强制拆分、回避或暂停相关权限，不能由该主体自行决定是否审计：

- 议题 + 预算 + 执行；
- 信息 + 执行 + 最终质量验证；
- 执行 + 投诉 + 监督；
- 预算 + 执行 + 重大自身利益；
- 执行 + 监督 + 重大自身利益；
- 议题 + 预算 + 执行 + 重大自身利益。

环节数量只是触发器，不是“权力集中度总分”。审计仍须分析每一环节的实际控制强度、可替代性、持续时间、影响范围、退出成本和关联网络，不能以机械计数直接认定违法或个人责任。

## 五、自动纠偏

| 控制组合 | 最低自动措施 |
|---|---|
| ① + ② | 信息来源、遗漏和反证独立复核 |
| ② + ③ | 方案和替代方案外部专业复核 |
| ③ + ④ | 财政与利益关系独立审核 |
| ④ + ⑤ | 联合批准、预算跟踪与外部抽查 |
| ⑤ + ⑥ | 独立质量验证、原始记录保全 |
| ⑤ + ⑦ | 外置投诉入口和不可由执行者删除的投诉记录 |
| ⑤ + ⑧ | 外部监督及必要的权限暂停审查 |
| ⑧ + ⑨ | 调查事实与最终责任裁判分离 |
| 任一环节 + ⑩ | 重大利益门槛审查、披露、回避或外部复核 |
| 三个及以上环节 | 外部联合审计和权限拆分方案 |
| 四个及以上环节 | 原则上强制拆分；不能拆分时暂停新增授权并采用更强替代保障 |

发现重大投诉、记录删除、质量数据异常或报复线索时，应与证据保全、替代调查和举报保护机制连接。

## 六、小规模组织和连续性例外

分权不以增加永久机构数量为目标。小规模、偏远或高连续性任务无法由不同人员承担全部环节时，可以使用双人确认、跨单元轮换验证、外部抽样、原始记录镜像、公开理由、独立投诉和定期复核等功能性分离。

任何例外须说明无法分人的客观理由、保留了哪些替代保障、持续期限和扩大能力后的拆分计划。不得以人员不足永久取消外部投诉、记录保全、利益回避或高后果责任裁判的独立性。

## 七、紧急状态

紧急状态确需暂时合并权限时，必须事前或在最短时间内记录危险、合并环节、适用对象、地域、权限范围、不可触碰事项、最短期限、实时监督、补偿、复核和自动解除。每次延长重新授权；紧急结束后进行外部审计、证据和数据访问审查及损害修复，不得把临时合并转为常态职位资产。

## 八、停止线与待验证问题

停止线：

- 用不同机构名称掩盖同一控制网络；
- 让执行者自采、自释并最终认证自身绩效；
- 让被投诉机构成为唯一投诉入口；
- 让调查者同时作高后果最终裁判；
- 把正常公开报酬一概认定为腐败，或反过来以“正常关系”隐藏重大关联利益；
- 以分权为名制造无人负责、无法行动或无限程序循环；
- 以紧急、规模小或人员不足永久豁免纠偏。

待验证问题：不同任务风险如何调整触发门槛；关联主体如何识别；质量人员的任命、预算和安全如何独立；外部审计怎样及时且不形成新中心；自动措施怎样避免瘫痪服务；矩阵怎样与项目生命周期、财政、证据和紧急机制共同演练。
