# Political System

本模块研究：在个人需求由本人优先表达、解释和修订，而一项满足方案的实质受影响者均保有知情、参与、异议、监督和救济资格的前提下，共同需求、代表、决策和执行权限怎样形成，又如何防止“代表需求”变成“拥有人民”。

受影响者的参与资格针对方案、共同资源、可接受风险和第三方后果；它不使受影响者成为他人第一人称需求的所有者，也不使多数意见取代当事人表达。

公共决策可以对机构、运营者、出资者和其他明确角色设定职责与程序，但规则成立不等于某个人已经承诺普通自愿任务，也不等于有限公共责任任务已经完成个案分配。项目确认有能力成员原则上承担有约束力但有限的互惠公共责任；其具体落实必须另行说明任务必要性、机构先行责任、公平分配、能力与条件、换班、延期、替代、豁免、异议、申诉和限定授权，不能藏在一般制度模板里。基本保障不得与履责挂钩。
