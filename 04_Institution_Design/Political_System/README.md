# Political System

本模块研究：在个人需求由本人优先表达、解释和修订，而一项满足方案的实质受影响者均保有知情、参与、异议、监督和救济资格的前提下，共同需求、代表、决策和执行权限怎样形成，又如何防止“代表需求”变成“拥有人民”。

受影响者的参与资格针对方案、共同资源、可接受风险和第三方后果；它不使受影响者成为他人第一人称需求的所有者，也不使多数意见取代当事人表达。

公共决策可以对机构、运营者、出资者和其他明确角色设定职责与程序，但规则成立不等于某个人已经承诺普通自愿任务，也不等于有限公共责任任务已经完成个案分配。项目确认有能力成员原则上承担有约束力但有限的互惠公共责任；其具体落实必须另行说明任务必要性、机构先行责任、公平分配、能力与条件、换班、延期、替代、豁免、异议、申诉和限定授权，不能藏在一般制度模板里。基本保障不得与履责挂钩。

## 正式参与不能由私域影响替代

一个人在家庭、照护关系、经济活动或非正式网络中能够影响他人，不等于其公共参与权已经获得制度保障，也不等于其具备实际行使这些权利的条件。象征性的尊崇、家庭内资源安排或依赖关系中的事实影响，也不能替代公开的信息、提案、证据提交、代表、任职、异议、申诉和救济资格。

反过来，纸面上的平等入口也不能单独证明真实参与已经成立。还须检查：

- 本人是否有可理解信息、时间、安全、行动条件与必要支持；
- 能否提出议题和证据，而不只在别人设定的问题里表达偏好；
- 能否竞争正式角色、质疑决定、请求救济并防止报复；
- 家庭成员、照护者、专家或代表的意见是否补充本人表达，而不是冒充本人统一意见；
- 非正式控制是否会绕过公开程序，正式程序是否又忽略关系中的真实依赖与退出成本。

这是一项跨场景研究边界，不是对任何性别、家庭、宗教、文化或历史时期的既定结论。具体比较必须限定法域、时期、群体与权利内容，并同时寻找反例。
