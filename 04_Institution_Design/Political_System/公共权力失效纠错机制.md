# 公共权力失效纠错机制

本文件的纠错方向已经由项目发起者确认；调查门槛、机构组成、基金规模、证据规则、追偿时效和利益计算仍须法律研究、受影响者参与与压力测试。

## 总原则

任何公共权力不得同时控制决定、证据、监督、修复与利益。任何一环失效时，其他独立入口必须能够取得事实、启动调查、保护受影响者、完成必要修复并追回经正当程序认定的不当利益。

项目、任期与执行权限结束，不自动消灭已经发生的说明、证据保存、调查、赔偿与修复责任；这不等于无限期政治追责。责任仍须依据证据、控制力、因果关系、可预见性、主观状态、程序与适当时效分别认定。

纠错机制启动前后的权力集中使用 [`十环节权力集中控制矩阵.md`](十环节权力集中控制矩阵.md) 检查。尤其不得让执行者同时控制最终质量记录和唯一投诉入口，也不得让监督者同时完成事实调查、高后果最终裁判和自身利益分配。

## 一、外部证据取得

重大公共项目应持续产生决策、预算、合同、风险、专业意见、变更、监督和验收记录，并区分：

- 原则上主动公开的公共记录；
- 因隐私、商业秘密、调查安全或依法保密而限制公开，但仍须接受独立监督的受保护记录；
- 调查无法合法取得时，须经司法或其他法定独立程序强制取得的记录。

受保护证据不得只由被调查机构控制。托管应分散风险，采用完整性校验、分级访问、访问留痕、纠错与保存期限，避免产生一个掌握全部敏感信息的新事实中心。

合理怀疑足以申请初步调查和限事项、限证据类型、限期限的证据保全，但不构成责任认定。举报者应说明已知事实、时间、相关主体、异常和可能的证据位置；不得要求其先取得只有掌权者能够取得的完整证据。善意举报应受保护，骚扰性或重复申请由公开的分流程序处理，不以压制异议替代审查。

故意删除、修改、转移或隐匿已知与争议直接相关的受控证据，应承担独立的证据妨碍责任。事实无法查明时，可以结合控制能力、删除时间、主观状态与其他证据分配证明风险或作相称不利推定，不得自动推定有罪。

## 二、替代调查

监督独立是一项须持续维护的条件，不是永久事实。重大举报长期不处理、明显利益冲突、拒绝保全关键证据、调查记录遭篡改或多个独立信号共同指向同一异常时，应允许受影响者、公民、专业人员、其他监督机关、审计或司法入口申请替代调查。

替代调查组应按具体事项临时组成，调查权限随案产生并在交接后终止。能力池与随机抽取本身不足以证明独立；还必须有来源多样、利益冲突排除、经费与人身安全保障、完整过程记录和外部复核。

调查者可以取得事项相关记录、询问人员、检查财政和监督记录、申请强制取证或临时保护并提交报告；不得同时自行处罚、裁判和决定最终赔偿。原监督与替代调查均失效时，应保留多个法定申请入口、公开不受理理由和复核渠道；司法授权也是受约束的调查入口，不被假定为永不失效。

## 三、先行修复与后续追偿

受害者的紧急医疗、基本住所、必要生活、安全保护和恢复支持，不应等待责任人具备赔偿能力后才开始。公共先行修复基金可以先处理必要修复；完整损害额与最终责任仍须经调查、协议或裁判确认。

必须分开维护：

- 受害者修复账户：已经获得、仍然需要和无法恢复的损害；
- 责任追偿账户：各责任主体应负份额、已追回金额、可执行财产与法定终止条件。

基金来源、支付优先级、风险分担、年度审计和资金不足方案必须公开。未知责任人、尚未查明责任、无法归责事故与自然灾害不得混为一种情形；先行救助不使事实调查自动停止。

追偿只能针对责任人本人的可处分财产和收入，保留基本食物、住所、医疗与必要生活条件，并依据故意、重大过失、一般过失和合理错误分别处理。应另行研究时效、破产或重新开始机制。继承人不承担超出责任人遗产范围的个人债务。

不得以公共责任劳动、专门劳动或基本保障交换赔偿。责任人可以自愿从事正常有报酬劳动，再依法从可处分收入追偿；不得形成债务劳动。

## 四、不当利益追缴

重大公共项目应记录与项目结果直接相关的实际控制、受益所有权、重大投资、债权债务和合同关系。申报分为依法公开与受保护部分，只收集判断重大利益冲突所需的信息，不公开无关家属隐私。

重大利益冲突应在决定前触发回避。项目失败不自动证明腐败，也不自动没收财产；正常、公开且未利用职务影响的收益不追缴。利用内幕信息、职务影响、关联交易、贿赂、欺诈或故意制造失败取得的利益，须经正当程序认定后追缴。

追缴对象是与公共权力滥用具有可说明因果关系的不当利益增量，而不是全部财产。计算须说明举证责任、收益与成本、代持或关联关系以及善意第三人保护。

临时资产保全须达到法定事实门槛，经独立审查，限于相关范围并保留基本生活、正常经营和申诉所需财产。追回利益优先修复受害者和公共损失，再支持必要制度修复；调查人员不得按追回金额提成。

## 五、连接后的纠错链

```text
项目责任与利益档案
→ 执行、监督和异常发现
→ 证据保全与外部取得
→ 必要时启动替代调查
→ 独立责任与利益认定
→ 受害者先行修复
→ 责任追偿与不当利益追缴
→ 项目和制度修正
```

## 停止线

- 以保密为由让证据彻底脱离监督；
- 以合理怀疑直接代替责任认定；
- 建立集中掌握全部敏感证据且不可外部审计的新机构；
- 让调查、裁判、处罚和收益分配由同一主体完成；
- 因责任人无力赔偿而延迟受害者的必要生存与医疗修复；
- 以追偿取消责任人的基本保障或强迫劳动；
- 将项目失败本身当作没收私人财产的理由；
- 以反腐或资产保全名义进行无范围、无期限、无申诉的财产控制。

## 待验证问题

- 初查、证据保全、强制取证与资产保全分别需要何种门槛？
- 替代调查组如何获得真实独立的人员、预算、数据和安全保障？
- 公共先行修复基金怎样覆盖巨灾与系统性损害而不失去偿付能力？
- 多主体、跨机构和长期潜伏损害中的因果、份额与时效如何认定？
- 如何验证五层纠错能抵抗机构串谋，而不是增加新的程序迷宫？
