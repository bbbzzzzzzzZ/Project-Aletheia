# 主体社区与城市渐进可达机制

> **核心底线：主体社区是在全城最低可达义务之上的群体定制与渐进式建设起点；其存在不得成为其他地区拒绝基本无障碍建设的理由。**

## 一、问题与定位

将既有城市一次性改造成能够深度回应所有差异化需求的空间，可能同时受到建筑结构、土地、资金、技术、施工和时间约束。若只等待全城改造完成，正在生活的人会长期承担不可达造成的风险、时间损失和对家庭照护的依赖；若只建设封闭机构，又可能把支持转化为空间隔离。

本机制研究一种候选中间路径。任何具体立项都不得预设主体社区必然优于直接改造共同空间或提供分散支持；应先比较三类方案对自主、安全、时间、家庭负担、成本和长期隔离风险的影响，并获得实际使用者的有效参与和授权。

只有当比较和授权支持建设主体社区时，才进入以下渐进路径：

```text
先建设高适配度的主体社区节点
↓
以连续、安全的可达走廊连接必要公共服务
↓
连接不同社区与共同城市空间，形成城市网络
↓
在新建、翻修和基础设施更新中逐步扩大普遍可达范围
```

它回答的不是“整座城市是否应当可达”，而是：

- 在资源与时间有限时，先改造哪里、做到何种深度；
- 如何让受影响者尽快获得较完整的自主生活空间；
- 如何使局部试点继续向外连接，而不是固化为隔离区；
- 如何让家属能够共同居住、照护或外出工作，而不被迫承担全部支持责任。

本文只规定机制方向、角色边界、渐进顺序和停止条件，不规定社区规模、建设期限、预算比例、治理席位或具体工程标准。

## 二、规范起点

### 1. 人格先于功能

任何人获得安全住所、基本服务、社会参与和自主生活条件的理由，不取决于其是否具有特殊天赋、经济产出或可被社会利用的能力。

### 2. 需求者拥有优先解释权

具有共同可达需求的人应当参与定义空间目标、可接受取舍和评价标准。家庭成员、照护者、专家、建设者和公共机构可以补充事实与承担责任，但不能因为表达能力、专业知识或资源控制而取得对当事人生活目的的所有权。

### 3. 共同空间权与主体空间权并存

一个人同时具有：

- 平等进入共同城市空间的资格；
- 与具有相似需求者共同建设、使用和治理高适配空间的资格；
- 在两类空间之间自由往返、迁入、迁出和保持社会关系的资格。

主体社区补充共同城市，不替代共同城市。

### 4. 环境选择产生设计、局面创设与修复责任

当城市、建筑、教育、交通或数字服务只采用一种默认接口，并把适应成本长期转移给少数使用者和家庭时，这不再只是个人身体条件问题。作出设计、投资和维护选择的具体决策者、出资者、公共机构、建设者与运营者，应按实际控制力和可预见影响分别承担说明、改造、支持与修复责任。

这是对设计选择、局面创设和环境影响的责任归属，不是把有限互惠公共责任自动分配给居民、家属或某类身份。机构必须供给支持和修复环境；即使成员有限公共责任原则成立，具体劳动仍须另经任务必要、公平分配、能力与条件、换班、延期、替代、豁免、异议、申诉和限定授权程序。

## 三、工作定义

正式文本宜使用“具有共同可达需求的群体”，避免把多数人的身体与感知条件直接称为“正常”，再把其他人规定为偏离正常。

| 概念 | 本文工作定义 | 明确边界 |
|---|---|---|
| 共同城市空间 | 面向所有居民的街道、交通、公共服务、商业、教育、文化与治理空间 | 不因主体社区存在而免除最低可达责任 |
| 主体社区 | 嵌入共同城市、以某类持续共同需求为优先设计条件，并由主要使用者实质参与治理的完整生活节点 | 不是强制安置区、封闭机构或单一护理设施 |
| 共用底座 | 各空间共同承担的生命安全、基本通行、公共信息、应急、申诉和服务接口 | 具体最低标准仍需依法规、证据和参与程序形成 |
| 群体定制模块 | 在共用底座之上，针对触觉、声音、视觉、空间、行动、认知或照护等需要配置的可调整设施与服务 | 不假定同一群体内部需求完全相同 |
| 可达走廊 | 从主体社区连续连接交通、医院、学校、工作地点和其他重要空间的物理与信息路径 | 不是一段孤立的无障碍设施，而是端到端可完成的行动链 |
| 城市网络 | 多个主体社区、关键走廊和共同空间形成的可迁移、可复制、可相互访问的系统 | 不以取消主体社区或强迫完全同质化为终点 |

### 身体适配与偏好同质化不是同一种问题

主体社区的首要理由，是某些身体、感知、认知或照护条件需要连续的物理设施、服务接口和近距离支持。例如触觉导航、低刺激环境、行动辅助、持续照护与紧急响应，会直接影响一个人能否安全自主生活。

信仰、兴趣、观点、饮食、作息和生活偏好则未必需要住宅分隔。它们可能通过社团、预约空间、数字社区、局部设施或协商规则得到支持，不能只因为也属于“差异”就自动成为把居民按观念同质化的理由。

任何以共同信仰或偏好形成的自愿居住安排，都必须另外证明：

- 成员资格不是获得住房、福利、教育和政治权利的条件；
- 居民可以改变观点、退出社团或保持不表态，而不失去住所和必要服务；
- 住宅规则不排除家庭中的不同信仰、儿童成长中的变化和多重身份；
- 不以维持“纯净”“一致”或避免接触差异者作为公共资助目标；
- 共同城市空间、学校、就业和跨社区交往仍然真实可达。

因此，空间设计必须记录它在解决哪一种具体障碍，不能从“相似的人住在一起更方便”直接推出身份分区。

## 四、空间结构

```text
                    全城最低可达底线
                            │
                    ┌───────┴───────┐
                    │               │
              主体社区节点 A   主体社区节点 B
                    │               │
                    └───可达走廊────┘
                            │
              交通 / 医疗 / 教育 / 就业 / 文化
                            │
                  新建与翻修中的持续扩展
```

| 层级 | 主要目标 | 推进方式 |
|---|---|---|
| 全城最低底线 | 不因位置或身份失去生命安全、紧急求助、基本公共信息和必要服务 | 立即识别高风险缺口，不等待完整改造计划 |
| 主体社区节点 | 在有限范围内尽快形成能够居住、学习、工作、交往和参与治理的高适配空间 | 可优先利用适合改造的既有建筑与模块化设施，也可建设新节点 |
| 关键可达走廊 | 扩大居民能够独立、安全到达的生活半径 | 按实际高频目的地逐段连接，并验证整条行动链 |
| 城市网络 | 连接不同节点，使支持、知识和设施不被单一社区垄断 | 复制经验证的接口，保留不同社区的定制能力 |
| 普遍城市更新 | 在新建、重大翻修和设施更换时逐步吸收有效标准 | 把试点经验转化为共同底座，而非永远保留为特供产品 |

全城最低底线不得低于所在地当前适用的强制性安全、无障碍和合理便利义务。主体社区不能延后已经到期的义务，其专项资源也不得挤占已经承诺或依法应当用于共同城市整改的资源。立项时必须同时列出高风险缺口、责任主体、整改期限和独立审计方式；具体法律与工程标准需按所在地另行核查，不能由本文替代。

## 五、渐进建设流程

### 阶段零：路径比较与授权

至少比较：

- 直接改造共同城市中的目标空间；
- 为使用者提供分散式住房、个人支持和交通连接；
- 建设主体社区节点并逐步连接走廊；
- 上述方式的组合。

比较必须同时计算工程成本、居民时间与风险、家庭无偿照护、迁移影响、外部服务可达性和长期锁定效应。主体社区方案只有在受影响者实质参与、替代方案被诚实呈现、迁入不会成为获得福利与必要服务的条件，并且存在可撤回授权时，才能进入原型阶段。

### 阶段一：需求与障碍共识

- 由实际使用者描述日常行动、学习、工作、照护和社会参与中的障碍；
- 分别记录先天与后天条件、程度差异、多重障碍、年龄和个人偏好；
- 家属、服务人员和专家提交观察，但不得冒充当事人的统一意见；
- 盘点现有建筑、公共服务、交通连接、土地条件和安全约束；
- 公开哪些是规范目标、经验事实、工程判断和待验证假设。

### 阶段二：小范围原型

- 在自愿参与和真实退出的前提下，先测试住宅单元、公共活动空间、导航接口和支持服务；
- 优先使用可逆、可维护、可比较的模块，避免未经验证即投入不可逆工程；
- 同时保留对照方案和使用者能够直接否决的高风险设计；
- 把失败、冲突和少数体验作为正常反馈，而不是解释为使用者“不适应”。

### 阶段三：完整主体社区

主体社区应当提供完整生活条件，而不是只集中医疗或照护功能。可包括：

- 独立住宅、家庭共同住宅和可选择的支持型住宅；
- 日常商业、餐饮、文化、运动和公共交往空间；
- 教育、能力发展、数字服务与适配工作空间；
- 基础健康服务、紧急响应和外部医疗转介；
- 居民议事、监督、申诉和服务更换渠道；
- 与公共交通和城市街区连续连接的出入口。

“完整生活条件”不意味着把教育、医疗、就业和文化全部内置并要求居民在社区内部解决。外部学校、医院、工作地点和公共生活的平等可达仍是不可替代的评价指标；内部服务是选择与支持，不是限制外出的理由。

### 阶段四：关键走廊

扩展顺序由居民实际生活决定，而不是只由建设便利决定。优先连接：

- 公共交通枢纽；
- 医院与常用健康服务；
- 学校、培训与图书馆；
- 主要就业和公共服务地点；
- 亲友居住区、商业与文化空间；
- 其他主体社区。

评估对象是一次出行能否从起点完整到达目的地并返回，而不是统计安装了多少单项设施。

### 阶段五：网络化与普遍更新

- 将经过验证的设计接口形成公开、可复制的知识；
- 在新建项目、重大翻修和设备更换时逐步纳入共用底座；
- 允许不同社区继续保留超出底线的深度定制；
- 定期比较“继续建设专门节点”“扩大走廊”与“直接改造共同空间”的成本、收益和分配影响；
- 扩展不以消灭差异或取消主体社区为当然终点。

## 六、居住、家庭与支持

### 居住选择

居民可以选择：

- 独自居住；
- 与伴侣、亲属或朋友共同居住；
- 使用由本人选择和控制的个人协助；
- 短期居住、过渡居住或长期居住；
- 随时提出迁出、迁回或更换社区，并获得不以服从为条件的过渡支持。

迁入必须基于自由、知情且可撤回的选择。诊断、身份登记、住房资格、福利或必要服务不得以迁入主体社区为条件。迁出请求不得仅因运营方便、既有资源安排或服务提供者反对而被否认；确需安排过渡时间时，期限、理由和替代支持必须可说明、可申诉，并不得限制居民人身自由。未进入主体社区的人仍保有共同城市中的基本权利。

### 退出不替代追责与修复

“可以搬走”不等于冲突已经解决。若一方遭受暴力、歧视、服务侵害、资源侵占或持续骚扰，退出可以是保护选项，但不得：

- 取消对侵害事实的调查、停止、修复和责任追究；
- 让受侵害者单独承担搬迁、重新适配、关系中断和失去工作的成本；
- 让控制住房、支持、证据或公共资源的一方用“你可以走”逃避纠正；
- 把社区内部难以表达、照护需求较高或资源较少的人优先迁出；
- 以退出人数下降或社区更同质作为机制成功的证据。

迁出支持应包括必要的过渡住所、服务连续、信息和数据可携带、关系衔接、合理成本承担与独立申诉。即使本人选择留下，也不得失去对伤害的救济。

### 家属生活

家属可以在社区共同生活，也可以外出工作、学习和参与其他社会生活。共同居住不等于自动接受无期限、无报酬的全天照护责任。

主体社区进入持续运营前，必须建立能够替代被迫家庭照护的基本支持能力；具体服务组合仍需由使用者参与试验和修订。最低应覆盖：

- 由本人选择、能够更换的个人协助；
- 临时替代与喘息支持；
- 紧急联络和夜间响应；
- 家庭照护知识、心理支持与申诉；
- 在不侵犯隐私的情况下与外部学校、雇主和医疗服务衔接。

公共机制若只建设住房，却把持续支持全部转移给家庭，尤其长期集中给某一名成员，就不构成完整的主体社区。

### 支持而非接管

支持服务的目的，是扩大本人能够决定和完成的生活，而不是以安全、效率或照护为名接管其时间、身体、财产、社交与外出决定。确需代理时，应遵循最小替代、利益冲突披露、短期限和持续复核。

## 七、治理与责任角色

| 角色 | 主要责任 | 不得自动取得的权力 |
|---|---|---|
| 居民与主要使用者 | 表达需求、形成生活目标、评价取舍、参与治理和纠错 | 不因一种共同身份代表全部成员 |
| 家属与其他共同生活者 | 表达自身需求、说明照护影响、承担自由接受、范围明确、可以退出且必要时获得报酬的关系责任 | 对居民人生、财产和迁移的所有权 |
| 专业人员 | 说明工程、医疗、教育、安全和服务方案的事实、风险与边界 | 以专业能力垄断生活目标 |
| 服务提供者 | 在合同与授权范围内提供住房、协助、维护和运营 | 将基本服务绑定服从、劳动或放弃申诉 |
| 公共机构 | 保障共用底座、配置资源、监督质量、维护跨区域连接和救济 | 以出资为由替使用者定义幸福 |
| 独立监督与救济主体 | 接收申诉、审查越权、暂停伤害、要求修复和补偿 | 同时经营被监督的核心服务 |

主要使用者必须对社区核心目标、生活规则和效果评价拥有不可被“征求意见”替代的实质参与权。具体代表方式、席位、表决与否决边界仍需结合群体规模、表达条件和利益冲突另行设计。

共享某种障碍不等于意见一致。治理必须保留直接表达、少数意见、多重身份、替代代表、服务更换与个人退出。

## 八、资源与成本责任

### 共用底座与定制模块分层

- 共用底座由共同体承担，不因使用人数较少就全部转为个人消费；
- 群体定制模块根据障碍程度、实际使用、替代方案、可复制价值和资源约束进入公开程序；
- 个性化偏好与基本可达条件分开，不用奢侈偏好否定基本需求；
- 公共资金支持不以居民就业、贡献或展示特殊能力为前提。

### 避免重复浪费

- 优先识别既有建筑中可安全、低成本改造的部分；
- 使用开放接口、模块化设施和可维护标准；
- 不把每类需求都建设成互不兼容的封闭系统；
- 将试点产生的非隐私知识向其他社区和城市更新公开；
- 同时计算居民时间、家庭无偿照护、事故风险和失去教育就业机会等隐性成本，而不只计算工程造价。

### 选址责任

主体社区不应仅因土地便宜而被放置在远离交通、医院、学校、就业和社会关系的城市边缘。若低建设成本以长期出行、照护依赖和社会隔离为代价，只是把成本从预算转移给居民与家庭。

## 九、开放、边界与自由往返

主体社区以特定需求为优先，不等于所有空间都必须排斥其他人。可根据住宅隐私、安全和公共功能区分：

- 居民私人空间；
- 成员共同空间；
- 预约访问空间；
- 向所有市民开放的公共空间。

任何访问规则都不得反向限制居民外出、工作、受教育、就医、迁移和参与共同城市。非成员访客进入时应遵守当地的多感官、安全和交往规则，但不应被强制进行制造恐惧或怜悯的“残障模拟”。

住房必须有可负担性、租住稳定和反报复保护。居民提出申诉、拒绝某项服务或参与公共批评，不得成为涨价、降级支持、拒绝续住或迫使迁出的理由。住房与核心支持若由同一运营者提供，应设置可携带服务、独立申诉和不中断基本生活的更换机制。

一个人可以同时具有多种需求并参与多个社区。制度不得要求其选择唯一身份，也不得把社区成员资格变成就业、福利或政治权利的永久标签。

身份表达由本人决定。任何人不得被要求隐藏身体条件、辅助方式、信仰、家庭关系或其他身份来换取进入共同空间；也不得被迫公开诊断、信仰、经历或成员资格来证明需求、代表群体或参加展示。确需提供适配信息时，应只收集完成本次支持所需的最小信息，并允许本人选择披露对象、方式和期限。

## 十、反馈、扩容与评价

### 评价维度

- 居民能否更自主地决定居住、出行、学习、工作和交往；
- 可独立、安全到达的空间与服务是否扩大；
- 时间、金钱、风险和对临时帮助的依赖如何变化；
- 家庭无偿照护负担及家属继续工作、学习和生活的条件；
- 教育、就业、医疗、文化和公共决策参与是否改善；
- 安全事故、险情、服务中断和隐私侵害；
- 居民满意、少数意见、申诉、退出和迁移情况；
- 成本和收益是否不成比例地集中在某些人身上。
- 居民跨社区就学、工作、就医、探亲、文化参与和共同治理的实际频率与可选择范围；
- 迁入、迁出与跨社区交往是否因收入、障碍程度、照护需要、年龄或身份表达而出现系统差异；
- 外部居民是否能够在尊重社区规则的前提下进入开放空间，社区居民是否能在不隐藏身份的情况下进入共同城市；
- 住宅、服务、数据与申诉能否跨运营者和社区携带，而不以失去支持作为退出代价。

指标只能帮助判断目标是否接近，不能代替居民对生活经验的表达。平均改善不能抵消少数成员持续承受的重大伤害。

“融合”不以不同群体最终相同、主体社区消失或跨社区接触次数最大化为目标。更合适的判断是：居民是否保留差异和私人边界，同时具有真实、可负担、无惩罚地进入共同生活、建立关系和选择离开的条件。任何量化指标均不得用于强迫社交、公开身份或削弱成员共同空间。

### 反隔离压力测试

扩容和续期前至少用以下情境检验：

1. 当居民改变信仰、兴趣、家庭关系或身份表达时，住所和支持是否仍然稳定？
2. 当一个人同时具有多种障碍或不符合群体平均特征时，能否获得个体配置而不被转移？
3. 当社区内部发生侵害时，受影响者能否留下并获得保护，也能选择迁出且不独自承担成本？
4. 当城市预算紧张时，主体社区是否被用作取消其他地区基本可达义务的理由？
5. 当学校、雇主、医院或公共机构认为“社区内部已经有服务”时，居民是否仍能使用外部共同服务？
6. 当运营者掌握住房、支持和数据时，拒绝服务、投诉或公开批评是否会提高退出成本？
7. 当跨社区交往较少时，制度是在消除交通、信息和污名障碍，还是要求居民证明自己愿意“融入”？

### 扩容门槛

继续扩建、复制或把机制纳入城市标准前，至少应能够说明：

- 需求来源与使用者授权仍然有效；
- 立项时比较过直接共同空间改造、分散支持和主体社区方案，选择理由仍然成立；
- 主要风险得到记录并存在可用救济；
- 原型没有通过限制退出或隐藏成本制造表面成功；
- 走廊能够端到端使用，而不是只有零散设施；
- 资源与责任分配公开，家属和低表达能力者的负担没有被隐藏；
- 独立复核能够建议继续、修改、暂停或终止。

## 十一、主要失败路径与停止条件

| 失败路径 | 预防与修正 |
|---|---|
| 主体社区变成隔离区 | 城市内选址、自由迁移、连续走廊、开放公共功能和外部服务权利 |
| 城市以专属社区为由拒绝改造 | 明确全城最低底线和新建、翻修时的持续更新义务 |
| 把群体想象成同一种人 | 个体配置、多重身份、少数意见、替代方案与可更换服务 |
| 支持服务接管居民生活 | 住房与服务权限拆分、本人选择、独立申诉和最小代理 |
| 把照护成本隐藏给家庭 | 专业支持、喘息服务、家庭负担统计和责任公开 |
| 专家或运营者夺取目标决定权 | 区分目标、事实判断、执行、监督和救济权限 |
| 临时试点变成永久收容 | 自动复核、扩容门槛、真实退出和停止后的安置与修复 |
| 不同群体的需求相互冲突 | 多通道冗余、局部定制、影响评估和透明协调程序 |
| 数据与智能设备形成监控 | 数据最小化、用途限定、离线替代、删除与纠错权 |
| 只服务易展示或高产出成员 | 基本资格与贡献分离，检查最弱表达者和最坏受影响者 |
| 身体适配被扩大为信仰或偏好的住宅纯净化 | 要求说明具体空间障碍，优先使用社团、局部设施和协商，不以观念一致作为公共住房资格 |
| 用“可以退出”代替追责 | 同时保留留下并获保护、迁出获支持、事实调查、责任追究与成本修复 |
| 融合要求隐藏或公开身份 | 本人控制表达，适配只收集最小信息，共同空间不得以身份表演为准入条件 |
| 跨社区接触变成强制同化指标 | 评价机会和实际障碍，不强迫交往，不以主体社区消失作为成功标准 |

出现以下情况，应立即暂停相关安置、建设或运营权限并启动独立复核：

- 强制迁入、限制迁出或以基本服务惩罚退出；
- 把福利、必要服务、住房资格或家庭支持与迁入绑定；
- 持续阻止居民进入共同城市、就业、教育、医疗或亲友关系；
- 主体社区被用来取消其他地区的基本安全与可达义务；
- 居民没有真实表达、治理、申诉和更换服务的渠道；
- 重大安全、照护、暴力、隐私或财产伤害被隐瞒；
- 对家庭的无偿照护负担成为机制运行的必要条件；
- 同一机构同时控制住房、服务、评估、监督、救济和全部证据。
- 以信仰、观点、诊断或身份“纯净”为由强制迁入、迁出、隐藏或公开；
- 以退出可能为由拒绝调查侵害，或要求受侵害者承担主要迁移与重新适配成本；
- 学校、医疗、就业或公共机构以社区已有内部服务为由系统性拒绝居民。

停止后必须继续保障住所、医疗、个人支持和迁移选择，并保存证据、停止伤害、修复损失、追究越权责任。不能以项目失败为由再次把成本转移给居民。

## 十二、待验证问题

- 哪些持续共同需求适合建立主体社区，谁有资格提出与复核？
- 如何证明主体社区优于直接共同空间改造、分散支持或三者组合，而不是只因行政管理更方便？
- 全城最低可达底线如何确定，哪些高风险缺口不得等待渐进改造？
- 社区代表如何产生，如何覆盖内部差异、儿童、无法直接表达者和多重身份？
- 公共资金、建筑所有者、运营者和使用者如何分担不同层级成本？
- 选址、土地与住房价格机制如何避免把主体社区推向城市边缘？
- 何时应继续建设专门节点，何时应把资源转向共同空间改造？
- 不同群体的定制要求发生冲突时，谁参与形成可修订的协调方案？
- 如何保障个人协助者和专业照护者的劳动条件，而不把支持成本重新压给低薪劳动者？
- 如何使试点知识公开复用，同时保护居民隐私并避免商业垄断？
- 如何证明渐进路径正在扩大活动范围，而不是把长期拖延包装成务实？
- 身体／感知／照护适配与信仰／偏好社群在公共资助、成员资格和居住规则上应采用哪些不同门槛？
- 跨社区融合应记录哪些机会与障碍，才能避免把融合变成身份隐藏、强制公开或强迫交往？
- 当退出用于保护本人时，住房、服务、数据、关系与修复成本分别应由谁承担？
