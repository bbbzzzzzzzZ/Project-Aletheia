## 当前机制草案

- [`主体社区与城市渐进可达机制.md`](主体社区与城市渐进可达机制.md)：以“主体社区节点—可达走廊—城市网络”处理有限资源下的渐进可达、家庭支持和群体主体性；区分身体／感知／照护适配与信仰／偏好同质化，加入退出成本、身份表达和反隔离压力测试。
- [`职业入口开放、能力分级与任务授权原则.md`](职业入口开放、能力分级与任务授权原则.md)：确认学习和资格验证入口开放、专业资格原则上不因岗位名额限量，并把资格、岗位、责任与任务授权分开；分级和实施参数仍开放。
