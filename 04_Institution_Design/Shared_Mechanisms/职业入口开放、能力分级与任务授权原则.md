# 职业入口开放、能力分级与任务授权原则

本文件的方向原则已由项目发起者通过 `D-020`、`PCR-C35F82` 确认；资格标准、分级数量、认证组织、岗位选择、记录期限及实际效果仍须研究和共同验证。

## 一、定位

本专题研究如何取消与专业能力、任务风险和责任承担无直接关系的职业限制，同时保护受专业活动影响的人。

核心区分是：

> 学习入口可以开放；能力和任务资格必须验证；影响他人的执行权限必须另行授权。

职业身份、学历、能力、任务资格、岗位、责任与执行权限不得互相自动推出。

## 二、候选原则

### 1. 取消无关准入限制

任何人原则上都可以接触专业知识、使用公共学习资源、参加训练、提交能力证据和申请资格验证。不得仅因出身、财富、家庭背景、社会身份、传统学历路径或人为人数名额，永久阻断学习与证明能力的机会。

资格认证原则上不设置人数上限。达到公开标准的人都可以取得相应资格；“今年没有岗位”不能被写成“申请人没有能力”。

### 2. 稀缺资源与资格分开

教师时间、实验设备、临床机会和高成本训练资源可能真实稀缺，可以依据透明、可质疑的规则分配。但资源稀缺必须触发扩容、轮换、替代训练和公平排序，不能固化为身份垄断或永久名额。

### 3. 能力、证据、资格与权限分开

```text
开放学习
→ 形成现实能力
→ 提交可复核的能力证据
→ 取得特定领域、任务和风险下的任务资格
→ 满足岗位或具体任务条件
→ 经独立程序授予有限执行权限
→ 执行、监督与结果反馈
→ 更新能力判断、任务资格或授权范围
```

现实能力只是任务资格的必要条件之一；任务资格只是进入候选范围的依据。能力、资格、岗位和责任都不自动产生执行权限。

### 4. 资格按领域和风险记录

资格只能说明某人在特定时期、条件和领域能够安全承担哪些任务，不形成跨职业总等级、人格等级或统一职业分数。

同一个人可能在不同领域具有不同资格。高风险任务需要更强证据、监督和复核，但高资格不产生更高人格价值、公共目标决定权或政治权利。

### 5. 岗位可以有限，资格不因岗位稀缺而封闭

固定岗位可以根据真实任务量、连续性、预算和组织责任设置数量。取得资格不等于获得雇佣、报酬或固定岗位；没有固定岗位也不应消灭已经证明的资格。

岗位选择规则必须公开，并防止用岗位、训练机会或任务分配实施关系排斥、身份继承和观点惩罚。

### 6. 培训、认证、使用与监督分离

培训者不能因提供教学自动拥有最终认证权；认证者不能控制全部学习入口；任务机构不能单独决定谁拥有通用资格；监督者不能同时垄断任务分配、评价、申诉和处罚。

认证可以综合考试、模拟、作品、带教观察、独立评审和真实实践证据。标准、理由、利益冲突和申诉路径应公开。

### 7. 任务反馈不变成人格信用

评价以具体任务为对象，区分结果、过程、风险、复杂度、第三方影响和可纠正错误。不得把多个领域压缩成单一“职业信用分”，也不得让一次失败造成终身职业死亡。

任务反馈可以支持培训、复核、资格范围调整或重新授权；任何限制都须相关、相称、限期、可申诉并允许恢复。

### 8. 高风险领域保留安全门槛

医学、司法、工程、航空、儿童长期照护和使用国家强制力等活动，可以按照潜在伤害、不可逆性和影响范围设置更严格的资格与授权条件。限制的是未经验证而独立承担高风险任务，不是学习、研究、提出意见或申请验证的资格。

## 三、禁止的自动跳转

```text
学习完成 ≠ 现实能力已经形成
现实能力 ≠ 任务资格
任务资格 ≠ 固定岗位
固定岗位 ≠ 任意任务权限
责任承担 ≠ 自动授权
一次成功 ≠ 永久资格
职业贡献 ≠ 人格或政治等级
```

## 四、待验证问题

- 哪些现行名额来自真实训练容量，哪些只是职业集团的数量控制？
- 如何扩充高成本实践机会，同时不把学习者置于无监督高风险任务中？
- 谁制定资格标准，如何允许替代标准、新方法和外部挑战？
- 岗位不足时怎样公平选择，且不反向污染资格认证？
- 如何处理合理错误、能力下降、严重失责与故意伤害之间的不同后果？
- 任务记录的最小字段、保存期限、访问者和删除条件是什么？

## 五、本稿不确认

- 跨职业统一等级；
- 固定的分级数量或名称；
- 自动评分、总信用分或终身职业档案；
- 通过考试后自动取得岗位或执行权限；
- 取消医疗、司法、工程等高风险任务的能力与安全要求。
