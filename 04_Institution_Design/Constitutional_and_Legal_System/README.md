# 宪制与法律系统

本模块研究人的基本地位、公共权力的产生与边界、法律形成、司法解释、权利冲突和救济。它是框架草案，不是现行法律文本。

当前入口：

- [`宪制与司法原则.md`](宪制与司法原则.md)：宪制骨架、法律形成、权利冲突与救济。
- [`司法解释体系.md`](司法解释体系.md)：以文字、整体结构、规范目的和现实后果四种方法解释既有规范，并让主体表达、支持、利益冲突、第三方影响和复核贯穿每一种方法。
- [`司法资格、岗位与案件授权分离机制.md`](司法资格、岗位与案件授权分离机制.md)：法院常设、资格开放、岗位有限和案件逐项授权的已确认方向及开放机制。

四种解释方法回答“既有规范怎样适用于案件”；司法组织四层回答“谁在什么条件下取得办理该案的有限权限”；贯穿式主体接口保障当事人和受影响者能够进入解释、质疑和复核。三者不得合并，主体接口也不是第五种解释法或第五层司法组织。
