# 公共责任与社会基础保障维护细则

> [!WARNING]
> 这是已被当前框架取代的旧项目机制细则，不是当前实施规则。共同依赖不自动生成个人非自愿义务；下文固定工时、抽签、积分、处罚和“已确定”状态均不具有现行效力。

整理时间：2026-08-09  
状态：工作草案  
用途：把公共责任、无人承担任务、社会基础保障维护、诚信后果和反强制边界整理成可继续细化的制度模块。

---

# 一、基本原则

## 1. 公共责任不是生存交换

公共责任是为了保障全体成员基本生存、安全与社会持续运转所必须完成的公共劳动。

但公共责任不能被理解为：

> 只有劳动，才配获得基本生存。

基本生存保障来自人的存在和社会成员资格，而不是当前劳动表现。

社会基本生存保障至少包含：

- 基本食物；
- 基本住所；
- 基础医疗；
- 基础教育；
- 基本人身安全；
- 必要公共服务。

因此，贫困最多意味着缺少额外消费、储蓄和奢侈空间，不能意味着一个人为了活下去被迫出卖时间。

## 2. 公共责任不是无限义务

公共责任应当有明确时长、明确任务、明确边界和明确退出机制。

公共系统不能因为一个人具备能力，就默认拥有这个人的时间。

核心边界：

> 能力登记不等于时间可调用；公共责任完成后，剩余时间归个人。

## 3. 强制只能是最后机制

公共任务无人承担时，制度不能第一反应就是强制。

应按顺序处理：

```text
确认无人承担原因
↓
改善条件 / 提高系数 / 缩短排班 / 技术替代
↓
年度任务清理：是否取消、替代、自动化或降级
↓
轮值、请假、换班、延期
↓
最后才进入一生一次的社会基础保障维护抽签机制
```

# 二、公共责任时间制度

## 1. 三档时间结构

| 类型 | 时间 | 含义 | 边界 |
|---|---:|---|---|
| 正常年度公共责任 | 400 小时 / 年 | 普通成员正常完成年度公共责任的标准 | 不应吞没个人主要生活时间 |
| 正式工作型公共责任年 | 800 小时 / 年 | 当个人把公共责任工作作为当年主要正式工作时，可达到的单年极端上限 | 不能由系统单方面强制 |
| 三年集中结算 | 1200 小时 / 结算周期 | 本人主动申请一次性完成三年公共责任，完成后后两年免除常规公共责任 | 必须本人申请，不得被机构诱导 |

## 2. 400 小时标准

400 小时是正常年度公共责任完成标准。

它表示：

> 一个社会成员在不牺牲个人生活、学习、家庭、创造和市场劳动的前提下，对公共系统承担的常规年度责任。

待补：

- 400 小时内部如何分配给不同类型任务；
- 是否按年龄、身体、照护责任、地区差异调整；
- 是否允许用知识贡献、照护贡献、教育贡献折抵部分公共责任。

## 3. 800 小时正式工作型上限

800 小时不是默认义务，而是：

> 以公共责任工作作为当年主要正式工作时的单年极端上限。

这意味着个人不是一边承担高强度市场工作，一边额外快速累积公共责任时长。

这一年中，公共责任工作本身就相当于个人主要社会工作。

边界：

- 不能由系统单方面要求个人达到 800 小时；
- 不能把 800 小时作为普通年度默认标准；
- 高风险、重体力、强照护、强情绪消耗任务应设置更严格休息限制；
- 若健康风险触发，应暂停或退出高强度年度安排。

## 4. 1200 小时三年集中结算

个人可以主动申请三年集中结算。

规则：

> 本人主动申请，在一个结算周期内完成 1200 小时公共责任，完成后后续两年免除常规公共责任。

这个机制的意义是：

> 允许个人把公共责任当作一段正式工作集中完成，用之后两年的时间主权去学习、市场工作、照护家庭、创业、研究或休息。

反诱导边界：

- 学校不得要求学生提前完成 1200 小时；
- 雇主不得把“已完成未来三年公共责任”作为录用条件；
- 机构不得把集中完成作为福利资格、培训资格或晋升条件；
- 家庭、组织不得代替本人申请；
- 不得买卖、转让、雇人代做公共责任；
- 申请应允许冷静期和撤回机制。

# 三、公共任务分类

| 任务类型 | 定义 | 处理原则 |
|---|---|---|
| 普通公共服务任务 | 对公共系统有益，但非关键生存维护任务 | 自愿优先，普通拒绝不惩罚 |
| 四级公共运行任务 | 与公共运行有关，但必要性、替代性和社会代价需要持续评估的任务 | 每年清理，能取消就取消，能替代就替代 |
| 脏、累、险任务 | 工作环境差、身体消耗大、风险高的基础维护任务 | 提高责任积分系数，缩短排班时间，改善工具和安全条件 |
| 纯枯燥任务 | 低风险但重复、无聊、缺少意义感的任务 | 缩短排班时间，拆分任务，轮换岗位 |
| 基础生存系统维护 | 食物、水、电、基础医疗、公共安全等不能中断的系统维护任务 | 稳定团队、储备人员、预承诺窗口、严格紧急机制 |
| 高风险专业任务 | 医疗急救、工程抢险等错误代价极高的任务 | 只允许合格人员承担，不得向无资格者轮值 |
| 长期照护任务 | 需要持续关系、情绪劳动和稳定信任的任务 | 不宜完全任务化，应设置稳定团队和周期休息 |
| 临时灾害任务 | 水灾、疫情、地震、战争等危机中的临时任务 | 按分灾种紧急机制处理 |

# 四、无人承担任务处理流程

## 1. 第一步：确认无人承担原因

任务无人承担时，先判断原因，而不是直接进入强制。

常见原因：

- 太脏；
- 太累；
- 太危险；
- 太枯燥；
- 排班过长；
- 工具落后；
- 回报过低；
- 任务描述不清；
- 任务本身已经不必要；
- 任务可以被技术替代；
- 任务需要专业能力但能力池不足。

## 2. 脏、累、险任务

如果无人承担的原因是脏、累、险，应优先：

- 提高责任积分系数；
- 缩短单次排班时间；
- 改善工具；
- 改善防护；
- 减少连续暴露；
- 引入技术替代；
- 提供休息与恢复窗口。

原则：

> 高伤害任务不能靠道德要求解决，必须靠条件改善和责任系数补偿解决。

## 3. 纯枯燥任务

如果无人承担的原因主要是枯燥，应优先：

- 缩短排班时间；
- 拆分任务；
- 轮换岗位；
- 自动化；
- 将任务与其他低强度任务组合；
- 降低连续重复劳动时间。

原则：

> 枯燥任务不是道德问题，而是任务设计问题。

## 4. 四级公共运行任务年度清理

每年发起一次公共任务清理问卷。

核心问题：

1. 你认为哪项四级公共运行任务应该取消？
2. 为什么它不必要？
3. 是否存在替代方式？
4. 替代方式会造成什么影响？
5. 这些影响是否可以承受？
6. 是否可以先小范围试点？

流程：

```text
公众提出取消 / 替代建议
↓
说明理由
↓
提出替代方式
↓
评估影响
↓
小范围试点
↓
确认可承受
↓
取消 / 替代 / 自动化 / 降级
```

原则：

> 社会进步不是让人承担越来越多责任，而是让不必要的公共任务越来越少。

# 五、轮值机制

## 1. 轮值的定义

轮值是公共任务长期无人承担，但还没有进入强制基础保障维护之前的排班机制。

轮值不是强制劳动。

轮值应允许：

- 请假；
- 换排班；
- 延期；
- 合理豁免；
- 任务替代；
- 申诉。

## 2. 轮值与强制的边界

| 项目 | 轮值 | 强制基础保障维护 |
|---|---|---|
| 适用阶段 | 中间机制 | 最后兜底机制 |
| 是否可请假 | 可以 | 可以，但最终需要完成或获得豁免 |
| 是否可换班 | 可以 | 可以，但必须留下记录 |
| 拒绝后果 | 普通拒绝不惩罚 | 无合理理由拒绝才触发诚信后果 |
| 是否影响基本保障 | 不影响 | 也不影响 |
| 是否可申诉 | 可以 | 必须可以 |

# 六、社会基础保障维护抽签机制

## 1. 启动条件

社会基础保障维护抽签机制只能在以下条件都成立时启动：

1. 该任务属于基础保障维护任务；
2. 任务对基本生存、安全或关键公共运行具有必要性；
3. 已经尝试提高责任积分系数；
4. 已经尝试缩短排班时间；
5. 已经尝试改善工具和安全条件；
6. 已经评估是否可以取消、替代、自动化或降级；
7. 仍然长期无人承担。

## 2. 基本规则

当前草案：

> 每个人在 18 到 25 岁之间，一生中必须通过抽签，承担为期半年的社会基础保障维护。

该机制的性质：

- 是最后兜底机制；
- 是强制加运气式分配；
- 不是普通公共任务；
- 不是永久服役；
- 不是职业锁定；
- 不能触碰基本生存线。

## 3. 必须保留的弹性

抽签后仍应允许：

- 请假；
- 换班；
- 延期；
- 分段完成；
- 身体豁免；
- 精神健康豁免；
- 照护责任豁免；
- 教育或重大人生阶段延期；
- 申诉。

待补：

- 请假标准；
- 换班规则；
- 延期上限；
- 豁免条件；
- 半年内的工作时长上限；
- 安全、住宿、培训和补偿标准。

# 七、诚信后果与处罚边界

## 1. 普通拒绝不惩罚

普通公共任务拒绝，不应被直接记为失信。

普通拒绝只能用于：

- 理解任务吸引力不足；
- 调整排班；
- 改善任务条件；
- 发现任务系统问题。

不能用于：

- 扣诚信积分；
- 限制基本保障；
- 制造隐性强制；
- 把拒绝者标记为低价值成员。

## 2. 只有抽签后无合理理由拒绝，才触发诚信后果

诚信后果只适用于：

> 已经通过公平抽签进入社会基础保障维护，并且已经提供请假、换班、延期、豁免和申诉渠道后，仍无合理理由拒绝履行。

可触发后果：

- 诚信积分扣减；
- 限制部分非基本公共运行福利；
- 限制部分公共协作资格；
- 要求补做；
- 进入信用修复程序。

## 3. 不得触碰基本生存保障

任何诚信后果都不能限制：

- 基本食物；
- 基本住所；
- 基础医疗；
- 基础教育；
- 基本人身安全；
- 必要公共服务。

可限制的只能是非基本公共运行福利。

待补：

- 哪些福利属于非基本公共运行福利；
- 诚信扣减幅度；
- 信用修复时间；
- 补做与替代服务规则。

# 八、社会贡献积分

## 1. 责任积分次年清零

年度责任积分用于记录当年公共责任完成情况。

基本计算方式可以写成：

```text
责任积分 = 任务时长 × 难度 / 风险 / 消耗系数
```

规则：

> 责任积分在年度或结算周期内用于公共责任结算；结算完成后，历史记录转入社会贡献积分。

这里的“积分兑换自由时间”可以成立，但它不是购买特权。

它的含义是：

> 已经完成的公共责任经过折算后，可以减少未来常规公共责任调用，从而释放连续自由时间。

## 2. 社会贡献积分是贡献履历

社会贡献积分用于展示一个人一生中对社会做过的贡献。

也可以理解为：

> 一生总责任 / 一生总贡献的履历。

它可以合并：

- 公共责任贡献；
- 知识贡献；
- 基础研究贡献；
- 公共服务贡献；
- 其他被确认的社会贡献。

在公共系统内部，社会贡献积分可以作为理解一个人长期贡献履历的参考。

但它不是：

- 市场货币；
- 可与市场货币交换的积分；
- 权力凭证；
- 政治资格；
- 就业条件；
- 教育录取条件；
- 住房条件；
- 基本福利条件。

教育应保持自由开放。

学生任何时候都可以学习，教师和学生通过互选形成教学关系；责任积分、社会贡献积分和知识贡献积分不得作为学习资格或师生互选的前提。

## 3. 积分与科研资源申请

目前积分与公共福利的关系应极其有限。

基本生存保障、基础教育和普通学习权不受积分影响。

唯一可以考虑挂钩的是稀缺公共科研资源申请，例如：

- 科研资助；
- 实验设备；
- 实验场地；
- 研究团队公共支持；
- 稀缺材料使用额度。

申请这类资源时，可以参考：

- 责任积分；
- 对应业务的任务质量分；
- 专业相关性；
- 研究计划质量；
- 同行或专家评审；
- 资源稀缺程度；
- 风险和伦理审查。

这不是积分兑换福利，而是公共系统在分配稀缺科研资源时使用内部贡献与质量记录。

## 4. 展示权属于本人

社会贡献积分不得强制公开。

本人应有权选择：

- 完全公开；
- 部分公开；
- 匿名公开；
- 隐藏。

原则：

> 社会贡献积分是文明记忆，不是社会信用镣铐。

# 九、反机构诱导规则

为了防止集中完成公共责任变成隐性筛选，必须明确：

- 学校不得要求学生提前完成 1200 小时；
- 雇主不得优先录用已完成未来三年公共责任的人；
- 机构不得把集中完成作为福利、培训、补贴、晋升或资格条件；
- 家庭和组织不得代替本人申请集中完成；
- 市场不得形成“公共责任已完成者优先”的雇佣歧视；
- 公共系统不得默认把低收入者推向集中完成模式。

集中完成只能是：

> 本人主动选择的一种时间安排方式。

# 十、紧急状态边界

## 1. 统一启动条件

紧急状态只能在以下条件成立时启动：

> 国家生存、公众生命安全、重大财产安全或关键社会运行系统受到严重威胁，且常规法律与常规公共责任机制已无法有效应对。

这里的关键社会运行系统包括但不限于：

- 食物供应；
- 饮水；
- 电力；
- 基础医疗；
- 公共安全；
- 通讯；
- 交通救援；
- 基础行政协调。

## 2. 分灾种设计

水灾、疫情、地震、战争不能用同一套机制粗暴处理。

应分别设计：

- 启动条件；
- 调用范围；
- 可调用人员；
- 时间上限；
- 补偿机制；
- 退出条件；
- 事后审查；
- 权力滥用追责。

待补文件：

- 水灾紧急机制；
- 疫情紧急机制；
- 地震紧急机制；
- 战争紧急机制；
- 基础设施崩溃紧急机制。

# 十一、当前待补问题

## 1. 公共责任时间分配

- 400 小时标准责任如何分配？
- 800 小时正式工作型公共责任年包含哪些任务？
- 1200 小时集中结算是否允许分段？
- 不同年龄、健康、照护责任的人是否有不同标准？

## 2. 抽签半年机制

- 是否固定 18 到 25 岁？
- 是否允许延至 30 岁？
- 半年内每周工作时长是多少？
- 培训期是否算入半年？
- 住宿和补贴标准是什么？
- 豁免和延期如何审核？

## 3. 非基本公共运行福利范围

- 哪些福利可以因无合理理由拒绝基础保障维护而限制？
- 限制多久？
- 如何修复？
- 如何申诉？

## 4. 四级任务清理机制

- 谁发起年度问卷？
- 谁汇总结果？
- 谁做影响评估？
- 小范围试点多长时间？
- 谁决定最终取消、替代或降级？

# 十二、核心公式

```text
基本生存保障
不以劳动表现为前提
↓
公共责任
以 400 小时为正常年度标准
↓
无人承担任务
先改善条件、提系数、缩排班、做年度清理
↓
仍无人承担
```
