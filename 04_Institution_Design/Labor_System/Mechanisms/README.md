# Labor Mechanisms

本目录保存劳动与公共责任的当前机制草案及旧项目候选稿。框架入口仍是 [`../劳动制度白皮书.md`](../劳动制度白皮书.md) 与 [`../公共责任制度.md`](../公共责任制度.md)。

- [`有限互惠公共责任机制.md`](有限互惠公共责任机制.md)：把一般互惠责任转换为具体任务义务，并连接年度责任积分、机构先行责任、关系型任务、权限退出与紧急例外。
- [`公共服务连续性与储备机制.md`](公共服务连续性与储备机制.md)：当前连续性、稳定团队、储备、交接与容量状态机制草案。
- [`公共责任缺席与后果_候选机制.md`](公共责任缺席与后果_候选机制.md)：只在具体公共责任任务已经正当成立后，区分无责任突发、轻微过失与恶意逃避；保持候选、`not-ready`，不以基本保障或超额贡献作为纪律工具。
- [`公共责任与社会基础保障维护细则_候选稿.md`](公共责任与社会基础保障维护细则_候选稿.md)：旧项目导入、现已标为 `archive / superseded` 的机制细则快照。

旧快照中的 `400/800/1200` 工时、按人抽签、人格化积分和处罚规则已经退出当前基线，不得作为待执行的现行草案引用。现行年度责任积分与领域贡献积分以 `D-025` 和当前激励制度文件为准。
