# 公共能力池

## 定义

本文件所称“能力池”，专指服务劳动模块中候选公共任务匹配的**公共能力池**：它是个人能力图谱中经本人明确授权、可更新且有适用边界的最小信息投影。“公共”表示它与经过审查的公共任务系统建立接口，不表示能力数据向所有人公开。若未来用于其他任务类型，必须另行确认用途与授权，不能默认扩张。

它用于帮助已经确认的任务找到可能的承担者，不是人力所有权清单、完整人格档案或自动调度名单。个人能力发现与私人记录见 [`../Education_System/能力发现.md`](../Education_System/能力发现.md)。

## 最小字段

- 具体能力及可验证证据；
- 适用任务、风险等级与禁止范围；
- 熟练度、有效期、复核和失效条件；
- 本人授权展示的信息范围与查看者；
- 可接受的联系与时间窗口；
- 暂停、疲劳、健康和照护限制；
- 申诉、更正、撤回和删除方式。

授权还必须说明：谁可以查看、允许匹配的任务类别、是否允许联系、联系渠道、有效期、禁止的二次用途，以及撤回后如何删除派生记录。

## 原则

- 能力属于个人，系统只记录和认证特定资格。
- 拥有能力不等于已经适配、已经被公平分配或已经取得当前任务权限；有限公共责任仍须另走个案程序。
- 能力更高不产生更高人格价值或目标决定权。
- 认证渠道应多元，避免学历和机构垄断。
- 匹配应防止少数高能力者被持续过度调用。
- 进入公共能力池只表示允许在限定范围内匹配；允许匹配不等于允许联系，允许联系不等于接受任务。

## 普通自愿任务的双侧匹配流程

个人不是被能力系统“送进任务池”。个人侧与任务侧分别形成，在匹配点汇合：

```text
个人侧：能力发现 → 私人能力图谱 → 本人细粒度授权 → 公共能力池

任务侧：需求表达 → 影响、资源与共同性审查 → 共同任务确认 → 任务池

汇合：公共能力池 + 任务池
      → 条件匹配 → 邀请 → 本人接受或拒绝
      → 明确承诺 → 授予有限任务权限
      → 执行、反馈与退出
```

```text
发现能力 ≠ 记录能力
记录能力 ≠ 授权进入公共能力池
进入公共能力池 ≠ 同意被任意联系
允许联系 ≠ 接受任务
接受任务 ≠ 获得超出任务的权限
```

任务承诺应指向条件明确的任务封套。本人承诺一个封套，不等于同意系统在目标、风险、时间、地点、指挥、数据、报酬、第三方影响或退出条件实质变化后继续调用。完整规则见 [`任务池.md`](任务池.md)。

## 有限公共责任任务的能力接口

有限互惠公共责任原则不授权机构读取私人能力图谱，也不把进入公共能力池变成义务资格。该分支可以在目的限定、最小必要和可复核的条件下核验具体任务能力，但必须：

- 先说明任务必要性、分配范围及为何需要核验该项能力；
- 允许本人更正记录、提交替代证据、说明健康、疲劳、照护和当前条件；
- 区分“曾经会做”“资格仍有效”“当前可以安全承担”和“已取得执行权限”；
- 不以拒绝公开完整能力、健康、位置或日程为逃避责任的证据；
- 在换班、延期、替代或豁免成立后停止不必要的数据访问；
- 不因某人能力稀缺而反复集中分配，或把高能力变成更重的人格义务。

有限公共责任任务的能力匹配只形成适配证据，不能自动形成任务决定。完整的公平分配、个案通知、条件审查、异议、申诉和限定授权仍在 [`任务池.md`](任务池.md) 完成。
