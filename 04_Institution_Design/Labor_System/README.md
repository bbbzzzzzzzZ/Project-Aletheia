# Labor System

本模块是 Aletheia 的第一个应用性压力测试：在承认基本保障与个人时间主权的前提下，社会如何识别、组织并公平承担必要劳动。

本模块继承 [`人为什么合作`](../../00_Core_Question/人为什么合作.md)、[`需求与责任`](../../00_Core_Question/需求与责任.md)、[`第一原则`](../../03_Aletheia_Framework/第一原则.md)、[`需求归属与公共需求责任`](../../03_Aletheia_Framework/需求归属与公共需求责任.md)、[`责任模型`](../../03_Aletheia_Framework/责任模型.md) 和 [`权力模型`](../../03_Aletheia_Framework/权力模型.md)。这里出现的机制不得反向定义人格价值、需求或基本保障。

推荐顺序：

1. [`劳动制度白皮书.md`](劳动制度白皮书.md)
2. [`任务池.md`](任务池.md)
3. [`能力池.md`](能力池.md)（公共任务匹配接口）
4. [`时间制度.md`](时间制度.md)
5. [`公共责任制度.md`](公共责任制度.md)
6. [`Mechanisms/有限互惠公共责任机制.md`](Mechanisms/有限互惠公共责任机制.md)
7. [`基本保障_有限公共责任_关键服务连续性协调研究.md`](基本保障_有限公共责任_关键服务连续性协调研究.md)

下层材料：

- [`Mechanisms/`](Mechanisms/)：当前机制草案与旧项目候选稿；具体责任转换先读 [`有限互惠公共责任机制.md`](Mechanisms/有限互惠公共责任机制.md)，连续性问题先读 [`公共服务连续性与储备机制.md`](Mechanisms/公共服务连续性与储备机制.md)；
- [`Implementation/`](Implementation/)：根目录重构前的历史参数与公式稿。

当前确认的是：基本保障绝不与履责挂钩；公共需求成立后先由公众承担归属层第一责任，并转化为可追溯的共同决定与机构职责；在此之后，有能力成员原则上承担有约束力但有限的互惠公共责任，并保留正当理由下的换班、延期、替代、豁免、异议和申诉。责任怎样记录、比较和结算属于激励机制，集中见 [`../Incentive_System/责任积分、贡献积分与领域专业评价.md`](../Incentive_System/责任积分、贡献积分与领域专业评价.md)；本导航不重复分类、公式、参数或历史方案。

本模块将“公共必要性认定”、“公共需求归属责任”、“机构的公共组织与维护责任”、“有限互惠公共责任”和“具体公共责任任务义务”分开。前四者不自动把任务分配给某个成员；具体任务只通过独立分支成立。普通自愿任务必须取得本人承诺；有限公共责任任务必须另经必要性、公众与机构先行责任、公平、能力、条件、通知、异议、替代、豁免、申诉和限定授权程序，不能把非本人承诺解释为无程序派工。

能力发现和个人能力图谱属于教育与个人发展接口；本模块只接收本人细粒度授权后的最小能力信息。参见 [`../Education_System/能力发现.md`](../Education_System/能力发现.md)。
