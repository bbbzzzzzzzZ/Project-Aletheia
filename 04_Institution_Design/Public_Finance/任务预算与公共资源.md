# 任务预算与公共资源

本文件的财政方向已经由项目发起者确认；税制、预算参数和分配机制仍待研究。

## 基本顺序

```text
已越过共同协调入口门槛的候选公共事项
→ 公共必要性与受影响者审查
→ 暂时公共决定
→ 具体任务与有限授权
→ 预算、分配与执行
→ 结果反馈
→ 缩减 / 再授权 / 退出
```

预算不能自行产生公共目的。个人表达需要、共同需要主张或候选公共事项，也不会自动生成公共决定、任务授权或预算；个人资源不因公共需要存在就自动成为公共资源。入口边界见 [`../../03_Aletheia_Framework/制度生成语法.md`](../../03_Aletheia_Framework/制度生成语法.md)。

## 资源类别

公共税收、公共土地与自然资源收益、公共资产收益、特定目的收入和临时融资应分别记录来源、用途、规模、期限与偿还责任。知识及其他共同生成资源的权利束需要另行研究。

## 任务预算

预算优先对应可审查的任务，而不是永久部门利益。跨任务冲突应公开比较紧迫性、权利影响、机会成本、时间跨度、最坏受影响者和退出成本。

公共项目应分项记录建设、材料、工资、维护、能源、土地、管理、退出与长期环境成本，同时记录参与者和受影响者的时间、交通、待命、恢复、健康、安全、照护与必要机会成本。已知、估计、不确定和暂时无法货币化的成本应分别展示，不合成为一个由单一机构控制的“总难度分”。

项目分类应按资金用途和组成进行，不把混合项目强塞进“基本支出”或“投资”单一类别。维持基本医疗、教育、安全和必要基础设施的支出不以财务回报证明正当；预期产生回报的投入须公开回报假设、周期、最坏情形、退出和维护责任。

受影响者参与所需的交通、照护、无障碍、翻译、时间和必要专业支持应列入项目成本，避免项目控制者以参与费用排除异议。资金安排须保留独立参与支持与申诉入口。

公共先行修复资金与责任追偿分账。追回的不当利益优先用于修复受害者和弥补公共损失，调查与追缴人员不得按追回金额提成。基金规模、支付优先级、风险分担、年度审计和不足方案继续保持开放。

## 财政退出

重大任务必须包含成功、失败、缩减和停止条件。支出完成率不是成功指标；问题减少、权利改善和副作用控制才是反馈对象。
