# Project Aletheia 制度白皮书

## 责任型社会制度框架（草案）

> 本文是 Project Aletheia 当前的项目级制度白皮书框架。它回答：既然社会应当服务于具体的人，人的需要怎样进入共同判断，公共责任怎样落实，又怎样防止共同目标直接变成对个人的占有。
>
> 本文不是法典、实施方案或已经验证的社会蓝图。它不规定固定工时、统一责任额度、积分公式、轮换周期、机构名称或处罚参数。现行定义仍以上游研究框架和术语表为准；本文负责把它们连接成一条可阅读的制度叙述。

## 一、为什么需要这项制度研究

现代社会能够完成单个个人无法独自完成的事情。食物、住房、照护、医疗、教育、交通、知识和安全，都依赖许多陌生人的长期合作。

但这种合作也可能发生目的倒置：

- 职业原本只是人承担某类工作的方式，后来却变成对人的永久定义；
- 工资和市场价格原本只处理交换，后来却被用来判断人的价值；
- 组织原本为了完成事情而建立，后来却要求人证明自己对组织有用；
- 公共需要原本属于公众共同面对的问题，后来却可能被推给当下正在求助的人，或直接变成某些人的无限义务；
- 能力、资源和专业知识原本为了完成任务，后来却可能转化为替别人决定的权力；
- 技术提高效率以后，节省下来的时间未必归还给人，反而可能产生更多填表、监控和展示性任务。

Project Aletheia 因此不从“怎样让社会机器更高效”开始，而从一个更基础的问题开始：

> 社会怎样维护共同生活所需的条件，同时不把具体的人变成制度的材料？

这只是研究切口，不是预设答案。项目不假定所有现代社会问题都来自同一种“错位”，而是具体检查：需要归属于谁，成本由谁承担，谁作出共同决定，谁获得执行权限，评价又对谁产生了超出原用途的影响。每一项都必须与已有理论、现实制度和更简单的竞争解释比较；在完成这种比较前，Aletheia 不能仅凭重新命名概念宣称提出了全新方案。比较工作见 [`研究问题与既有方案地图`](../08_Research_Workbench/01_Source_and_Priority_Maps/Project_Aletheia_研究问题与既有方案地图.md)。

这项研究面对的核心张力不是“个人还是社会”二选一。人需要他人和共同条件，也需要保有自己的身体、时间、关系和生活方向。共同责任如果完全缺失，必要服务可能无法持续；共同责任如果没有边界，自由又会被公共目标吞没。

白皮书要研究的，就是怎样使这两件事同时成立。

## 二、项目采用怎样的人与社会方向

### 1. 人先于身份和功能

项目首先面对能够感受、选择、学习并修订生活方向的人，而不是劳动力、岗位、能力、收入、贡献或制度位置。

人的身体、历史、关系和现实条件会限制选择，但这些限制不使职业和评价取得定义整个人的权力。一个人具有某项能力，只能说明他在特定条件下可能完成某类行动；不能说明他更有价值，也不能说明他已经愿意承担任务。

### 2. 自由、自主和社会依赖同时存在

本项目把自由、自主和社会依赖作为规范方向与工作假设，而不是已经被证明的单一人性定律。

- 自由要求人的生活方向、身体和时间不被外部目标预先占有；
- 自主要求人获得理解信息、辨认需要、形成选择和修订方向的现实条件；
- 社会依赖说明自由并非孤立完成，它始终需要照护、劳动、知识、关系、基础设施和共同安全。

因此，自由不是免除一切责任，社会性也不是共同体对人的所有权。制度必须同时维护共同存在基础和个人真实选择空间。

### 3. 社会因为人而存在

社会不是高于所有人的独立生命，也不是若干孤立个人的简单相加。它是人在共同生活中形成的关系、资源、知识、规则和风险。

制度只是处理其中确实需要稳定协调、权利保护和持续修正的问题。人的痛苦、关系冲突或生活困惑，可以停留在理解、本人行动、关系调整、自愿合作或既有服务中；没有进入新任务或新规则，不是失败。

## 三、白皮书继承的七条共同命题

本文不另立一套公理。它沿用根 README 与项目总纲的同一组七条普通语言命题：

1. **人先于身份和功能。** 职业、能力和贡献只能说明人的一部分，不能决定人的高低，也不能封住以后改变方向的可能。
2. **自己最有资格说明自己的需要，但需要不是命令。** 别人可以帮助理解事实和后果，却不能替本人拥有他的人生目的；表达需要也不会自动产生支配别人的权利。
3. **先判断这是谁的需要，再分清谁做了什么。** 私人需要由本人先负责；经确认的公共需要由公众先负责。表达、组织、承诺、执行和造成影响的人，再各自承担能够说明的责任；正在求助不等于要为整个公共系统负责。
4. **基本生活不靠履责换取，共同责任必须有限而公平。** 共同需要不能直接指定某个人；还要说明为什么由他承担、条件是否合理，以及遇到困难能否换一种方式。
5. **帮助不是施舍，接受帮助也不等于欠下人格债务。** 真实付出应当被看见，但不能把帮助变成永久服从，也不能把人按贡献排成高低。
6. **有能力、有资源或有影响力，不等于有权替别人决定。** 为完成一件事暂时交出的行动范围必须说清边界，并在事情结束或条件改变时归还。
7. **决定做什么、谁来承担、谁能行动不能混成一步；制度错了必须能改。** 现实结果、异议和受损经验都应使规则可以修改、暂停或结束。

后续所有制度模块都必须能解释自己怎样落实这些命题，又可能在哪里违背它们。

项目发起者已经确认以上七条的当前普通语言方向；这使本文相关部分完成了中心方向审阅，不表示白皮书其他段落已经逐句批准，也不表示事实核查、实践者复核或现实验证已经完成。

## 四、先判断需求归属，再谈第一责任

一个需要发生在谁身上、由谁说出来，不一定表示它只属于这个人。

私人偏好主要服务某个人自己的生活方案时，个人承担需求归属层的第一责任。他可以自行行动、请求帮助或寻求自愿交换，但不能只凭表达就把满足义务转给别人。

一项公共需求主张经过可质疑、可修订的公共正当性判断，确认属于公众应共同维护的最低条件以后，公众的第一责任随需求归属成立。病人可以是公共医疗需求在某一时刻的具体显现者，却不因此负责医疗系统为什么存在。

这里的公众是共同需求归属层的主体，不等于每个自然人的义务总和，也不是某个政府部门的别名。公众负责意味着：共同体不能把公共需求推回给当前求助者，必须使最低回应、共同成本、机构承接、监督和修复可追溯。

公共责任至少要分别说明五项内容：

1. **公共必要性认定**：这项公共需求主张是否成立，最低范围、不行动后果、替代和代价是什么；
2. **公共需求归属责任**：公共需求成立后，公众承担不能把它整体外部化的第一责任；
3. **公共组织与维护责任**：哪些机构或角色负责资金、人员、能力、物资、容量、监督、救济和连续性；
4. **有限互惠公共责任**：成员是否以及怎样公平分担维持公共必要条件的有限责任；
5. **具体公共责任任务义务**：某个人是否在某一时间承担某项有约束力任务。

第一项确认公共需求以后，第二项随归属成立；它仍不自动决定后三项，也不产生执行权限。机构供给失败、成员身份、受益事实、现实能力和公共缺口，都不能单独指定某个人。

## 五、从公共决定到现实行动

公共事项真正困难的地方，常常不是“大家是否认为事情重要”，而是共同需要的时间、风险和机会成本最后由谁承担。

因此，任何公共事项至少要区分三个问题：

### 1. 大家决定做什么

公共决定说明暂时目标、最低服务、资源方向、可接受风险和复核日期。它要识别受到实质影响的人，公开事实、不确定性、替代方案和少数保护。

这一决定只回答“共同体暂时选择什么”，不自动回答“必须由谁做”。

### 2. 具体由谁承担

普通任务由本人在知情条件下作出的具体承诺成立。有约束力的公共责任任务，则必须经过独立的个案程序，至少检查：

- 机构是否先履行正常组织、雇佣、培训、工具、储备和替代责任；
- 候选范围、既有负担、风险、时间和轮替是否公平；
- 本人是否具有当下相关能力，任务条件是否安全、合理；
- 健康、照护、创伤、年龄、隐私和其他正当理由能否进入延期、替代、豁免和申诉；
- 任务范围、期限、补偿、恢复和退出条件是否明确。

项目发起者此次只确认继续保留这一分支为待研究候选；上述条件、个案程序、现实效力和最终是否采用都尚未确定。

### 3. 承担者可以做什么

任务成立仍不等于取得权限。访问数据、调动资源、进入空间、对他人产生约束或使用强制手段，都必须按照完成任务的最小必要范围另行授权，并说明监督、撤回和结束条件。

三类输出在逻辑、依据和记录上必须分开，但不要求设立三套庞大机构，也不要求时间上机械排队。消防、急救、灾害处置，或已经由本人知情接受且范围明确的角色排班，可以预先安排或快速连续完成多个环节；前提是事前范围、能力和负担清楚，紧急启动最小、期限明确，事后能够复核，权限能够自动退出。

取得技能、通过认证、开放能力信息和承担任务仍是不同事情。能力证明不自动等于持续意愿；在不存在越权、危险或紧急健康情形时，已经正当形成的任务也不能无通知、无必要交接地随意取消。承担者只在可行范围内承担通知和安全交接，替代安排首先是机构责任。两者怎样在不同专业领域取得平衡，仍需验证。

## 六、制度怎样从人的问题开始，又避免接管人的问题

白皮书不把人的所有需要送入同一流程。项目在两份文件中保持边界：

- **世界观**说明项目怎样看人、关系、社会和制度，并保留倾听、本人行动、关系调整、自愿合作及既有服务等不新建设制度的路径；
- **制度生成语法**只处理已经另行说明为候选共同协调事项的问题，研究任务或规则怎样有限成立、反馈和退出。

越过共同协调入口以后，需求、责任、权力、资源、决定和反馈几个模型互相校正：

```text
需求：谁正在经历什么，这项具体需要归属于谁？
责任：谁因归属、承诺、角色、决定、行动或影响负责？
权力：谁事实控制什么，谁又获得了什么有限授权？
资源：要调用什么，代价和机会成本由谁承担？
决定：目标、具体承担和执行权限是否分别说明？
反馈：谁受益、谁受损、谁被遗漏，怎样修订、停止和修复？
```

这些问题不是一条不可逆流水线。发现需求理解错误、负担集中、能力条件变化或实际伤害时，应当退回前一步，而不是为了流程完整强迫制度继续运行。

## 七、制度模块怎样共同工作

| 模块 | 主要问题 | 当前方向 | 最主要风险 |
|---|---|---|---|
| 劳动 | 必要工作怎样完成，又不让职业占有人生 | 任务、能力、承担依据、时间和权限分离；服务连续性与个人退出共同设计 | 公共责任变成固定身份、无限待命或数字劳役 |
| 教育 | 人怎样认识自己、发展能力并持续改变方向 | 教育服务人的成长和共同生活能力，不只服务就业筛选 | 重新把人训练成社会需要的工具 |
| 经济 | 交换、创新、基本保障和公共资源怎样共存 | 人的存在价值、公共责任记录和市场交换分别处理 | 价格、财富和技术重新决定人格与公共权力 |
| 政治 | 共同选择怎样产生，代表和专家处在什么位置 | 受影响者相称参与，目标决定、专业判断、执行和监督分离 | 代表垄断需求，多数取消少数边界，临时权限永久化 |
| 宪制与司法 | 怎样保护人的基本地位并纠正公共决定 | 权利底线、证据、解释、裁判、救济和修复可相互纠错 | 司法或法律解释自行创造不可监督的新权力 |
| 行政 | 怎样持续执行公共职能而不形成机构所有权 | 行政围绕有限职能、任务、公开理由和周期复核运行 | 机构为自我延续制造需求、预算和岗位 |
| 公共财政 | 共同资源怎样服务已说明的公共目标 | 预算与任务、受影响者、机会成本、监督和退出连接 | 预算规模替代实际效果，公共成本被隐藏或转嫁 |
| 信息与 AI | 数据和模型怎样提供帮助而不取得最终定义权 | 最小数据、用途限定、可质疑建议和人类可追溯决定 | 数据入口、指标和算法形成事实裁决权 |
| 激励 | 怎样让真实贡献可见，又不把记录变成人的价格 | 责任、贡献、质量和专业证据分账且限域使用 | 积分、声誉和便利累积成人格、阶层或政治等级 |

模块之间没有简单上下级关系。教育影响能力形成，却不能决定人的职业；劳动调用资源，却不能取消基本保障；经济交换不能购买政治权；政治决定不能拥有个人的需要；司法纠错也不能脱离证据和监督。

## 八、怎样判断制度有没有变好

项目发起者明确关心：一个普通人在承担必要共同责任之后，实际还有多少属于自己的时间。

自主时间是重要评价轴，因为人的生命时间不可恢复。制度如果只提高产出，却扩大无意义劳动、待命、通勤、通知、评分、恢复负担和无法安全拒绝的占用，就可能没有把效率真正还给人。

但自主时间不是唯一指标，也不能只看平均小时数。评价至少要同时检查：

- **基本权利与保障**：人是否无需用服从换取食物、住所、医疗、安全和救济；
- **真实选择能力**：时间是否有基本资源、教育、健康、无障碍和信息支持；
- **负担分布**：平均改善是否建立在少数人的极端劳动、风险或照护上；
- **关系与照护**：制度是否把关系性需要压成匿名任务，或把隐藏照护推给家庭；
- **非支配**：人是否能够拒绝、异议、退出并免受跨域报复；
- **服务连续性**：减少劳动是否牺牲了必要服务对象的安全与可达性；
- **事实权力**：谁实际控制数据、标准、资源、入口和救济；
- **可纠错性**：错误能否被发现、暂停、修复，并使权限和事实控制退出。

未来可以研究时间分布、待命、恢复、照护和注意力占用的测量方法，但白皮书不预设公式，也不把复杂生活压成单一总分。

## 九、当前仍未确定什么

Project Aletheia 目前只能确定方向和边界，不能声称已经完成制度设计。至少以下问题仍然开放：

1. 自由、自主和社会依赖应当作为规范选择，还是能够形成可证伪的人类行为命题？
2. 哪些需要应当成为公共需求，公众的地域、跨代和跨组织边界怎样确定？
3. 公众第一责任怎样落到可追溯机构，而不变成“所有人负责”或“无人负责”？
4. 有限互惠公共责任的成员范围、总负担、公平分配、豁免、替代和申诉怎样成立？
5. 基本公共能力适合普及到什么程度，高风险专业能力怎样兼顾训练、熟练度、安全、轮换和关系连续性？
6. 学习、认证、能力信息授权、进入候选池、接受角色、待命、具体任务与执行权限怎样分开？
7. 已经成立的任务在健康、危险、越权或生活条件变化时怎样暂停或退出；通知、隐私、替代与安全交接怎样平衡？
8. 怎样把机会成本、既有负担和高能力者被反复调用纳入分配，又不让市场收入决定公共价值？
9. 自主时间怎样测量并与资源、能力、关系、非支配、负担分布和服务连续性一起评价？
10. 基本保障在真实资源短缺时怎样公平交付，而不重新与履责或人格评价挂钩？
11. 代表、多数、专家、未来世代、儿童、失能者和未被组织者怎样进入共同选择？
12. 紧急快速通道怎样避免临时责任和权限常态化？
13. 责任与贡献记录怎样避免刷分、隐私侵入、跨域声誉和新的社会等级？
14. 各模块怎样从小规模原型、专业实践者和受影响者审阅中获得现实证据？

## 十、白皮书怎样继续展开

项目维持三级文档结构：

- **框架层**说明问题、原则、接口、边界与未决事项；
- **机制层**研究任务、机构、轮换、记录、监督、申诉和退出可能怎样运行；
- **实施层**才处理参数、法条、算法、表单、系统设计与具体机构。

本文只处于第一层。[`Project_Aletheia_机制层总览草案.md`](Project_Aletheia_机制层总览草案.md)先把公共认定、任务封套、具体承担、最小授权与关键服务连续性连接成候选运行链；年度责任记录、任务系数、专业评价、权力控制矩阵、公共服务储备和具体轮换办法，仍由相应专题机制文件维护。任何机制只有在受影响者、实践者、反例和失败条件中经过验证后，才可能进入更具体的实施研究。

### 现实比较是进入实施研究的前置条件

价值方向和候选机制不能直接证明现实方案更好。每一项候选改变至少要回答：

- **现行基线是什么？** 限定具体地域、时期、机构、规则与受影响者；
- **旧制度哪些功能必须保留？** 不能只列痛点，也要说明现行安排已经解决的协调、专业安全、连续性与救济；
- **为什么选择这一改动？** 同时比较维持现状、较小幅度修补和候选机制；
- **收益、代价和资源落在谁身上？** 分开常态成本、转换成本、机会成本与最坏受影响者；
- **怎样小规模、可逆地检验？** 写明合法权限、支撑制度、进入条件、备用服务、停止、回滚、修复和补偿。

这五问不是第八条公众命题，也不是已经确认的实施阶段。完整记录格式由 [《制度压力测试协议》](../06_Criticism_and_Failure/制度压力测试协议.md) 维护；未完成现实基线、竞争方案、成本分布和回滚准备时，候选机制只能停留在内部研究。

白皮书的下一步不是继续增加宏大原则，而是选择边界明确的场景检验接口。例如：

- 夜间急救中，公众、医院、专业人员和患者分别处在什么责任位置；
- 长期照护中，稳定关系与公平分担怎样同时成立；
- 消防或灾害响应中，预先角色安排与紧急权限怎样退出；
- 自动化减少必要劳动以后，时间怎样真实返还而不是制造新任务；
- 资源短缺时，最低保障、服务降级和申诉怎样保持公平。

如果这些场景显示项目让必要服务更脆弱、把责任集中给低权力者、扩大事实控制、制造新的身份等级，或让人失去更多真实可支配时间，框架就必须被修改，而不是要求现实适应理论。
